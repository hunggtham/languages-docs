# Lesson 03 — Gerunds and `-ed / -ing` adjectives

**Level:** A2–B1  
**Goals:** recognize the job of `V-ing`, choose the correct adjective ending, and avoid the common errors in the notes.

## Gerund: `V-ing` as a noun

- Subject: `Learning English is fun.`
- After a preposition: `I am interested in learning English.`
- After verbs such as **enjoy, finish, avoid, suggest, keep, mind**: `I enjoy studying English.`

Compare:

- `I am studying English.` → present continuous; `studying` is the verb.
- `Studying English is important.` → gerund; `studying` is the subject noun.

After **want, need, hope, plan**, use `to + verb`: `I want to study`, not `I want studying`.

## `-ed` and `-ing`

- `-ed` describes the person’s feeling: `I was tired.`
- `-ing` describes the thing that causes the feeling: `The work was tiring.`

| Cause (`-ing`) | Feeling (`-ed`) |
|---|---|
| boring | bored |
| interesting | interested |
| exciting | excited |
| tiring | tired |
| surprising | surprised |
| amazing | amazed |
| confusing | confused |
| frustrating | frustrated |
| annoying | annoyed |
| worrying | worried |
| disappointing | disappointed |
| embarrassing | embarrassed |
| shocking | shocked |
| frightening | frightened |
| depressing | depressed |
| satisfying | satisfied |
| relaxing | relaxed |
| exhausting | exhausted |
| overwhelming | overwhelmed |
| fascinating | fascinated |

The natural pair is: `It was a tiring day. I was tired.`
