# Error notes — sentences found in the export

These are corrections of sentences written in the Markdown note or visible in the screenshots. The goal is to show the pattern, not to grade the learner.

| Original | Standard correction | Why |
|---|---|---|
| `I enjoy study English.` | `I enjoy studying English.` | `enjoy` takes a gerund. |
| `I finished do my work.` | `I finished doing my work.` | `finish` takes a gerund. |
| `It's tired day.` | `It's a tiring day.` | The day causes the feeling, so use `-ing`; add the article `a`. |
| `I am tired.` | Correct | The person feels tired, so use `-ed`. |
| `so which one do you matters more` | `So which one matters more to you?` | No `do` when `which one` is the subject. |
| `My opinion is earning money because it's important for me.` | `I think earning money matters because it is important to me.` | Natural clause structure and pronoun reference. |
| `If can become a professional…` | `If I could become a professional…` | A conditional clause needs a subject and modal. |
| `It would make me very happe…` | `It would make me very happy.` | Adjective spelling: `happy`. |
| `I don't know why did they use machine guns.` | `I don't know why they used machine guns.` | Indirect questions use statement order. |
| `Do you know how many emus were there?` | `Do you know how many emus there were?` | The embedded clause keeps subject before verb. |
| `He said me that the theory was wrong.` | `He told me that the theory was wrong.` | `tell` takes an object; `say` does not (`said to me`). |
| `She told that lions hunt at night.` | `She said that lions hunt at night.` | Add an object after `told`, or use `said`. |
| `He asked what did I think.` | `He asked what I thought.` | No question inversion inside an indirect question. |
| `They denied that using the wrong method.` | `They denied using the wrong method.` | `deny` is commonly followed by `V-ing`. |
| `He explained me the experiment.` | `He explained the experiment to me.` | Use `explain + thing + to + person`. |
| `She said she will publish it next year.` | `She said she would publish it the following year.` | Backshift after past `said`; adjust the time reference. |
| `I didn't used to like coffee.` | `I didn't use to like coffee.` | After `did`, use the base form `use`. |
| `Did you used to live abroad?` | `Did you use to live abroad?` | Same `did + base form` rule. |
| `I'm used to work late.` | `I'm used to working late.` | `be used to` is followed by a noun or gerund. |
| `Japan is two hours Vietnam.` | `Japan is two hours ahead of Vietnam.` | Use `ahead of/behind` for time differences. |

## Corrections that need confirmation

The diary line OCRed as `then that’s so late than I thought` is ambiguous. The most likely intended sentence is **`But it was later than I thought.`** If the intended meaning is that the speaker arrived late, use **`But I was later than I thought.`**
