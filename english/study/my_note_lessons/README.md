# My note → web-ready English lessons

This folder is a cleaned, teachable version of the Notion export in
`english/study/my_note/`. The source export is unchanged.

## Contents

- `lessons/`: short, self-contained lessons with objectives, rules, examples and source-image references.
- `exercises/`: practice sets. They contain no hidden answers.
- `answers/`: answer keys with a brief reason for each answer.
- `error-notes/`: corrections of sentences found in the notes and screenshots.
- `media/`: all 89 exported PNG files, renamed deterministically (`notion-image-001.png` … `notion-image-089.png`).
- `source-inventory.md`: audit of all source images and the lesson they support.
- `manifest.json`: machine-readable index for a later web import.

## Editorial rules

1. The original Notion files are evidence, not a final curriculum. OCR-only text is marked as a source reference and is not silently treated as a confirmed answer.
2. Exercises are newly formatted from the rules and examples in the notes. The answer key explains the grammar choice.
3. Corrections preserve the likely intended meaning. Where the screenshot is unclear, the correction is marked **Cần xác nhận ý**.
4. Image references use relative paths so the folder can be copied to a static web directory as one unit.
