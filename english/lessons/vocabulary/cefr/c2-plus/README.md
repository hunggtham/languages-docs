# C2+ Vocabulary

C2+ extends the corpus beyond standard C2 with rare but living literary, journalistic, technical-adjacent, rhetorical, and specialized contemporary English. Lessons remain topic-first and self-contained; there is no fixed item quota.

Files are numbered independently inside each topic folder. Every headword has an American IPA heading, English core meaning, Vietnamese mental image, useful usage notes, an original example with Vietnamese translation, Korean linking when helpful, and a review passage that reuses every headword.
