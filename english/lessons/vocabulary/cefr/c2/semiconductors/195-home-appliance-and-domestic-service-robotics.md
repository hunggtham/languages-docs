# C2 Vocabulary — Home-appliance and domestic-service robotics

This lesson follows domestic service from diagnosis and repair to accessibility, energy, security, and recycling. The network is **appliance diagnostic robot → washing machine repair robot → refrigerator service robot → dishwasher inspection robot → oven calibration robot → vacuum cleaner maintenance robot → air conditioner cleaning robot → heat pump service robot → water heater inspection robot → dryer lint inspection robot → microwave leakage test robot → smart appliance firmware robot → home energy audit robot → pipe leak household robot → window shade installation robot → furniture assembly robot → home accessibility robot → elderly home support robot → home security inspection robot → household recycling robot**.

## 1. appliance diagnostic robot /əˈplaɪəns ˌdaɪəɡˈnɑːstɪk ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that identifies faults in a household appliance.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot identify fault của household appliance.
**Grammar & collocations:** `appliance-diagnostic-robot scan` — scan; `isolate an electrical fault` — isolate fault điện.
**Examples:** `The appliance diagnostic robot isolated an electrical fault.` → Robot chẩn đoán appliance cô lập lỗi điện.
**Liên kết tiếng Hàn:** `가전 진단 로봇`.
