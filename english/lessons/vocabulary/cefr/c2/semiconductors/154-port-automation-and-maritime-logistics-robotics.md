# C2 Vocabulary — Port automation and maritime logistics robotics

This lesson follows a container through automated port arrival, inspection, storage, dispatch, and vessel coordination. The network is **port automation robot → autonomous container truck → ship-to-shore crane robot → yard crane automation → container stacking robot → terminal tractor autonomy → berth scheduling → container routing → cargo inspection robot → port security robot → underwater hull inspection → harbor patrol robot → maritime surveillance drone → container damage detection → seal verification → cargo tracking robot → warehouse-to-port coordination → intermodal dispatch → truck appointment scheduling → yard congestion prediction**.

## 1. port automation robot /pɔːrt ˌɔːtəˈmeɪʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot or automated machine that moves, inspects, or coordinates cargo in a port.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot/machine tự động move, inspect hoặc coordinate cargo trong port.
**Grammar & collocations:** `port-automation-robot fleet` — fleet; `move a container safely` — move container an toàn.
**Examples:** `The port automation robot moved the container from the inspection lane to the yard.` → Port automation robot chuyển container từ inspection lane tới yard.
**Liên kết tiếng Hàn:** `항만 자동화 로봇`.

## 2. autonomous container truck /ɔːˈtɑːnəməs kənˈteɪnər trʌk/
**Part of speech:** noun
**Core meaning (English):** a self-driving truck that carries containers within a port or terminal.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** truck tự lái chở container trong port/terminal.
**Grammar & collocations:** `autonomous-container-truck route` — route; `haul a loaded box` — chở loaded container.
**Examples:** `The autonomous container truck waited until the crane cleared the lane.` → Autonomous container truck đợi tới khi crane dọn lane.
**Liên kết tiếng Hàn:** `자율 컨테이너 트럭`.

## 3. ship-to-shore crane robot /ʃɪp tə ʃɔːr kreɪn ˈroʊbɑːt/

**Nghĩa cốt lõi & hình ảnh ghi nhớ:** crane tự động chuyển container giữa ship và quay.
**Grammar & collocations:** `ship-to-shore-crane-robot spreader` — spreader; `lift a container from a vessel` — nâng container từ vessel.
**Examples:** `The ship-to-shore crane robot aligned the spreader before lifting the next box.` → Ship-to-shore crane robot căn spreader trước khi nâng box tiếp.
**Liên kết tiếng Hàn:** `선박-육상 크레인 로봇`.

## 18. intermodal dispatch /ˌɪntərˈmoʊdəl dɪˈspætʃ/

**Liên kết tiếng Hàn:** `복합 운송 배차`.
