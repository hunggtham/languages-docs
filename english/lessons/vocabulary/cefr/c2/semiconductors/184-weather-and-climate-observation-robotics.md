# C2 Vocabulary — Weather and climate observation robotics

This lesson follows environmental observation from weather-station maintenance and atmospheric sampling to hazards, climate records, and field recovery. The network is **weather radar maintenance robot → atmospheric sampling robot → meteorological balloon launch robot → rain gauge maintenance robot → ice storm monitoring drone → lightning detection robot → air quality calibration robot → ocean buoy sensor robot → glacier crevasse mapping robot → volcanic ash monitoring drone → earthquake sensor deployment robot → seismic station maintenance robot → landslide monitoring robot → flood gauge inspection robot → climate station cleaning robot → permafrost survey robot → hail detection drone → drought monitoring robot → wind profiler robot → solar radiation measurement drone**.

## 1. weather radar maintenance robot /ˈweðər ˈreɪdɑːr ˈmeɪntənəns ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that inspects or services radar equipment used to observe weather.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot inspect/service radar equipment dùng observe weather.
**Grammar & collocations:** `weather-radar-maintenance-robot tool` — tool; `service a rotating antenna` — service rotating antenna.
**Examples:** `The weather radar maintenance robot serviced the rotating antenna before the storm.` → Robot maintenance weather radar service rotating antenna trước storm.
**Liên kết tiếng Hàn:** `기상 레이더 유지보수 로봇`.

## Review in context

A **weather radar maintenance robot**, **atmospheric sampling robot**, **meteorological balloon launch robot**, and **rain gauge maintenance robot** support observation, while an **ice storm monitoring drone**, **lightning detection robot**, and **air quality calibration robot** track hazards and pollution.
