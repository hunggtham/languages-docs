# C2 Vocabulary — Postal mail automation and parcel robotics

This lesson follows mail from intake and recognition to sorting, inspection, delivery, returns, and secure handling. The network is **postal sorting robot → parcel dimension scanning robot → automated mail processing robot → envelope cancellation robot → stamp verification robot → postal address recognition robot → parcel X-ray inspection robot → delivery route optimization robot → mailbag handling robot → sorting conveyor robot → post office service robot → postal locker delivery robot → international customs parcel robot → return mail processing robot → fragile parcel handling robot → oversize parcel robot → postal security screening robot → rural delivery robot → mail vehicle loading robot → weatherproof parcel robot**.

## 1. postal sorting robot /ˈpoʊstəl ˈsɔːrtɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that separates letters and parcels by destination, service, or handling requirement.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot separate letter/parcel theo destination, service hoặc handling requirement.
**Grammar & collocations:** `postal-sorting-robot chute` — chute; `route a parcel by postcode` — route parcel theo postcode.
**Examples:** `The postal sorting robot routed the parcel to the regional hub.` → Postal sorting robot route parcel tới regional hub.
**Liên kết tiếng Hàn:** `우편 분류 로봇`.
