# C2 Vocabulary — Railway and metro infrastructure robotics

This lesson follows rail infrastructure from geometry and weld inspection to overhead power, stations, and depot work. The network is **railway ballast inspection robot → track geometry mapping robot → rail weld inspection robot → overhead line inspection drone → pantograph inspection robot → switch point maintenance robot → platform edge inspection robot → station elevator patrol robot → train undercarriage inspection robot → wheel profile scanning robot → signaling cabinet inspection robot → railway vegetation control robot → level crossing inspection robot → tunnel ventilation robot → catenary tension measurement → railway debris clearing robot → automated track possession system → metro depot cleaning robot → rail corridor survey drone → rail fastener inspection robot**.

## 1. railway ballast inspection robot /ˈreɪlweɪ ˈbæləst ɪnˈspekʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that checks the stones supporting railway sleepers for displacement, fouling, or drainage problems.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot check ballast đỡ sleeper về displacement, fouling hoặc drainage problem.
**Grammar & collocations:** `railway-ballast-inspection-robot camera` — camera; `inspect a shoulder of ballast` — inspect ballast shoulder.
**Examples:** `The railway ballast inspection robot found fouled ballast beside the curve.` → Robot inspection railway ballast tìm ballast fouled cạnh curve.
**Liên kết tiếng Hàn:** `철도 자갈 검사 로봇`.
