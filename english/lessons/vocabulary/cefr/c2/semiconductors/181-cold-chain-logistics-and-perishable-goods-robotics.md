# C2 Vocabulary — Cold-chain logistics and perishable-goods robotics

This lesson follows temperature-sensitive goods from storage and packing to route monitoring, quality checks, and delivery. The network is **cold-chain warehouse robot → refrigerated pallet robot → temperature excursion monitor → automated freezer retrieval → perishable order picking robot → ice-pack packing robot → reefer container inspection robot → cold-room inventory robot → thermal packaging robot → fresh produce sorting robot → meat processing inspection robot → seafood grading robot → dairy filling robot → frozen food palletizing robot → cold-chain route monitoring drone → biologic cold-chain courier robot → last-mile chilled delivery robot → packhouse quality robot → shelf-life prediction system → refrigerant leak patrol robot**.

## 1. cold-chain warehouse robot /koʊld tʃeɪn ˈwerhaʊs ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that stores, moves, or retrieves goods that must remain within a controlled temperature range.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot store, move hoặc retrieve goods phải giữ trong temperature range control.
**Grammar & collocations:** `cold-chain-warehouse-robot route` — route; `move a chilled pallet` — move chilled pallet.
**Examples:** `The cold-chain warehouse robot moved the chilled pallet before the door opened.` → Robot cold-chain warehouse chuyển pallet chilled trước khi door mở.
**Liên kết tiếng Hàn:** `콜드체인 창고 로봇`.
