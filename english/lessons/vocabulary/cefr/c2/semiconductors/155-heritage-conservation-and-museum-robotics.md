# C2 Vocabulary — Heritage conservation and museum robotics

This lesson follows robots that document, inspect, preserve, and explain cultural heritage without damaging fragile objects. The network is **heritage conservation robot → archaeology robot → museum guide robot → artifact scanning robot → 3d documentation robot → monument inspection robot → cultural heritage mapping → laser scanning robot → photogrammetry robot → archaeological survey drone → cave mapping robot → underground heritage robot → artifact handling robot → museum security robot → visitor guidance robot → conservation imaging → multispectral artifact imaging → surface condition mapping → mortar deterioration detection → stone crack detection**.

## 1. heritage conservation robot /ˈherɪtɪdʒ ˌkɑːnsərˈveɪʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that documents, inspects, or helps preserve historic objects, buildings, and sites.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot document, inspect hoặc preserve historic object, building và site.
**Grammar & collocations:** `heritage-conservation-robot platform` — platform; `inspect a fragile surface` — inspect surface dễ hỏng.
**Examples:** `The heritage conservation robot inspected the ceiling without touching the painted surface.` → Heritage conservation robot kiểm tra trần mà không chạm painted surface.
**Liên kết tiếng Hàn:** `문화유산 보존 로봇`.

## 2. archaeology robot /ˌɑːrkiˈɑːlədʒi ˈroʊbɑːt/

**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot survey, map, excavate hoặc document archaeological remain.
**Grammar & collocations:** `archaeology-robot trench` — trench; `record a buried feature` — ghi buried feature.
