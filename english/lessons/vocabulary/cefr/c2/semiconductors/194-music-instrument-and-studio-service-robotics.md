# C2 Vocabulary — Music-instrument and studio-service robotics

This lesson follows instruments and studio spaces from inspection and restoration to transport, calibration, and performance support. The network is **musical instrument inspection robot → piano tuning robot → string replacement robot → violin varnish robot → wind instrument cleaning robot → guitar fret polishing robot → instrument digitization robot → concert instrument transport robot → audio equipment calibration robot → acoustic panel installation robot → studio cable routing robot → speaker cone inspection robot → microphone repair robot → instrument case inventory robot → orchestra chair setup robot → music archive scanning robot → instrument humidity monitor robot → recording booth cleaning robot → sheet music delivery robot → instrument restoration robot**.

## 1. musical instrument inspection robot /ˈmjuːzɪkəl ˈɪnstrəmənt ɪnˈspekʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that checks an instrument’s structure, surface, mechanism, or sound-producing parts.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot check structure, surface, mechanism hoặc sound-producing part của instrument.
**Grammar & collocations:** `musical-instrument-inspection-robot camera` — camera; `inspect a cracked bridge` — inspect bridge nứt.
**Examples:** `The musical instrument inspection robot found a crack near the bridge.` → Robot inspection musical instrument tìm crack gần bridge.
**Liên kết tiếng Hàn:** `악기 검사 로봇`.
