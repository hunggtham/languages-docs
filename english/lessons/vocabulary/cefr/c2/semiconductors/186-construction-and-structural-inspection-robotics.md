# C2 Vocabulary — Construction and structural-inspection robotics

This lesson follows a building project from surveying and foundations to concrete work, prefabrication, safety, and demolition. The network is **concrete scanning robot → rebar inspection robot → site surveying drone → brick wall inspection robot → tower crane inspection drone → formwork placement robot → concrete finishing robot → foundation pile inspection robot → structural crack mapping drone → thermal bridge inspection drone → building materials handling robot → prefabrication assembly robot → welding inspection drone → construction safety patrol robot → dust monitoring construction robot → demolition sorting robot → concrete curing robot → masonry layout robot → scaffold inspection robot → temporary structure monitoring robot**.

## 1. concrete scanning robot /ˈkɑːnkriːt ˈskænɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that scans concrete to find voids, pipes, reinforcement, or hidden damage.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot scan concrete để tìm void, pipe, reinforcement hoặc damage ẩn.
**Grammar & collocations:** `concrete-scanning-robot sensor` — sensor; `locate an embedded pipe` — locate embedded pipe.
**Examples:** `The concrete scanning robot located an embedded pipe before drilling.` → Robot scanning concrete locate pipe embedded trước drilling.
**Liên kết tiếng Hàn:** `콘크리트 스캔 로봇`.
