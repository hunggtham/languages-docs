# C2 Vocabulary — Medical-device manufacturing and reprocessing robotics

This lesson follows a medical device from assembly and inspection to sterile packaging, reprocessing, and traceability. The network is **medical device assembly robot → catheter insertion robot → stent inspection robot → implant packaging robot → sterilization loading robot → surgical instrument cleaning robot → prosthetic alignment robot → orthotic fabrication robot → diagnostic cartridge assembly robot → inhaler testing robot → wearable device calibration robot → device leak testing robot → implant surface inspection robot → cleanroom medical device robot → endoscope reprocessing robot → medical device labeling robot → sterile barrier packaging robot → device usability test robot → biocompatibility sample robot → medical device traceability system**.

## 1. medical device assembly robot /ˈmedɪkəl dɪˈvaɪs əˈsembli ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that assembles components into a device used for diagnosis, treatment, or monitoring.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot assemble component thành device dùng cho diagnosis, treatment hoặc monitoring.
**Grammar & collocations:** `medical-device-assembly-robot cell` — cell; `join a miniature component` — join component nhỏ.
**Examples:** `The medical device assembly robot joined the miniature valve to the catheter hub.` → Robot assembly medical device join valve nhỏ với catheter hub.
**Liên kết tiếng Hàn:** `의료기기 조립 로봇`.
