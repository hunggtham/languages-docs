# C2 Vocabulary — Additive and composite manufacturing robotics

This lesson follows advanced production from material deposition and layup to inspection, repair, finishing, and traceability. The network is **industrial 3D printing robot → metal powder deposition robot → wire arc additive robot → laser cladding robot → powder bed recoater robot → build chamber inspection robot → support removal robot → post-processing finishing robot → robotic metrology arm → surface roughness scanning robot → additive repair robot → composite layup robot → automated fiber placement robot → resin infusion robot → ultrasonic weld inspection robot → non-destructive testing robot → toolpath verification robot → mold polishing robot → manufacturing inspection drone → part traceability robot**.

## 1. industrial 3D printing robot /ɪnˈdʌstriəl θriː ˈdiː ˈprɪntɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that builds a three-dimensional part by depositing or solidifying material layer by layer.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot build part 3D bằng cách deposit/solidify material từng layer.
**Grammar & collocations:** `industrial-3D-printing-robot cell` — cell; `build a complex bracket` — build bracket complex.
**Examples:** `The industrial 3D printing robot built a lightweight bracket overnight.` → Robot industrial 3D printing build bracket nhẹ qua đêm.
**Liên kết tiếng Hàn:** `산업용 3D 프린팅 로봇`.

## Review in context

An **industrial 3D printing robot**, **metal powder deposition robot**, **wire arc additive robot**, and **laser cladding robot** build or repair metal, while a **powder bed recoater robot** and **build chamber inspection robot** control the process. A **support removal robot**, **post-processing finishing robot**, **robotic metrology arm**, and **surface roughness scanning robot** finish and measure parts. An **additive repair robot**, **composite layup robot**, **automated fiber placement robot**, and **resin infusion robot** create advanced structures. An **ultrasonic weld inspection robot**, **non-destructive testing robot**, **toolpath verification robot**, **mold polishing robot**, **manufacturing inspection drone**, and **part traceability robot** connect evidence to production quality.

**Bản dịch tiếng Việt:** **Industrial 3D printing robot**, **metal powder deposition robot**, **wire arc additive robot** và **laser cladding robot** build/repair metal, còn **powder bed recoater robot** và **build chamber inspection robot** control process. **Support removal robot**, **post-processing finishing robot**, **robotic metrology arm** và **surface roughness scanning robot** finish/measure part. **Additive repair robot**, **composite layup robot**, **automated fiber placement robot** và **resin infusion robot** tạo advanced structure. **Ultrasonic weld inspection robot**, **non-destructive testing robot**, **toolpath verification robot**, **mold polishing robot**, **manufacturing inspection drone** và **part traceability robot** nối evidence với production quality.
