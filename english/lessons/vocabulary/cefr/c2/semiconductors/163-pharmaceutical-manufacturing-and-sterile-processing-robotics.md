# C2 Vocabulary — Pharmaceutical manufacturing and sterile-processing robotics

This lesson follows a medicine from sterile production and inspection to packaging, storage, and pharmacy preparation. The network is **pharmaceutical manufacturing robot → aseptic filling robot → vial inspection robot → tablet coating robot → capsule sorting robot → sterile isolator robot → cleanroom transfer robot → bioreactor sampling robot → cell culture handling robot → lyophilization loading robot → drug packaging robot → serialization verification robot → cold storage retrieval robot → batch record review robot → cleanroom environmental monitoring robot → contamination control robot → automated visual inspection → fill-finish robot → clinical supply robot → pharmacy compounding robot**.

## 1. pharmaceutical manufacturing robot /ˌfɑːrməˈsuːtɪkəl ˌmænjəˈfæktʃərɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot used to make, handle, inspect, or package medicines in a controlled facility.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot dùng để make, handle, inspect hoặc package medicine trong facility kiểm soát.
**Grammar & collocations:** `pharmaceutical-manufacturing-robot cell` — cell; `handle a sterile batch` — handle sterile batch.
**Examples:** `The pharmaceutical manufacturing robot moved sealed containers between process stations.` → Robot pharmaceutical manufacturing chuyển container sealed giữa process station.
**Liên kết tiếng Hàn:** `제약 제조 로봇`.

## Review in context

A **pharmaceutical manufacturing robot** can feed an **aseptic filling robot**, while a **vial inspection robot**, **tablet coating robot**, and **capsule sorting robot** check different products. A **sterile isolator robot**, **cleanroom transfer robot**, **bioreactor sampling robot**, and **cell culture handling robot** protect controlled processes; a **lyophilization loading robot** handles freeze-dried material. A **drug packaging robot** and **serialization verification robot** prepare traceable packs, while a **cold storage retrieval robot** protects temperature-sensitive stock. A **batch record review robot**, **cleanroom environmental monitoring robot**, and **contamination control robot** support quality. **Automated visual inspection**, a **fill-finish robot**, a **clinical supply robot**, and a **pharmacy compounding robot** connect manufacturing with patient-ready medicine.

**Bản dịch tiếng Việt:** **Pharmaceutical manufacturing robot** có thể feed **aseptic filling robot**, còn **vial inspection robot**, **tablet coating robot** và **capsule sorting robot** check các product khác nhau. **Sterile isolator robot**, **cleanroom transfer robot**, **bioreactor sampling robot** và **cell culture handling robot** bảo vệ controlled process; **lyophilization loading robot** xử lý material freeze-dried. **Drug packaging robot** và **serialization verification robot** chuẩn bị pack traceable, còn **cold storage retrieval robot** bảo vệ stock nhạy nhiệt. **Batch record review robot**, **cleanroom environmental monitoring robot** và **contamination control robot** hỗ trợ quality. **Automated visual inspection**, **fill-finish robot**, **clinical supply robot** và **pharmacy compounding robot** nối manufacturing với medicine sẵn sàng cho patient.
