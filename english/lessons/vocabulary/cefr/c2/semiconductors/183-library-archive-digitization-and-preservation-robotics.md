# C2 Vocabulary — Library, archive digitization, and preservation robotics

This lesson follows cultural records from careful retrieval and page handling to scanning, metadata, conservation, and disaster recovery. The network is **archive scanning robot → book digitization robot → manuscript page-turning robot → library shelf inventory robot → rare book handling robot → document flattening robot → microfilm scanning robot → archival box retrieval robot → humidity monitoring robot → conservation imaging robot → paper deacidification robot → book repair robot → library return sorting robot → automated shelving robot → reading room delivery robot → copyright metadata robot → document OCR verification robot → digitization quality robot → archive pest monitoring robot → disaster document recovery robot**.

## 1. archive scanning robot /ˈɑːrkaɪv ˈskænɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that scans archival records while handling them gently and consistently.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot scan archival record và handle nhẹ/nhất quán.
**Grammar & collocations:** `archive-scanning-robot camera` — camera; `capture a fragile page` — capture page fragile.
**Examples:** `The archive scanning robot captured the fragile page without pressing its fold.` → Robot scanning archive capture page fragile mà không press fold.
**Liên kết tiếng Hàn:** `기록 보관소 스캔 로봇`.
