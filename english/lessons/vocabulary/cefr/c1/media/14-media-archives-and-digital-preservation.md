# C1 Vocabulary 14 — Media archives and digital preservation

This lesson follows how media organizations preserve published work so that evidence, memory, and public access survive technological change.

Flow: **preservation standard → catalog record → metadata schema → born-digital → archival copy → migration plan → file format obsolescence → access copy → rights clearance → institutional memory → archive description → finding aid → digitization backlog → preservation repository → authenticity marker → archival embargo → digital preservation → collection policy → accession record → preservation metadata**.

## 1. preservation standard /ˌprɛzərˈveɪʃən ˈstændərd/
**Part of speech:** noun
**Core meaning (English):** an agreed technical or professional rule for keeping information usable, authentic, and accessible over time.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** rule technical hoặc professional giữ information usable, authentic và accessible lâu dài.
**Grammar & collocations:** `long-term preservation standard` — standard dài hạn; `follow a preservation standard` — tuân theo.
**Examples:** `The archive adopted a preservation standard for video, audio, and interactive stories.` → Archive adopt standard preservation cho video, audio và story interactive.
**Liên kết tiếng Hàn:** `보존 표준`.

## 2. catalog record /ˈkætəlɔɡ ˈrɛkərd/
**Part of speech:** noun
**Core meaning (English):** a structured description that identifies an item in a collection and helps users discover it.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** description có cấu trúc identify item trong collection và giúp user discover.
**Grammar & collocations:** `complete catalog record` — record đầy đủ; `create a catalog record` — tạo.
**Examples:** `The catalog record listed the broadcast date, contributors, language, and duration.` → Record catalog list date broadcast, contributor, language và duration.
**Liên kết tiếng Hàn:** `목록 기록`.

## 3. metadata schema /ˈmɛtəˌdeɪtə ˈskiːmə/
**Part of speech:** noun
**Core meaning (English):** a defined set of fields and rules used to describe, organize, and exchange information about files or objects.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** tập field và rule định nghĩa cách describe, organize và exchange information về file hoặc object.
**Grammar & collocations:** `shared metadata schema` — schema chung; `design a metadata schema` — design.
**Examples:** `A shared metadata schema made records from partner archives searchable together.` → Schema metadata chung làm record từ archive partner search cùng nhau được.
**Liên kết tiếng Hàn:** `메타데이터 스키마`.

## 4. born-digital /ˌbɔrn ˈdɪdʒɪtəl/
**Part of speech:** adjective
**Core meaning (English):** created originally in digital form rather than converted from a physical or analog source.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** được create ngay ở digital form, không convert từ physical hoặc analog source.
**Grammar & collocations:** `born-digital record` — record; `preserve born-digital material` — preserve.
**Examples:** `The collection included born-digital photographs with editing histories and embedded metadata.` → Collection gồm photo born-digital có editing history và metadata embedded.
**Liên kết tiếng Hàn:** `디지털 태생의`.

## 5. archival copy /ɑrˈkaɪvəl ˈkɑpi/
**Part of speech:** noun
**Core meaning (English):** a stable, carefully managed version of a file kept for long-term preservation rather than everyday use.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** version stable, managed cẩn thận để preserve lâu dài, không dùng everyday.
**Grammar & collocations:** `high-resolution archival copy` — copy độ phân giải cao; `store an archival copy` — lưu.
**Examples:** `The producer deposited an archival copy before compressing a smaller version for streaming.` → Producer deposit copy archival trước khi compress version nhỏ để stream.
**Liên kết tiếng Hàn:** `보존용 사본`.

## 6. migration plan /maɪˈɡreɪʃən plæn/
**Part of speech:** noun
**Core meaning (English):** a documented plan for moving files or systems to new formats, platforms, or storage without losing important properties.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** plan document move file hoặc system sang format, platform hoặc storage mới mà không mất property quan trọng.
**Grammar & collocations:** `phased migration plan` — plan theo phase; `approve a migration plan` — duyệt.
**Examples:** `The migration plan scheduled tests before the aging server was retired.` → Plan migration schedule test trước khi server cũ retire.
**Liên kết tiếng Hàn:** `마이그레이션 계획`.

## 7. file format obsolescence /faɪl ˈfɔrmæt ˌɑbsəˈlɛsəns/
**Part of speech:** noun
**Core meaning (English):** the condition in which a digital file format becomes difficult to open, interpret, or maintain because tools or documentation disappear.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** tình trạng format file khó open, interpret hoặc maintain vì tool hoặc documentation biến mất.
**Grammar & collocations:** `risk of file format obsolescence` — risk; `monitor file format obsolescence` — monitor.
**Examples:** `File format obsolescence threatened a collection of interactive election graphics.` → Obsolescence format file đe dọa collection graphic election interactive.
**Liên kết tiếng Hàn:** `파일 형식 노후화`.

## 8. access copy /ˈæksɛs ˈkɑpi/
**Part of speech:** noun
**Core meaning (English):** a user-friendly version of an archival item made available for viewing or listening while the preserved master remains protected.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** version thân thiện cho user view hoặc listen, còn master preserve được bảo vệ.
**Grammar & collocations:** `low-bandwidth access copy` — copy; `stream an access copy` — stream.
**Examples:** `The library offered an access copy so visitors would not handle the fragile original.` → Library offer copy access để visitor không handle original dễ hỏng.
**Liên kết tiếng Hàn:** `이용용 사본`.

## 9. rights clearance /raɪts ˈklɪrəns/
**Part of speech:** noun
**Core meaning (English):** the process of confirming that an organization has permission to preserve, reproduce, display, or distribute material.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** process confirm organization có permission preserve, reproduce, display hoặc distribute material.
**Grammar & collocations:** `complex rights clearance` — clearance phức tạp; `complete rights clearance` — hoàn tất.
**Examples:** `Rights clearance delayed the online release of an interview with three performers.` → Clearance rights trì hoãn online release interview với ba performer.
**Liên kết tiếng Hàn:** `권리 정리`.

## 10. institutional memory /ˌɪnstəˈtuːʃənəl ˈmɛməri/
**Part of speech:** noun
**Core meaning (English):** the knowledge of past decisions, practices, and events retained by an organization and its records.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** knowledge về decision, practice và event past được organization và record giữ lại.
**Grammar & collocations:** `preserve institutional memory` — preserve; `lose institutional memory` — mất.
**Examples:** `The archive preserved institutional memory after the original newsroom team retired.` → Archive preserve memory institutional sau khi team newsroom original retire.
**Liên kết tiếng Hàn:** `조직 기억`.

## 11. archive description /ˈɑrkaɪv dɪˈskrɪpʃən/
**Part of speech:** noun
**Core meaning (English):** an explanatory account of an archival collection, its origin, contents, arrangement, and limits.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** account explain origin, content, arrangement và limit của collection archive.
**Grammar & collocations:** `detailed archive description` — description chi tiết; `publish an archive description` — publish.
**Examples:** `The archive description explained why several broadcasts were missing from the series.` → Description archive giải thích vì sao vài broadcast thiếu trong series.
**Liên kết tiếng Hàn:** `아카이브 기술서`.

## 12. finding aid /ˈfaɪndɪŋ eɪd/
**Part of speech:** noun
**Core meaning (English):** a guide that helps researchers locate and understand materials within an archive.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** guide giúp researcher locate và understand material trong archive.
**Grammar & collocations:** `online finding aid` — guide online; `consult a finding aid` — consult.
**Examples:** `The finding aid grouped the recordings by program, year, and interview subject.` → Finding aid group recording theo program, year và subject interview.
**Liên kết tiếng Hàn:** `검색 도구`.

## 13. digitization backlog /ˌdɪdʒətəˈzeɪʃən ˈbæklɔɡ/
**Part of speech:** noun
**Core meaning (English):** the accumulated collection of physical or analog materials that still need to be converted into digital form.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** collection physical hoặc analog tích lũy vẫn cần convert sang digital.
**Grammar & collocations:** `large digitization backlog` — backlog lớn; `reduce the digitization backlog` — giảm.
**Examples:** `A grant helped the museum reduce its digitization backlog of local newspapers.` → Grant giúp museum giảm backlog digitization của local newspaper.
**Liên kết tiếng Hàn:** `디지털화 적체`.

## 14. preservation repository /ˌprɛzərˈveɪʃən rɪˈpɑzəˌtɔri/
**Part of speech:** noun
**Core meaning (English):** a managed storage environment designed to keep digital objects safe, documented, and usable over time.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** storage environment managed để giữ digital object safe, documented và usable lâu dài.
**Grammar & collocations:** `trusted preservation repository` — repository đáng tin; `deposit files in a preservation repository` — deposit.

**Liên kết tiếng Hàn:** `보존 저장소`.

## 15. authenticity marker /ˌɔθɛnˈtɪsəti ˈmɑrkər/

**Core meaning (English):** a piece of information or technical feature that helps show whether a preserved item is genuine and unchanged.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** information hoặc feature technical giúp cho thấy item preserve là genuine và unchanged.
**Grammar & collocations:** `visible authenticity marker` — marker; `verify an authenticity marker` — verify.

## 16. archival embargo /ɑrˈkaɪvəl ɪmˈbɑrɡoʊ/
**Part of speech:** noun
**Core meaning (English):** a restriction that delays public access to preserved material until an agreed date or condition.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** restriction delay public access đến material preserve cho tới date hoặc condition agreed.
**Grammar & collocations:** `temporary archival embargo` — embargo tạm thời; `lift an archival embargo` — dỡ.
**Examples:** `The archival embargo protected personal letters until the writers' families were consulted.` → Embargo archival bảo vệ letter cá nhân cho tới khi consult family writer.
**Liên kết tiếng Hàn:** `아카이브 공개 유예`.

## 17. digital preservation /ˈdɪdʒɪtəl ˌprɛzərˈveɪʃən/
**Part of speech:** noun
**Core meaning (English):** the continuing management of digital information so that it remains authentic, understandable, and usable in the future.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** management liên tục giữ digital information authentic, understandable và usable trong future.

## 18. collection policy /kəˈlɛkʃən ˈpɑləsi/

**Core meaning (English):** a public statement explaining what an archive collects, why it collects it, and what it excludes.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** statement public explain archive collect gì, vì sao và exclude gì.

## 19. accession record /əkˈsɛʃən ˈrɛkərd/

**Core meaning (English):** a record created when new material enters a collection, documenting its source, date, condition, and ownership.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** record create khi material mới vào collection, document source, date, condition và ownership.
**Grammar & collocations:** `complete accession record` — record đầy đủ; `create an accession record` — tạo.

**Liên kết tiếng Hàn:** `수집 등록 기록`.

## 20. preservation metadata /ˌprɛzərˈveɪʃən ˈmɛtəˌdeɪtə/
**Part of speech:** noun
**Core meaning (English):** technical information that records how a digital object was created, stored, checked, and changed over time.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** technical information record object digital create, store, check và change thế nào.
**Grammar & collocations:** `rich preservation metadata` — metadata phong phú; `capture preservation metadata` — capture.
**Examples:** `Preservation metadata recorded every format conversion and integrity check.` → Metadata preservation record mọi format conversion và integrity check.
**Liên kết tiếng Hàn:** `보존 메타데이터`.

## Review in context

A media archive follows a **preservation standard** when it creates a **catalog record** and applies a shared **metadata schema** to every **born-digital** item. It stores an **archival copy**, writes a **migration plan**, and monitors **file format obsolescence** before offering an **access copy**. **Rights clearance** determines what can be shared, while careful records preserve **institutional memory**. An **archive description** and **finding aid** help users navigate the **digitization backlog** and find material in the **preservation repository**. An **authenticity marker** can support trust, while an **archival embargo** can delay access responsibly. Long-term **digital preservation** follows a **collection policy**, records each **accession record**, and captures **preservation metadata**.

**Bản dịch tiếng Việt:** Media archive tuân theo **preservation standard** khi tạo **catalog record** và áp dụng **metadata schema** chung cho mỗi item **born-digital**. Archive lưu **archival copy**, viết **migration plan** và monitor **file format obsolescence** trước khi cung cấp **access copy**. **Rights clearance** quyết định thứ gì có thể share, còn record cẩn thận preserve **institutional memory**. **Archive description** và **finding aid** giúp user navigate **digitization backlog** và tìm material trong **preservation repository**. **Authenticity marker** support trust, còn **archival embargo** có thể delay access có trách nhiệm. **Digital preservation** dài hạn follow **collection policy**, record mỗi **accession record** và capture **preservation metadata**.
