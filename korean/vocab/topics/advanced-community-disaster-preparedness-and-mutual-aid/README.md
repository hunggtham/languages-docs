# 공동체 재난 대비와 상호부조

재난이 닥친 뒤 기관의 지시만 기다리는 것이 아니라 주민이 위험을 파악하고 서로의 자원과 책임을 연결하는 어휘를 익힌다. 대피 물류나 위기 소통과 겹치지 않도록, 재난 전의 준비와 재난 후의 관계 회복을 중심으로 읽는다.
