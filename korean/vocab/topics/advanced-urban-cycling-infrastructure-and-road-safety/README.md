# 도시 자전거 인프라와 도로 안전

자전거를 취미 장비가 아니라 일상 교통수단으로 보려면 차로, 교차로, 주차와 신호가 서로 어떻게 연결되는지 읽어야 한다. 이 학습 파일은 자전거 이용자를 따로 배려하는 데서 그치지 않고, 모든 도로 이용자가 예측 가능하게 움직이도록 설계하는 말과 안전 운영의 어휘를 다룬다.

## 학습 범위

`news_formal`은 도시교통 계획과 도로 안전 정책을 설명하는 공식 담화에서, `native_spoken`은 이용자와 운영자가 실제 주행 상황을 조율할 때 쓰인다. 시설 명칭만 외우지 않고 차로의 보호 정도, 교차로의 상호작용, 주차와 연결성까지 하나의 이동 경로로 읽는다.
