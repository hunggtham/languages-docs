# 도시 교통 접근성과 길찾기의 언어

도시철도와 버스 환승 공간을 누구나 읽고 이동할 수 있게 만드는 설계 언어를 익힌다. 보행약자의 실제 경로, 촉각·음성 정보, 표지와 공간 인지, 재난 시 유도까지 연결해 접근성을 시설 하나가 아니라 연속된 경험으로 바라본다.

## 학습 파일

- [무장애 동선과 도시 길찾기](./01-accessible-transit-wayfinding.md) — `보행약자`, `무장애동선`, `촉지도`, `음성유도기`, `단차해소`, `유효폭`, `보행연속성`, `표지체계`, `경로안내체계`, `공간인지`, `랜드마크기반안내`, `위치기반안내`, `환승대기공간`, `피난유도`, `승강장연결통로`

## 학습 범위

`news_formal`은 교통약자 이동권, 시설 기준과 도시 설계 보고서에서 쓰인다. 현장 회의와 이용자 테스트에서는 `촉지도`, `음성유도기`, `공간인지`처럼 감각별 경험을 설명하는 말이 중요하다. 좋은 길찾기는 표지판을 많이 붙이는 일이 아니라, `무장애동선`과 `보행연속성`을 끊지 않고 출발지부터 승강장까지 같은 논리로 정보를 이어 주는 일이다.
