# 외모와 첫인상의 언어

얼굴과 분위기를 묘사하는 말, 미적 판단과 성격 평가를 구분하는 말, 첫인상에 대한 고정관념을 점검하는 어휘를 학습한다.

## 학습 파일

- [첫인상과 사람을 읽는 방식](./01-first-impressions-and-character.md) — `관상`, `귀티`, `백치미`, `왜소하다`, `순박하다`, `푸근하다`, `심미안`, `각양각색`, `다채롭다`, `가관`, `건방지다`, `허세`, `기질`, `본성`, `정체성`

각 파일의 읽기 지문은 최대 15개 target headword를 다루며, 외모 묘사와 사람의 가치를 혼동하지 않도록 context를 설계한다.
