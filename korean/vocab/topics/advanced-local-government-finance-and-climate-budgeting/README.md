# 지방재정과 기후예산을 설계하는 언어

지방정부가 세입의 한계와 기후 위험을 함께 계산하면서 어떤 사업에 돈을 배분하는지 살핀다. 예산 편성, 지방채 관리, 재정조정과 기후 성과를 하나의 정책 흐름으로 연결해 행정 문서와 주민 설명회에서 쓰는 말을 익힌다.

## 학습 범위

`news_formal`은 지방재정 운용, 예산 심의와 기후 투자 평가에서 쓰이는 정밀한 공식어다. `native_spoken`은 공무원·주민이 세입 전망과 사업 우선순위를 설명할 때 쓰는 구어적 정책어다. 기존의 일반적인 `기후재정`이나 `탄소예산`보다 지역정부가 실제 예산 주기에서 무엇을 측정하고 책임지는지에 초점을 둔다.
