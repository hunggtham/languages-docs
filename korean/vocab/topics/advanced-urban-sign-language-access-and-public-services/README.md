# 수어 접근과 포용적 공공서비스의 언어

공공서비스는 창구가 열려 있다는 사실만으로 모두에게 이용 가능한 것이 되지 않는다. 이 주제는 수어 사용자와 다양한 의사소통 필요를 가진 주민이 안내, 민원, 재난 정보와 디지털 서비스를 실제로 이용할 수 있게 하는 권리·설계·운영의 언어를 다룬다.

## 학습 범위

`news_formal`은 장애인 권리, 행정 지침, 디지털 접근성 정책과 예산 심의에서 쓰이는 표현을 다룬다. `native_spoken`은 주민, 수어통역사와 기관 직원이 예약·안내·민원을 조정하며 실제로 쓰는 현재의 말이다. 용어를 지원의 시혜로 축소하지 않고, 누구에게 어떤 정보와 의사소통 경로가 막혀 있는지 구체적으로 읽는 데 초점을 둔다.
