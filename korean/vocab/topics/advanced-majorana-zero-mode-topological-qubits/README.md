# 마요라나 제로 모드 및 위상 양자 비트 기술의 언어

마요라나 제로 모드(Majorana zero mode, MZM) 및 위상 양자 비트(topological qubit) 기술은 물질 내부의 비아벨 애니온(non-Abelian anyon) 준입자와 기하학적 위상학(topology)을 융합하여, 외부 환경 노이즈와 결맞음 손실에 근본적으로 면역된 차세대 결함 허용(fault-tolerant) 양자 컴퓨터를 구현하는 첨단 고체물리학 및 양자정보공학 분야입니다. 강한 스핀-궤도 결합을 지닌 반도체 나노와이어와 s-파 초전도체의 이종접합 구조에서 발현되는 마요라나 제로 모드는 공간적으로 분리된 두 끝단에 양자 정보를 비국소적으로 분산 저장함으로써, 국소 전하 요동이나 열적 섭동에 의한 정보 왜곡을 원천 차단합니다. 또한 시공간에서 준입자들을 서로 꼬아 교환하는 브레이딩(braiding) 연산을 통해 기하학적 불변성에 기반한 견고한 양자 논리 게이트를 실현합니다. 본 단원에서는 마요라나 제로 모드 위상 양자 비트, 비아벨 통계 브레이딩, 초전도체-반도체 접합, 키타에프 체인 단일선, 영에너지 모드 피크, 패리티 비파괴 측정, 준입자 중독 차단, 십자형 교차 접합 및 결함 허용 컴퓨터에 이르는 미래 위상 양자 정보 기술의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
