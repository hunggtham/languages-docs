# 계획 이주와 기후 정의

기후 재난으로 생활 터전을 옮겨야 할 때 누가 결정하고, 어떤 권리와 생계를 함께 보장해야 하는지 설명하는 고급 어휘를 학습한다.

## 학습 파일

- [기후 이동의 권리와 공동체 회복](./01-planned-relocation-and-climate-justice.md) — `기후 형평성`, `이주 결정권`, `거주 이전의 자유`, `자유롭고 사전된 동의`, `원주민 영토권`, `공동체 해체`, `장소 기반 회복`, `생계 전환`, `이주 후 빈곤`, `재정착지`, `수용 역량`, `세대 간 전승`, `문화적 연속성`, `비경제적 손실`, `이주 정의`

이 파일은 계획 이주를 단순한 주거 이전이 아니라 권리·참여·생계·문화의 연속성을 함께 설계하는 과정으로 읽게 한다.
