# 위상 절연체 스핀트로닉스와 스핀 궤도 토크의 언어

위상 절연체 스핀트로닉스는 물질 내부의 절연성 고유 특성과 표면의 위상학적으로 보호된 금속성 전도 채널을 활용하여 차세대 전자소자의 에너지 효율과 동작 속도를 극대화하는 최첨단 연구 분야입니다. 특히 스핀-운동량 잠금 특성(Spin-momentum locking)과 비스무트 셀레나이드(Bi₂Se₃) 및 텔루라이드 박막을 통한 거대 스핀 홀 각 구현은 스핀 궤도 토크(SOT) 기반의 초고속 자화 스위칭과 초저전력 스핀소자 구동을 가능하게 합니다. 본 학습 자료에서는 자기터널접합(MTJ) 구조와의 결합, 나노초 이하 자화 스위칭, 상온 위상 스핀 소자 소재, 그리고 차세대 비휘발성 메모리(SOT-MRAM) 및 미래 스핀 기반 컴퓨팅에 이르는 핵심 어휘 15개를 엄선하여 다룹니다.
