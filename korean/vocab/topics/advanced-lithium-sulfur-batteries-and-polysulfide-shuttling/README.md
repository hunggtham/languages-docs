# 리튬황 전지와 폴리설파이드 셔틀 억제의 언어

리튬황 전지는 기존 리튬이온전지를 뛰어넘는 고이론용량과 초경량 특성으로 차세대 항공 모빌리티 및 친환경 에너지 저장 분야에서 큰 주목을 받고 있습니다. 그러나 방전 과정에서 발생하는 폴리설파이드 셔틀 현상과 황의 낮은 전기 전도도로 인해 상용화에 어려움이 있었습니다. 본 단원에서는 황담지 탄소나노복합체, 다기능성 분리막 계면 엔지니어링, 리튬 금속 음극 보호 피막 등 폴리설파이드 셔틀을 효과적으로 억제하고 수명을 연장하기 위한 핵심 기술 어휘와 과학적 표현을 학습합니다.
