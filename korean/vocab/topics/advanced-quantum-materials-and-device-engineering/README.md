# 양자물질과 소자 설계의 언어

전자·스핀·빛의 양자 상태를 재료의 구조와 소자 설계로 연결하는 어휘를 익힌다. 물질의 분류를 외우는 데 그치지 않고, 어떤 성질을 만들고 측정하며 실제 장치로 옮길 때 어떤 한계가 생기는지 설명하는 흐름을 읽는다.

## 학습 범위

`news_formal`은 연구 성과, 소재 국산화, 소자 성능과 상용화 가능성을 과장 없이 설명하는 과학기술 보도의 register다. `native_spoken`은 연구자·공정 엔지니어가 측정 조건, 적층 품질과 설계 타협을 회의에서 풀어 말할 때 자연스럽다. 이 주제에서는 신기한 현상 자체와 재현 가능한 장치 성능을 구분하는 것이 핵심이다.
