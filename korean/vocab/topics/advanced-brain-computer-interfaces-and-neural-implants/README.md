# 뇌 기계 인터페이스와 신경 임플란트의 언어

뇌 기계 인터페이스(BCI)와 신경 임플란트 분야는 대뇌 피질 신호를 초미세 유연 전극으로 정밀하게 기록하고 인공지능으로 해독하여 마비 환자의 운동 기능을 재건하는 최첨단 융합 과학 기술입니다. 본 단원에서는 양방향 통신, 신경 교세포 염증 반응 최소화, 장기 체내 안정성 확보 등 차세대 신경공학 플랫폼 구축에 필요한 핵심 전문 어휘를 학습합니다.

- [초미세 유연 신경 전극 기반 피질 다채널 신호 기록 및 양방향 신경 인터페이스 기술](./01-brain-computer-interfaces-and-neural-implants.md) — 양방향뇌기계인터페이스, 초미세유연신경전극, 생체적합성신경임플란트, 피질내다채널신호기록, 국소장전위실시간해독, 인공지능신경신호디코딩, 신경교세포염증반응최소화, 양방향신경자극피드백, 무선전력통신두개내이식, 운동의도실시간추정, 마비환자신체기능재건, 신경가소성촉진재활, 비침습침습융합모니터링, 장기체내안정성확보, 차세대신경공학플랫폼

본 단원의 어휘들은 고도화된 신경과학 연구 및 임상 논문, 최신 공학 기술 보고서에서 빈번하게 사용되는 고급 전문 용어입니다.
