# 지리공간 분석과 도시 감지의 언어

지도 위에 점을 표시하는 데서 멈추지 않고, 위치·축척·센서 자료가 도시의 불평등과 환경 변화를 어떻게 드러내는지 읽는다. 정책 보고서와 연구자 대화에서 공간 자료의 구조, 오차, 해석 범위를 정확히 말하는 어휘를 연결한다.

## 학습 범위

`news_formal`은 도시계획, 재난 대응, 환경 감시와 공공 데이터 보고서에서 공간 자료의 근거와 한계를 설명할 때 쓰인다. `native_spoken`은 분석가와 현장 담당자가 지도·센서·모델 결과를 검토하며 “어디에서 어떤 패턴이 보이는가”를 풀어 말할 때 자연스럽다. 같은 수치라도 공간 단위와 해상도가 달라지면 결론이 달라질 수 있으므로, 위치를 곧 원인으로 단정하지 않는 태도까지 함께 익힌다.
