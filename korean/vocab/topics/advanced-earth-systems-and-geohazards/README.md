# 지질 재해와 지표 변화의 어휘

지진·화산·지반 변형을 한 가지 원인으로 단정하지 않고, 판의 움직임과 지표에서 관찰되는 징후를 연결해 읽는다. 이 주제는 과학·재난 보도에서 쓰는 전문어와 주민이 도로와 비탈의 위험을 제보할 때 쓰는 현재형 표현을 함께 다룬다.

## 학습 파일

- [지질 재해와 지표 변화의 언어](./01-geological-hazards-and-surface-change.md) — `판구조론`, `섭입대`, `단층대`, `지진파`, `화산쇄설류`, `마그마방`, `침강`, `융기`, `풍화작용`, `침식지형`, `액상화`, `지반침하`, `사면붕괴`, `싱크홀`, `포트홀`

## 학습 범위

`news_formal`은 판 경계, 화산·지진 위험, 지형 형성과 기반시설 안전을 분석하는 과학·재난 보도의 register다. `native_spoken`은 주민 신고, 도로 순찰과 안전 안내에서 `싱크홀`과 `포트홀`을 구별해 말할 때 자연스럽다. 지질 과정의 이름을 안다고 위험이 자동으로 예측되는 것은 아니므로, 관측 자료와 현장 조건을 함께 읽는 것이 핵심이다.
