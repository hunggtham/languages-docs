# 메타표면 편광 제어와 풀 스톡스 이미징의 언어

이 단원에서는 메타표면 편광 제어 렌즈(metasurface polarization control lens), 단일샷 풀 스톡스 편광 이미징(single-shot full-Stokes polarization imaging), 이방성 나노기둥 위상 지연(anisotropic nanopillar phase delay), 초박형 편광 카메라 모듈(ultrathin polarization camera module), 원편광 및 선형편광 동시 검출(circular and linear polarization simultaneous detection), 안개와 눈부심 속 자율주행 시각 센서(autonomous driving vision in dense fog and glare), 생체 조직 편광 현미경 소자(biomedical tissue polarization microscopy), 그리고 광학 위조 방지 기술(optical anticounterfeiting) 등 최첨단 나노광학 및 편광 이미징 분야의 전문 어휘를 다룹니다.
