# 대기의 흐름과 극한 날씨를 읽는 언어

날씨는 하루의 기분을 말하는 데서 끝나지 않고 대기의 흐름, 복사와 도시 구조가 위험의 규모를 바꾸는 과정을 보여 준다. 이 주제는 기상 분석과 기후 보도에서 관측 사실, 물리적 원인과 정책적 대응을 구분해 말하는 한국어를 다룬다.

## 학습 범위

`news_formal`은 예보, 기후 연구와 재난 정책에서 원인과 불확실성을 정밀하게 말할 때 쓰인다. `native_spoken`은 일기예보를 듣거나 주민에게 위험을 설명할 때 전문 개념을 일상적인 말로 풀어내는 lane이다. 특정 현상을 단순히 “이상하다”고 부르기보다 대기 구조, 관측 근거와 사회적 노출을 함께 읽는 것이 핵심이다.
