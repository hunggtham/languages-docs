# 지역 에너지 저장과 수요반응의 운영 언어

지역에서 생산한 전기를 저장하고 소비 시간을 조절하는 과정에서 주민·사업자·계통운영자가 어떤 선택을 하는지 읽는다. 기술 용어만 나열하지 않고 비용, 참여, 보상과 전력망 안정성이 한 운영 모델에서 어떻게 맞물리는지 살핀다.
