# 몸의 증상과 움직임

질병과 치료, 피부와 신체 감각, 추위와 운동에서 나타나는 미세한 움직임을 한 흐름으로 익힌다.

## 학습 파일

- [몸의 신호를 읽고 움직임을 조절하다](./01-symptoms-and-movement.md) — `합병증`, `구충제`, `축농증`, `건식`, `치골`, `귓불`, `물방울`, `후들거리다`, `벌렁거리다`, `펄럭`, `팔짝`, `묵직하다`, `팍팍`, `칼바람`, `격투`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 의학적 정보와 감각 묘사를 혼동하지 않도록 context를 분리한다.
