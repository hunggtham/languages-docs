# 공급망 인권 실사와 책임 있는 조달

기업이 제품을 싸고 빠르게 사 오는 데서 멈추지 않고, 공급망의 노동권 위험을 발견하고 줄이며 피해를 실제로 구제하는 흐름을 읽는 어휘를 익힌다.

## 학습 파일

- [공급망 인권 실사의 전 과정](./01-supply-chain-human-rights-due-diligence.md) — `공급망 투명성`, `인권 위험 식별`, `인권 영향 평가`, `실사 의무`, `책임 있는 조달`, `강제노동`, `현대판 노예제`, `노동 착취`, `간접고용`, `원청 책임`, `납품단가 후려치기`, `고충 처리`, `구제 접근성`, `보복 금지`, `노동자 목소리`

위험을 협력업체의 일탈로만 돌리지 않고, 구매 관행·계약 구조·신고 채널을 바꾸어 노동자의 권리를 공급망 운영에 넣는 과정을 한 기업의 조달 회의와 현장 조사 흐름으로 보여 준다.
