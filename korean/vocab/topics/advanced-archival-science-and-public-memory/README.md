# 기록과 공공 기억의 보존 언어

기록을 단순한 문서 묶음이 아니라 생산 맥락과 권리, 기억의 관계로 읽는다. 행정 기록과 디지털 자료를 어떤 기준으로 남기고 설명할지, 그리고 시민의 목소리를 공공 기억으로 연결할 때 필요한 전문어를 익힌다.

## 학습 범위

`news_formal`은 기록관리 정책, 행정 투명성, 역사 연구와 보존 기준을 정밀하게 설명하는 공식 register다. `native_spoken`은 기록관 해설, 시민 구술 프로젝트와 자료 기증 상담에서 전문어를 풀어 말할 때 자연스럽다. 기록의 가치는 오래 보관하는 데만 있지 않고 누가 어떤 맥락에서 만들었는지 추적할 수 있는 데에도 있다.
