# 토양의 기능을 회복하고 황폐한 땅을 되살리는 언어

토양은 식물을 지지하는 흙만이 아니라 물, 탄소, 미생물과 오염물질이 서로 작용하는 살아 있는 환경이다. 이 주제는 농업·환경 보도와 복원 현장에서 토양의 상태를 진단하고, 훼손 원인을 구분하며, 회복 방법을 설명할 때 필요한 고급 어휘를 연결한다.

## 학습 범위

`news_formal`은 토지 황폐화, 오염 정화, 기후 적응과 복원 정책을 근거에 맞게 보고할 때 쓰인다. `native_spoken`은 농민, 현장 기술자와 연구자가 흙의 상태와 관리 작업을 설명할 때 들을 수 있는 전문 구어 register다. 토양 문제는 눈에 보이는 표면만으로 단정하지 않고 수분, 공극, 생물 활동과 오염의 깊이를 함께 확인해야 한다.
