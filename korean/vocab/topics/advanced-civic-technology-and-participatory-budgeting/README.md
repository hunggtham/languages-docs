# 시민기술과 참여예산의 언어

디지털 도구가 시민의 의견을 모으는 데서 멈추지 않고 예산의 우선순위와 집행 책임을 어떻게 바꾸는지 읽는다. 참여의 숫자만 세지 않고 숙의의 질, 대표성, 접근 격차, 정책 환류까지 함께 판단하는 어휘를 익힌다.

## 학습 파일

- [시민이 예산을 함께 설계하고 검증하다](./01-civic-technology-and-participatory-budgeting.md) — `참여예산제`, `숙의민주주의`, `시민배심원제`, `숙의공론장`, `주민제안사업`, `예산편성권`, `재정분권`, `온라인주민총회`, `주민발안`, `정책환류`, `참여격차`, `대표성왜곡`, `주민체감도`, `투표쏠림`, `시민참여플랫폼`

## 학습 범위

`news_formal`은 지방재정, 제도 설계와 공공 데이터의 책임을 보도하거나 심사할 때 쓰이는 공식어다. `native_spoken`은 주민회의와 제품 검토에서 참여 장벽, 투표 분위기와 실제 체감 효과를 풀어 말할 때 나타난다. 이 lesson은 클릭 수를 시민 권한으로 착각하지 않고, 누가 말할 수 있었으며 그 의견이 예산 결정과 집행에 어떻게 이어졌는지 추적하는 읽기 습관을 연습한다.
