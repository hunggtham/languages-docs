# 자율무인잠수정과 해저 군집 탐사의 언어

대양의 심해는 극심한 수압과 전자기파 차단, 절대적인 암흑이 지배하는 극한의 미개척 영역이다. 자율무인잠수정(AUV)과 해저 군집 로봇 기술의 발전은 인간의 직접 개입이 불가능했던 수천 미터 심해를 스스로 탐색하고 해저 인프라를 지능적으로 관리하는 새로운 시대를 열었다. 이 주제는 다중 잠수정 간의 분산형 군집 협업, 수중 음향 통신과 무인 도킹 기지, 초고해상도 소나 및 광학 영상 기술, 그리고 극한 수압을 견디는 기계 역학적 제어 시스템에 이르는 첨단 심해 공학의 핵심 어휘를 심층적으로 탐구한다.
