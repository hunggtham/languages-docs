# 합성생물학과 바이오 안보의 언어

생물학적 시스템을 설계하고 생산 플랫폼으로 옮기는 과정에서 안전과 보안을 함께 판단하는 어휘를 익힌다. 기술의 가능성만 말하지 않고, 이중용도 위험과 연구 단계별 통제까지 읽는다.
