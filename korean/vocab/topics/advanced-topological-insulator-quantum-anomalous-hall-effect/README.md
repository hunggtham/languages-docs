# 양자 이상 홀 효과와 무손실 위상 전도의 언어

양자 이상 홀 효과(Quantum Anomalous Hall Effect, QAHE)는 외부 자기장 인가 없이도 물질 내부의 자화와 강한 스핀-궤도 상호작용에 의해 영자기장 상태에서 양자화된 홀 저항을 나타내는 현대 응집물질물리학의 핵심 현상입니다. 이 토픽에서는 무손실 카이랄 에지 전도 채널(chiral edge conduction channels), 자기 위상 절연체 이종접합(magnetic topological insulator heterostructures), 크롬/망간 도핑 위상 박막(chromium/manganese-doped topological films), 그리고 위상 불변성(topological invariance)을 기반으로 한 차세대 저손실 양자 소자, 양자 도량형 표준 저항계측(metrological resistance standards), 극저온 양자 컴퓨팅 인터커넥트(cryogenic quantum interconnects)의 전문 어휘를 심도 있게 학습합니다.
