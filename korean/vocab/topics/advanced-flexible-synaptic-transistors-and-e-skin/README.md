# 유연 시냅스 트랜지스터와 전자 피부의 언어

유연 시냅스 트랜지스터와 전자 피부(e-skin) 분야는 인간의 생체 촉각 신경계와 유연 전자공학을 융합하여 차세대 웨어러블 및 로봇 공학의 혁신을 이끄는 첨단 학문 영역입니다. 단기 및 장기 시냅스 가소성(STP/LTP)을 모사하는 생체적합성 유기 반도체막, 초저전력 시냅틱 가중치 제어, 이온젤 게이트 절연층 공정 등을 통해 생체 신호를 실시간으로 처리합니다. 또한 다감각 통합 신경모사 소자, 피부 밀착형 압력 센서 어레이, 신경모방 신경망 패치, 생체 이식형 소프트 전자 소자 등을 결합하여 로봇 인공 촉각 감각 피부와 지능형 생체 모방 센싱 소자의 구현을 가능하게 합니다.
