# 농촌 물 협동조합과 기후 회복력을 읽는 말

가뭄과 집중호우가 반복되는 농촌에서 주민이 물을 공동으로 관리하고 급수 체계를 회복하는 과정을 읽는다. 협동조합의 운영, 농업용수 배분, 수질 점검과 비상계획을 연결하는 정책·현장 어휘를 익힌다.
