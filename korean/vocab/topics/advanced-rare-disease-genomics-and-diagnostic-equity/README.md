# 희귀질환 유전체 진단과 접근성의 언어

희귀질환을 의심한 뒤 유전체 검사를 선택하고 결과를 해석해 진료로 연결하는 흐름을 읽는다. 검사 기술만이 아니라 진단 지연, 지역·소득에 따른 접근성, 환자와 가족에게 결과를 설명하는 책임까지 함께 다룬다.

이 주제는 “검사에서 변이가 보였다”와 “환자의 진단이 확정됐다”를 구별하면서, 검사 기회와 결과 설명의 불평등이 어떻게 진단 결과에 영향을 주는지 보여 준다.
