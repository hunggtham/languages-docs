# 이온토포레시스 및 역이온토포레시스 기반 경피 시스템의 언어

이온토포레시스(iontophoresis) 및 역이온토포레시스(reverse iontophoresis) 기술은 피부 표면에 인체에 안전한 미세 직류 또는 펄스 전류를 인가하여, 전기적 반발력과 전기삼투 흐름(electroosmotic flow)을 통해 약물 분자를 피부 각질층 너머로 통증 없이 주입하거나 반대로 피부 진피층의 간질액(interstitial fluid) 속 포도당, 젖산 등 핵심 생체 대사 물질을 비침습적으로 체외 추출하여 분석하는 첨단 바이오메디컬 전자약(electroceuticals) 및 스마트 센싱 융합 공학 분야입니다. 주사 바늘의 공포와 감염 위험 없이 당뇨 환자의 혈당을 24시간 실시간 모니터링하고 인슐린을 자동 투여하는 폐루프(closed-loop) 인공 췌장 시스템의 핵심 하드웨어를 제공합니다. 본 단원에서는 경피 이온 수송, 전기삼투 추출, 피부 자극 최소화 펄스 전류, 하이드로겔 이온 저장소, 전극 분극 제어 및 폐루프 약물 전달망에 이르는 첨단 생체 이온토포레시스 공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
