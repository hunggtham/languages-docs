# 디지털 형식 노후화와 보존

파일을 저장했다고 해서 그 파일을 미래에도 읽을 수 있는 것은 아니다. 이 주제는 소프트웨어와 저장 매체가 바뀌어도 디지털 기록의 내용, 맥락과 진본성을 유지하는 보존 실무를 다룬다.

## 학습 범위

`news_formal`은 공공기관과 기록관리 정책에서 형식의 수명, 접근권과 책임을 설명할 때 쓰인다. `native_spoken`은 기록관리자와 시스템 담당자가 파일을 옮기고 검증하는 실무 대화에서 자연스럽다. 파일을 다른 형식으로 바꾸는 것과 원본의 의미·무결성을 보존하는 일은 서로 다르므로 두 층위를 함께 익힌다.
