# 공동체 물 감시와 누수 저감

수도망의 누수와 수질 문제는 전문 기관만의 일이 아니다. 주민이 이상 징후를 기록하고, 운영기관이 계량·수압·관망 자료를 연결해 우선순위를 정할 때 물을 아끼면서도 안전한 급수를 유지할 수 있다. 이 주제는 공동체 모니터링, 누수 탐지, 관망 운영과 물 절약 약속을 함께 읽는 고급 어휘를 다룬다.
