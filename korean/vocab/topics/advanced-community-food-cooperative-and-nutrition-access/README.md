# 공동체 먹거리 협동조합과 영양 접근을 말하는 언어

공동체 먹거리 협동조합은 식품을 싸게 나누는 조직에만 머물지 않고, 주민이 필요한 먹거리와 영양에 접근하도록 구매·돌봄·교육·지역 계획을 연결하는 생활 인프라다. 이 묶음은 시장 가격과 공급망의 언어를 넘어, 누가 건강한 식품을 선택할 수 있는지와 공동체가 어떤 방식으로 격차를 줄이는지를 설명하는 어휘에 초점을 둔다.

## 학습 파일

## 학습 범위

`news_formal`은 지방정부·복지기관·사회적경제 조직이 먹거리 접근과 영양 격차를 평가하고 정책을 설계할 때 쓰인다. `native_spoken`은 조합원 회의, 공동구매, 식사 지원과 교육 현장에서 필요한 것을 설명할 때 자연스럽다. 개인의 선택만 탓하지 않고 가격·교통·돌봄·정보의 조건을 함께 말하는 연습을 한다.
