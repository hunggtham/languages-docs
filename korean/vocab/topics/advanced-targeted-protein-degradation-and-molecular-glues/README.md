# 표적 단백질 분해와 분자 접착제의 언어

표적 단백질 분해(Targeted Protein Degradation, TPD)와 분자 접착제(Molecular Glue) 기술은 기존 저해제 중심의 신약 개발 패러다임을 근본적으로 전환하는 최첨단 생명공학 및 의약화학 분야이다. 세포 내 고유한 유비퀴틴-프로테아좀 시스템(UPS)을 유도하여 질병 원인 단백질을 선택적으로 완전히 제거함으로써, 기존 합성의약품으로는 접근이 불가능했던 미충족 의료 수요의 난치성 질환과 약물 내성 돌연변이를 극복하는 전략이 이 분야의 핵심을 이룬다. 본 주제에서는 프로탁(PROTAC) 키메라 분자의 삼원 복합체 형성 기전부터 E3 리가아제 결합 모티프, 표적 단백질의 유비퀴틴화, 단백질 구조 기반 설계 및 체내 약동학적 최적화에 이르는 첨단 신약 개발 전문 어휘를 체계적으로 학습한다.
