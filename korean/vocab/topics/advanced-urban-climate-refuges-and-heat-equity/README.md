# 도시 기후 피난처와 열 형평성의 언어

도시의 폭염 대응은 냉방 시설을 몇 개 더 설치하는 데서 끝나지 않는다. 누가 더 오래 열에 노출되는지, 누가 비용과 거리 때문에 냉방을 이용하지 못하는지, 공공공간과 주거의 열환경을 어떻게 바꿀지까지 살펴야 한다. 이 주제는 기후 피난처를 설계하고 열 형평성을 평가할 때 쓰는 정책·현장 어휘를 하나의 생활권 상황으로 묶는다.

## 학습 범위

`news_formal`은 기후 정의, 도시계획과 복지 예산을 평가하는 공식 담화에 쓰인다. `native_spoken`은 주민이 더위를 피할 장소, 전기요금 부담과 집 안의 열기를 이야기할 때 자연스럽다. 장소를 하나 마련했다는 사실보다 실제 이동 가능성, 운영 시간, 주거의 단열과 냉방 비용을 함께 보아야 열 형평성을 논할 수 있다.
