# 고분자 순환성과 화학적 재활용의 언어

플라스틱 순환은 폐기물을 녹이는 한 단계의 기술로 끝나지 않는다. 고분자의 구조와 첨가제, 오염 정도, 공정의 에너지와 원료 수율을 함께 살펴야 실제로 자원이 다시 생산 체계에 들어오는지 판단할 수 있다. 이 주제는 소재과학 기사와 재활용 산업의 정책 담화에서 그 차이를 읽는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 소재 공학, 재활용 설비와 환경 규제의 기사·보고서에서 쓰인다. `native_spoken`은 연구자, 공정 담당자와 기업 실무자가 재생 원료의 품질과 비용을 설명하는 대화에서 들을 수 있다. 같은 ‘재활용’이라도 분자 구조를 되돌리는지, 단순히 형태를 바꾸는지, 실제로 다시 투입할 원료가 얼마나 남는지를 구분하는 것이 핵심이다.
