# 종교·영성과 세속사회의 언어

종교를 개인의 믿음에만 가두지 않고 세속화, 종교다원주의, 공적 중립과 공동체의 언어로 읽는다. 서로 다른 신앙과 무종교의 삶이 만나는 자리에서 권리와 편견, 영성을 어떻게 구별해 말하는지 익힌다.
