# 원격진료와 디지털 헬스의 운영 언어

원격으로 환자를 관찰하고 디지털 의료기술을 평가할 때 필요한 데이터·임상·사용자 경험의 표현을 익힌다.

## 학습 초점

이 lesson은 기술이 있다는 사실과 실제 진료에 안전하게 쓰인다는 사실을 구별한다. 데이터가 어디서 생기고 누구에게 공유되는지, 알고리즘의 성능이 어떤 환경에서 흔들리는지, 환자와 의료진이 어떤 방식으로 결과를 확인하는지를 함께 읽는다. 정책·병원 운영 문맥의 표현과 환자가 일상적으로 쓰는 표현을 한 흐름 안에서 비교한다.
