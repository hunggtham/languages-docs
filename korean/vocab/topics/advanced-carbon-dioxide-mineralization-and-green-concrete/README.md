# 이산화탄소 광물화와 친환경 그린 콘크리트의 언어

이 토픽은 기후 변화 대응과 탄소 중립을 위한 핵심 혁신 기술인 **이산화탄소 광물화(CO2 Mineralization)**와 **친환경 그린 콘크리트(Green Concrete)** 분야의 전문 어휘를 다룹니다. 산업 배출가스 속의 탄소를 포집하여 영구적으로 광물 형태로 고정하고, 시멘트 사용량을 획기적으로 줄이며 산업 부산물을 재활용하는 최신 건설 재료 공학의 학술·기술적 용어를 체계적으로 학습할 수 있습니다.
