# 맹그로브 복원과 블루카본의 언어

맹그로브 복원은 묘목을 심는 일만으로 끝나지 않는다. 조석이 드나드는 수문 조건, 염분과 담수의 균형, 뿌리 아래 퇴적물의 탄소·황 순환을 함께 회복해야 한다. 이 lesson은 현장 조사와 정책 보고서에서 복원 성과와 기후 효과를 과장하지 않고 설명하는 어휘를 다룬다.

## 학습 범위

`news_formal`은 연안 복원 정책, 블루카본 산정과 기후 적응 보고서에서 수치와 인과관계를 정밀하게 말할 때 쓰인다. `native_spoken`은 현장 조사·주민 협의에서 “물을 다시 통하게 한다”, “뿌리 밑에 탄소가 쌓인다”처럼 전문 개념을 실제 관리 선택과 연결할 때 자연스럽다. 탄소 저장량만 강조하지 않고 온실가스의 상쇄 효과, 퇴적 안정성과 장기 침수 위험을 함께 판단한다.
