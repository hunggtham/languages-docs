# 리튬 배터리 안전과 재활용

리튬 배터리는 전기차와 저장장치의 핵심 부품이지만, 안전한 사용과 폐기 이후의 회수까지 하나의 물질 흐름으로 보아야 한다. 이 주제에서는 셀의 이상 징후를 진단하고 열·전기 위험을 통제하는 말, 그리고 사용후 배터리를 방전·해체·분류해 재사용 또는 재활용으로 보내는 공정어를 연결해 읽는다. 높은 회수율만 강조하지 않고, 사고 예방·추적성·회수물의 품질과 다음 사용처까지 함께 판단하도록 구성했다.

## 학습 범위

`news_formal`은 전기차 배터리 안전 규정, 사고 조사, 자원순환 정책과 재활용 산업을 분석하는 공식·전문 register다. `native_spoken`은 배터리 공장·정비 현장·재활용 업체 회의에서 이상 징후와 처리 순서를 조율할 때 쓰이는 실무 표현이다. 같은 배터리라도 사용 가능한 모듈을 곧바로 파쇄하지 않고 진단 결과에 따라 재사용·재활용·안전 폐기로 나누는 판단의 흐름에 초점을 둔다.
