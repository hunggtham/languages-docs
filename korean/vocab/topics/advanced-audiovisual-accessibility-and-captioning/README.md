# 영상 접근성과 자막 제작의 언어

영상의 의미를 소리와 화면에만 맡기지 않고, 자막·수어·화면해설로 다시 설계하는 실무 언어를 익힌다. 제작자가 품질을 점검하는 말과 당사자의 정보 접근권을 설명하는 말을 함께 읽는다.

## 학습 범위

`news_formal`은 정보 접근권, 방송 정책과 제작 기준을 정밀하게 말할 때 쓰인다. 제작 현장과 자막 회의에서는 `자막 동기화`, `타임코드`, `자막 검수`처럼 작업의 순서와 책임을 드러내는 표현이 중요하다. `농인`과 `난청인`은 당사자의 정체성과 청각 조건을 함부로 한데 묶지 않도록 구별하고, `비언어적 단서`와 `청각정보`는 대사 밖의 의미까지 접근성 설계에 포함한다.
