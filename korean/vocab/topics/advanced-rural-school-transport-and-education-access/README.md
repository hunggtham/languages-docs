# 농촌 학교 통학과 교육 접근성

농촌 학생이 학교에 도착하기까지 필요한 차량, 환승, 안전과 지역 협력을 함께 읽는 어휘를 익힌다. 거리가 멀다는 사실만 세는 것이 아니라 통학 부담과 교육 기회의 차이를 어떻게 줄이는지 살펴본다.
