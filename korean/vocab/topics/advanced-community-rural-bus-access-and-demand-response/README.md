# 농촌 버스 접근과 수요응답 교통

농촌 마을에서 버스가 사라지거나 너무 드물게 다닐 때, 주민의 이동을 어떤 공공 서비스로 이어 갈지 읽는 어휘다. 고정 노선, 호출, 재정 보전과 이동권을 하나의 운영 문제로 연결한다.

## 학습 범위

`news_formal`은 지방교통계획, 예산, 조례와 공공 서비스의 책임을 다루는 공식 담화다. `native_spoken`은 주민이 예약과 배차, 실제 불편을 말하는 현장 표현을 보탠다. 이미 있는 도시 이동권·일반 교통정책 자료와 달리, 이 파일은 인구가 흩어진 농촌에서 고정 노선과 호출 서비스를 어떻게 함께 설계하는지에 초점을 둔다.
