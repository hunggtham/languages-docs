# 도시 건물 개보수와 열펌프의 언어

노후 건물을 고치는 일은 외벽을 새로 칠하는 수준을 넘어, 열이 새는 경로와 설비가 실제로 반응하는 방식을 다시 설계하는 일이다. 이 주제에서는 건물 외피, 환기, 저온 난방과 열펌프의 성능을 연결해 읽는다.

## 학습 범위

`news_formal`은 건물 에너지 정책, 성능 기준과 개보수 사업을 설명할 때 쓰인다. `native_spoken`은 설비 업체와 관리자가 실제 운전, 소음과 비용을 조율할 때 자연스럽다. 핵심은 열펌프를 단독 기기로 외우는 것이 아니라, 외피의 열손실을 줄이고 낮은 온도의 난방수와 저장·계약 구조를 함께 맞추는 시스템으로 이해하는 데 있다.
