# 대화와 공적 담화의 결

가벼운 대화와 공식 발언, 직설적인 평가와 신중한 설명을 구분하는 표현을 학습한다.

## 학습 파일

- [말의 온도와 설명의 책임](./01-conversation-and-discourse.md) — `잡담하다`, `한담`, `멘트`, `대놓고`, `팩폭`, `부연`, `진중하다`, `메아리`, `다분하다`, `염두에 두지 않다`, `장황하다`, `섣부르다`, `정석`, `막연하다`, `예견`
- [정책 정당성과 거버넌스의 언어](./02-policy-legitimacy-and-governance.md) — `거버넌스 공백`, `이해 상충`, `의제 설정`, `제도적 관성`, `구조적 취약성`, `정책 실험`, `정책 정당성`, `제도 설계`, `공공성 회복`, `정책 피로감`, `조정 실패`, `현장 집행력`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 말투의 register와 발언이 낳는 사회적 효과를 함께 보여 준다.
