# 홍수 위험과 유역 거버넌스

집중호우를 단순한 자연재해로 보지 않고, 유역의 물 흐름과 도시의 취약성, 하천·토지 이용·주민 참여를 함께 조정하는 정책 언어를 익힌다. 기술 지표를 읽는 법과 주민에게 위험을 설명하는 방식을 한 흐름으로 연결한다.
