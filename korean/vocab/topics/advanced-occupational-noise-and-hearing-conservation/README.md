# 직업성 소음과 청력보존의 언어

작업장에서 반복되는 소리 노출이 청력에 미치는 부담을 측정하고, 설비·운영·교육을 함께 바꾸어 청력을 보존하는 어휘를 익힌다. 개인에게 보호구만 떠넘기지 않고 소음원과 작업 방식, 검사를 연결해 예방의 책임을 읽는다.

## 학습 범위

`news_formal`은 노출 평가, 기준청력과 청력역치 변화, 공학적 저감과 행정적 통제처럼 산업보건 정책·감독에서 쓰이는 언어를 다룬다. `native_spoken`은 현장에서 보호구가 맞는지 확인하고 검사 결과를 알리며 기록을 남기는 실무 판단을 다룬다. 단순히 귀마개를 나누어 주는 것이 아니라 측정, 설계, 교육과 후속 조치를 하나의 청력보존 체계로 읽는 데 초점을 둔다.
