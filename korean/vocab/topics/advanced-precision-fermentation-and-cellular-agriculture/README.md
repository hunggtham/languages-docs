# 정밀 발효와 세포 농업의 언어

인류의 식량 생산 체계는 기후위기, 자원 고갈, 생명윤리라는 중대한 도전에 직면하여 근본적인 패러다임 전환을 맞이하고 있다. 동물을 직접 사육하여 도축하던 전통 농축산업에서 벗어나, 미생물의 유전체를 정밀하게 재설계하여 유용한 표적 단백질을 합성하는 정밀 발효(Precision Fermentation)와 줄기세포를 바이오리액터에서 증식·분화시켜 실제 육류 조직을 구현하는 세포 농업(Cellular Agriculture)은 미래 지속가능한 먹거리 혁신의 양대 축으로 부상했다.

본 주제에서는 대체단백질원의 발굴에서부터 무혈청 배양 배지 최적화, 조직공학적 3차원 지지체 설계, 대용량 바이오리액터 스케일업과 정밀 세포 수확에 이르는 상·하공정 전반의 핵심 기술 어휘를 다룬다. 아울러 신소재 식품의 규제 승인을 위한 안전성 평가와 축산업의 온실가스 배출을 획기적으로 줄이기 위한 환경성 지표까지 아우르는 정밀한 고급 한국어 표현 체계를 학습한다.
