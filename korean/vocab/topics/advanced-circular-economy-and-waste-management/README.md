# 자원을 되돌리고 폐기물의 끝을 설계하는 언어

쓰레기 문제는 버리는 순간 끝나는 일이 아니라 생산, 소비, 회수와 처리 시설이 이어지는 순환의 문제다. 이 주제는 환경 보도와 현장 대화에서 폐기물을 줄이고 다시 자원으로 돌리는 과정, 그리고 그 과정의 비용과 책임을 말할 때 필요한 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 순환경제 정책, 처리 기술, 환경 기준과 시설 운영을 보도하거나 분석할 때 쓰인다. `native_spoken`은 소비자가 물건의 두 번째 생명과 보증금 제도를 이야기하거나, 재사용 사업의 장단점을 설명할 때 들을 수 있는 말이다. 재활용을 무조건 좋은 결과로 단정하지 않고, 어떤 물질이 어떤 경로를 거쳐 다시 쓰이는지와 처리 부담이 어디로 이동하는지를 함께 읽는 것이 핵심이다.
