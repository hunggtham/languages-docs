# 도시의 밤과 공공공간 안전

도시가 밤에도 활력을 유지하면서 주민·상인·방문객의 안전과 보행자우선도로를 함께 보장하는 데 필요한 정책·현장 어휘를 익힌다.

## 학습 파일

- [야간경제와 공공공간 안전](./01-nighttime-economy-and-public-space-safety.md) — `야간경제`, `심야상권`, `야간경관`, `안심귀갓길`, `범죄예방환경설계`, `가로활성화`, `취약시간대`, `치안공백`, `안전사각지대`, `스마트폴`, `유흥밀집지역`, `유휴공간`, `야간노동`, `지역안전지수`, `보행자우선도로`

이 파일의 지문은 도시계획·상권 운영·주민 안전이 충돌하고 조정되는 한 장면을 통해 15개 target을 자연스럽게 연결한다.
