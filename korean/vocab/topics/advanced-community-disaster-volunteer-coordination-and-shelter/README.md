# 재난 현장의 자원봉사와 공동체 쉼터

재난 직후 주민과 자원봉사자가 대피·물자·안부 확인·쉼터 운영을 함께 조정할 때 필요한 고급 어휘를 익힌다. 기관의 일반적인 재난 대응보다 현장에서 사람과 자원을 연결하고, 취약한 사람의 안전과 존엄을 지키는 협업에 초점을 둔다.

## 학습 범위

재난자원봉사, 대피소운영, 임시거처, 수용능력, 구호물자배분, 자원봉사배치, 현장지휘, 대피동선, 취약계층대피, 안부확인망, 쉼터연계, 재난약자, 자원봉사교대, 심리응급지원, 귀가지원을 다룬다. 재난 위험 일반론이나 응급의학 어휘를 반복하지 않고, 지역 공동체가 실제 대피소를 운영하며 자원봉사자를 조정하는 데 필요한 표현을 골랐다.
