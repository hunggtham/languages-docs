# 스핀트로닉 멤리스터와 뉴로모픽 크로스바의 언어

본 주제는 전자의 전하와 스핀 각운동량을 동시에 활용하는 스핀트로닉 멤리스터(Spintronic Memristor)와 자기터널접합(MTJ) 크로스바 어레이, 자성 자벽 이동(Domain-Wall Motion) 기반 시냅스 소자 등 차세대 뇌신경 모사 인메모리 컴퓨팅 기술을 다루는 전문 어휘 모음입니다. 생체 시냅스의 장기 강화 및 억제 등 가소성 학습 규칙 모사, 다중 레벨 저항 상태 제어, 아날로그 시냅스 가중치 갱신, 스핀토크 유도 자화 반전을 통한 초저전력 비휘발성 시냅스 메모리 어레이 구현 원리를 체계적으로 다룹니다. 나아가 확률 비트(p-bit) 기반 확률적 컴퓨팅 스핀 소자와 칩 내부에서 직접 인공신경망을 학습시키는 온칩 학습 하드웨어 가속기, 그리고 폰 노이만 병목을 극복하는 차세대 지능형 메모리 반도체(PIM)에 이르는 최첨단 뉴로모픽 하드웨어 엔지니어링의 핵심 개념들을 종합적으로 학습합니다.
