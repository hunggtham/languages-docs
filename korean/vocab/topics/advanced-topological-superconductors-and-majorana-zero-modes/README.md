# 위상 초전도체와 마요라나 제로 모드의 언어

현대 양자 물리학과 양자 정보 과학의 최전선에서 위상 초전도체(Topological Superconductors)와 마요라나 제로 모드(Majorana Zero Modes, MZM)는 결함 내성 양자 컴퓨터(Fault-tolerant Quantum Computer) 구현을 위한 핵심 물리계로 주목받고 있습니다. 본 주제는 비아벨 통계(Non-Abelian Statistics), 브레이딩(Braiding) 연산, 초전도-반도체 나노와이어 헤테로구조, 영에너지 바이어스 피크(Zero-bias Conductance Peaks) 등 첨단 응집물질물리학과 양자 컴퓨팅 아키텍처를 아우르는 전문 어휘들을 다룹니다.
