# 네펜데스 모사 윤활유 함침 다공 표면(SLIPS) 기술의 언어

네펜데스(Nepenthes) 식충식물의 포충낭 가장자리(peristome) 미세 다공 구조와 젖음성 메커니즘을 모사한 윤활유 함침 다공 표면(SLIPS, Slippery Liquid-Infused Porous Surfaces) 기술은 고체 기재 내부에 윤활액을 모세관력으로 안정적으로 고정하여 초발수·초발유 특성과 결함 없는 원자 수준의 매끄러움을 구현하는 차세대 생체모사 계면 공학 분야입니다. 기존 연잎 효과 기반 초발수 표면이 지닌 압력 취약성과 미세 오염 축적의 한계를 극복하고, 박테리아 생물막 부착 방지, 극한 환경 방빙·결빙 지연, 의료용 기기 혈전 형성 억제, 선박 외벽 유체 마찰 저항 저감, 그리고 고점도 유체 무잔류 수송에 이르기까지 광범위한 산업 난제를 획기적으로 해결하고 있습니다. 본 단원에서는 다공성 나노 지지체, 모세관 윤활액 고정, 자가치유 피막, 광학 투명성 유지 및 친환경 무독성 윤활재에 이르는 첨단 네펜데스 모사 윤활유 함침 표면 기술의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
