# 에너지 전환과 전력망의 유연성

재생에너지 비중이 커질수록 전력망은 발전량만 늘리는 문제가 아니라, 순간순간 달라지는 공급과 수요를 안전하게 맞추는 문제가 된다. 이 topic은 계통의 물리적 안정도, 시장의 유연자원, 전력 변환과 배전 운영을 하나의 흐름으로 연결해 읽도록 돕는다.

## 학습 범위

`news_formal`은 전력시장 규칙, 계통 계획과 에너지 정책을 보도하거나 분석할 때 쓰이는 공식·전문 register다. `native_spoken`은 운영자가 재생에너지의 급격한 변화를 설명하거나 현장에서 대안을 조율할 때 들을 수 있는 표현이다. 물리적 현상과 정책적 선택을 같은 말로 뭉뚱그리지 않도록, 각 용어의 분석 수준과 책임 주체를 함께 익힌다.
