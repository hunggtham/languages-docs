# 법률 기술과 증거 플랫폼

법률 업무가 데이터와 플랫폼으로 재구성되는 과정을 따라가며, 법률 인공지능의 기반부터 전자소송·전자법정·증거 관리까지 연결해서 읽는다. 자동화가 편의성만의 문제가 아니라 검색 기준, 개인정보 보호, 절차적 공정성과도 맞물린다는 점을 익힌다.
