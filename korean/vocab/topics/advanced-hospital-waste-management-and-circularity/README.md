# 병원 폐기물 관리와 순환성의 언어

병원에서 나오는 감염성·유해성 물질을 안전하게 분리하고, 불필요한 소각과 일회용품을 줄이면서 자원을 순환시키는 운영의 어휘를 익힌다. 의료진의 안전, 환자 보호, 환경 규제와 조달 정책이 한 흐름에서 어떻게 만나는지 읽는다.

## 학습 범위

`news_formal`은 감염성·세포독성 폐기물, 소각 잔재, 위해성 분석과 위탁 처리 같은 규제·시설 언어를 다룬다. `native_spoken`은 병동에서 폐기물을 발생원에서 나누고 다회용 장비를 처리하는 현장의 판단을 다룬다. 단순히 의료폐기물을 버리는 일이 아니라 성상 파악, 전처리, 추적과 자원 회수까지 연결하는 순환 운영을 읽는 데 초점을 둔다.
