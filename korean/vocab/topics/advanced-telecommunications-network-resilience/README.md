# 통신망 회복력과 장애 대응의 언어

통신망이 끊기지 않도록 설계하는 일은 장비를 많이 두는 데서 끝나지 않는다. 경로를 나누고, 트래픽을 조절하고, 장애가 생겼을 때 책임 있게 우회·복구하는 운영 언어를 익힌다.

## 학습 파일

- [통신망을 지키는 설계와 운영의 핵심어](./01-network-resilience-and-failover.md) — `망복원력`, `이중화`, `다중화`, `페일오버`, `백홀`, `코어망`, `접속망`, `패킷손실`, `지연변동`, `혼잡제어`, `망분할`, `망가용성`, `트래픽엔지니어링`, `회선절체`, `장애조치`

## 학습 범위

`news_formal`은 기간통신망 투자, 재난 대응, 주파수와 네트워크 구조를 설명하는 기술·정책 보도에 쓰인다. `native_spoken`은 네트워크 운영자와 개발자가 장애 원인, 우회 경로와 복구 순서를 협의할 때 쓰는 실무어다. `slang_online`은 이 주제에서 남용하지 않고, 현재 현장에서 실제로 굳어진 `페일오버`만 contemporary 표현으로 다룬다.
