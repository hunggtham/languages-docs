# 웨어러블 땀 치료약물 농도 모니터링 기술의 언어

웨어러블 땀 치료약물 농도 모니터링(Wearable Sweat Therapeutic Drug Monitoring, TDM) 기술은 치료 유효 범위가 좁아 독성이나 치료 실패 위험이 높은 중증 질환 치료 약물(반코마이신 등 항생제, 면역억제제, 항암제)의 체내 농도를 피부 위에서 분비되는 땀을 매개로 실시간 비침습 감시하고 정밀 투약을 유도하는 최첨단 바이오전자 및 디지털 헬스케어 융합 공학 분야입니다. 반복적인 침습적 정맥 채혈의 고통과 감염 위험, 검사실 분석의 시간 지연을 근본적으로 극복하여 환자 침상 곁(point-of-care)에서 연속적인 약동학(PK) 프로파일링을 가능케 합니다. 본 단원에서는 자율 땀 포집 미세유체 채널, 표면 방오 양쪽성 이온 코팅, 전기화학적 압타머 센서 어레이, 피코몰급 초고감도 검출, 가역적 전극 재생, 온도·산도 다변량 보정, 혈중 농도 상관 모델링 및 무선 폐루프 스마트 투약 패치에 이르는 차세대 웨어러블 치료약물 모니터링 공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
