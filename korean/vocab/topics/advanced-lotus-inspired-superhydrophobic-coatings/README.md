# 연잎 모사 초소수성 코팅 및 자가세정 기술의 언어

자연계 연잎의 미세 계층 돌기 구조와 화학적 표면 에너지 제어를 모사하여, 접촉각 150도 이상의 초발수성과 자가세정, 결로 및 착빙 지연, 내마모성 코팅 및 대면적 스프레이 공정을 다루는 첨단 생체모사 계면화학 및 나노 표면 공학 어휘 단원이다.
