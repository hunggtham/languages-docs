# 광 집적회로와 광자 컴퓨팅의 언어

이 단원은 차세대 광 집적회로(PIC)와 광자 컴퓨팅(Optical Computing) 분야의 핵심 전문 어휘를 다룹니다. 실리콘 포토닉스를 활용한 온칩 집적, 마하-젠더 간섭계(MZI) 어레이를 통한 빛의 속도에 기반한 행렬-벡터 곱셈, 전광학 신경망 및 하이브리드 전자-광자 칩 아키텍처를 심도 있게 학습합니다.
