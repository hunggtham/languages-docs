# 산업공생과 자원 교환의 언어

산업공생은 한 기업의 부산물과 유휴 설비를 다른 기업의 원료·에너지·용수로 연결하는 협력 방식이다. 단순한 폐기물 거래가 아니라 물질 흐름, 공정 조건, 품질 책임과 장기 계약을 함께 설계해야 실제 자원 순환이 된다. 이 lesson은 산업단지에서 자원 교환을 검토하고 공정 간 의존성을 설명할 때 필요한 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 산업정책, 환경 규제와 자원순환 보고서에서 쓰이고, `native_spoken`은 산업단지 담당자와 공정 엔지니어가 공급 안정성·품질·비용을 조율할 때 들을 수 있다. 기업의 폐기물을 다른 기업의 투입물로 바꾸려면 잉여자원의 성상과 자원회수율뿐 아니라 공생협약, 공동처리와 책임 경계까지 함께 확인해야 한다.
