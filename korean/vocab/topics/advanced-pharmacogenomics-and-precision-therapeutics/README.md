# 약물유전체학과 정밀치료의 언어

약물유전체학과 정밀치료는 개인의 유전체 정보와 생체 분자 지표를 바탕으로 약물의 효능을 극대화하고 부작용을 최소화하는 현대 의약학의 핵심 분야이다. 환자마다 상이한 유전자 변이와 대사 효소의 특성을 정밀하게 분석하여 질병 메커니즘에 직접 작용하는 표적 약제를 선별하고 최적의 투여 용량을 산출하는 일련의 과정이 포함된다. 본 주제에서는 기초 유전체 분석에서부터 첨단 동반 진단, 임상 약동학 시뮬레이션, 병원 전산망 기반 처방에 이르는 정밀 의료 현장의 핵심 전문 어휘를 체계적으로 학습한다.
