# 번역과 통역 실무의 고급 언어

번역과 통역을 단순한 언어 치환이 아니라 의미·맥락·책임을 조정하는 전문 행위로 읽는다. 법정과 회의의 통역, 문화적으로 묶여 있는 표현의 번역, 자막과 더빙의 시간 제약을 한 흐름으로 연결해 실제 선택의 기준을 익힌다.

## 학습 범위

`news_formal`은 법정·공공기관·번역 품질과 책임을 논하는 공식 register다. `native_spoken`은 통역 현장과 제작 회의에서 시간, 자연스러움, 청중을 조율하는 말이다. 이 파일은 번역 결과만 평가하지 않고 누가 어떤 맥락에서 무엇을 보존하거나 바꾸었는지까지 묻는다.
