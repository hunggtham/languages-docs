# 공동체 산림 돌봄과 산불 예방

숲을 지키는 일은 산림청의 순찰이나 화재 진압만으로 끝나지 않는다. 주민이 숲의 상태를 관찰하고, 위험한 작업과 소각을 줄이며, 관리 기관과 책임을 나눌 때 예방이 생활 속 관행이 된다. 이 주제는 산불이 난 뒤의 불길 변화보다 산불이 나기 전의 공동 관리·감시·신고·정비에 초점을 둔다.
