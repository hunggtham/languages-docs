# 식물병리와 식량안보의 언어

식물의 병이 어떻게 나타나고 퍼지는지, 그리고 진단·검역·종자 관리가 식량 공급의 안정성과 어떻게 이어지는지 읽는다.

## 학습 파일

- [식물병 진단과 식량 공급의 회복력](./01-plant-disease-diagnosis-and-food-security.md) — `식물병리학`, `병징`, `병환`, `잠복감염`, `토양전염`, `매개충`, `내병성`, `저항성 품종`, `병해충종합관리`, `식물검역`, `검역병해충`, `생물적 방제`, `기주범위`, `무병종자`, `돌발병해`

## 학습 범위

`news_formal`은 식물병리 연구, 검역 조치, 종자 인증과 식량 공급 위험을 보도할 때 쓰인다. `native_spoken`은 농가 상담, 현장 조사와 방제 회의에서 병의 징후와 확산 경로를 설명할 때 자연스럽다. 병을 발견하는 순간부터 무병 종자, 저항성 품종, 통합 방제와 국경 검역으로 대응하는 흐름을 한 덩어리로 익힌다.
