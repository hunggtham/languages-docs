# 기후변화 시대의 문화유산 적응과 위험

기후변화가 문화유산에 가하는 위험을 단순한 복구 문제가 아니라 평가·계획·지역 협력의 언어로 읽는다. 유산영향평가에서 적응경로, 다중위험, 재료열화와 선제적 보존까지 연결하며 현장과 정책 보도에서 쓰이는 고급 표현을 익힌다.
