# 위상 마그노닉스와 스핀파 정보 처리의 언어

현대 응집물질물리학과 스핀트로닉스의 최전선에 위치한 위상 마그노닉스(Topological Magnonics)와 스핀파 정보 처리는 전자의 직접적인 전하 이동 없이 자성체 내 스핀의 세차 운동 파동(마그논)을 정보 매개체로 활용하여 줄열(Joule heating) 문제를 원천적으로 해결하는 혁신적인 분야입니다. 공간 반전 대칭성이 깨진 자성 계면에서의 드잘로신스키모리야상호작용(Dzyaloshinskii-Moriya Interaction; DMI)은 후방 산란을 억제하는 카이랄스핀파도파로채널과 나노 규모의 소용돌이 격자인 자기스커미온결정어레이를 안정화하며, 위상보호스핀파에지모드를 바탕으로 한 무손실스핀파정보전송을 가능하게 합니다. 또한 마그논밴드갭엔지니어링 기술과 자화방향성스핀파간섭계, 비가역스핀파스위칭회로 및 초고주파스핀파공진기의 정밀한 결합은 에너지 소모를 극소화한 초저전력마그논논리소자와 나노스케일스커미온메모리, 음향-스핀 융합형 마그논포논하이브리드소자 개발로 이어져 실리콘 반도체를 뛰어넘는 차세대자성정보처리기술 및 미래초고속스핀파컴퓨팅의 핵심 토대를 마련하고 있습니다.
