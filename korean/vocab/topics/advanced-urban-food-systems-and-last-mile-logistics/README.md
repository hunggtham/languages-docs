# 도시 먹거리 체계와 라스트마일 물류

도시에서 먹거리를 조달하고 보관하고 배달하는 흐름을, 접근성·폐기·노동·탄소의 관점에서 읽는다.

도시의 유통 인프라와 소비자의 가까운 생활권을 연결하되, 빠른 배송의 편리함이 폐기·노동·접근성 비용을 숨기지 않도록 읽는 파일이다.
