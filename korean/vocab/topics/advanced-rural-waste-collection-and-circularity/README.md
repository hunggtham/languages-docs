# 농촌 폐기물 수거와 순환성의 언어

인구가 흩어져 있고 계절에 따라 폐기물 발생량이 크게 달라지는 농촌에서, 수거망을 설계하고 자원을 안전하게 되돌리는 운영의 어휘를 익힌다. 이 주제는 도시형 대량 수거의 전제를 그대로 적용하지 않고 공동집하장, 순회노선, 농막과 영농 현장의 사각지대를 함께 읽는 데 초점을 둔다.

## 학습 범위

`news_formal`은 지방정부의 수거 설계, 계약과 성과 지표를 설명하는 데 쓰인다. `native_spoken`은 주민과 수거 노동자가 배출 장소와 시간을 조율하는 현장의 말투를 다룬다. 단순히 농촌의 폐기물을 더 자주 치우는 문제가 아니라, 이동거리·발생 계절·분리 품질·협동 운영을 함께 설계해야 실제 자원 회수가 가능하다는 점을 읽는다.
