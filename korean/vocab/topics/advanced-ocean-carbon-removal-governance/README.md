# 해양 탄소 제거 거버넌스의 책임과 검증

해양에서 탄소를 제거하는 기술은 기후 완화의 가능성만이 아니라 바다를 누가 사용하고 위험을 누가 부담하는지까지 묻는다. 이 lesson은 해양 탄소 제거 사업의 추가성·영구성·검증, 생태계 보호, 지역 공동체의 동의와 국경 간 책임을 한 정책 협의의 흐름으로 연결한다.

## 학습 범위

`news_formal`은 탄소 제거의 효과와 환경 위험을 심사하고 국제 규칙과 책임을 문서화할 때 쓰인다. `native_spoken`은 어민·주민·연구자·공무원이 시범사업의 조건과 보상, 중단 기준을 협의할 때 자연스럽다. “탄소를 많이 없앤다”는 홍보만으로는 충분하지 않으며, 기준선과 추가성, 생태계의 누적 영향, 장기 책임을 함께 확인하는 것이 핵심이다.
