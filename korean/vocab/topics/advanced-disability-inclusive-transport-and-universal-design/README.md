# 장애 포용 교통과 보편적 설계

장애가 있는 사람을 별도 이용자로 격리하지 않고 누구나 예측 가능하고 안전하게 이동할 수 있도록 교통수단과 환승 공간을 설계하는 어휘를 익힌다. 물리적 장치뿐 아니라 안내, 운영, 당사자 참여가 한 여정에서 어떻게 연결되는지 살핀다.
