# 이주민 환영과 언어 접근

새로 이주한 사람이 지역에서 살아가기 시작할 때 필요한 것은 한 번의 번역이 아니다. 정착 상담, 통역 연결, 체류 안내와 차별 대응이 서로 이어져야 공공서비스가 실제로 닿는다. 이 주제는 환영센터와 공공기관이 언어 접근을 권리와 관계의 문제로 다루는 표현을 익힌다.

## 학습 범위

`news_formal`은 이주 정책, 인권과 공공서비스 설계에서 쓰이는 표현이다. `native_spoken`은 환영센터 상담과 지역 기관 협업에서 실제로 들을 수 있는 실무어다. 통역을 단순한 언어 변환으로 축소하지 않고, 정확한 의사소통·비밀보장·후속 연결까지 함께 본다.
