# 뉴로모픽 인공망막 임플란트 및 광다이오드 배열 기술의 언어

뉴로모픽 인공망막 임플란트 및 광다이오드 배열 기술은 망막색소변성증(RP)이나 노인성 황반변성(AMD) 등으로 광수용체 세포가 파괴되어 실명한 환자들에게 시각을 복원해 주기 위해 생체 망막의 신경망 구조와 전기적 스파이크 신호 처리 방식을 모방한 차세대 전자 생체 신경보철(neural prosthetics) 공학 분야입니다. 안구 내에 삽입되는 초소형 광다이오드 픽셀 어레이를 통해 빛을 감지하고, 생체 시냅스와 신경절 세포(RGC)의 활동전위를 본뜬 펄스 신호를 잔존 시신경에 직접 전기적으로 인가함으로써 물체의 형태와 명암, 움직임을 뇌가 다시 인지하도록 유도합니다. 본 단원에서는 서브망막 광소자, 스파이킹 신경 부호화, 초고밀도 미세전극, 유연 생체 패키징, 초저전력 온칩 프로세서 및 장기 신뢰성 밀봉 기술에 이르는 첨단 신경 인터페이스 의공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
