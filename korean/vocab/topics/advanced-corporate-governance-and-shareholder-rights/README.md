# 기업지배구조와 주주 권리의 언어

기업을 평가할 때는 실적과 주가만이 아니라 누가 의사결정에 참여하고, 경영진을 누가 감시하며, 주주의 권리가 어떻게 보호되는지도 읽어야 한다. 이 주제는 주주총회, 인수합병과 이사회 책임을 하나의 흐름으로 연결한다.

## 학습 범위

`news_formal`은 주주총회 공시, 인수합병 보도와 회사법 분석에서 권한·책임·자본 배분을 정밀하게 말할 때 쓰인다. 이 lesson에서는 `native_spoken`보다 공식 담화에 자주 나오는 고급 어휘를 중심으로, 경영권 방어와 주주 보호를 어느 한쪽의 구호로 단정하지 않고 실제 절차와 이해상충을 따져 읽는 연습을 한다.
