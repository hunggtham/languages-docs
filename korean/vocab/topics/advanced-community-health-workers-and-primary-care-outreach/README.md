# 지역사회 건강요원과 일차의료 outreach를 읽는 말

지역사회 건강요원이 주민을 먼저 만나 건강 위험을 살피고, 필요한 일차의료와 예방 서비스로 연결하는 현장의 언어를 읽는다. 병원 안의 진료 전달체계보다 가구 방문, 신뢰 형성, 문화적 중개와 후속 확인에 초점을 둔다.
