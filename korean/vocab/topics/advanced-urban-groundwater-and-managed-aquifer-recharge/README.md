# 도시 지하수와 관리형 대수층 함양의 언어

도시가 빗물과 처리수를 땅속에 안전하게 저장해 가뭄과 취수 압력에 대응하려면 대수층의 구조, 주입 시설, 수질 변화와 장기 모니터링을 함께 읽어야 한다. 이 주제에서는 관리형 대수층 함양을 단순한 저장 기술이 아니라 허가·책임·지역 신뢰가 결합된 도시 물관리로 다룬다.

## 학습 범위

`news_formal`은 도시 물관리 계획, 수리지질 조사와 환경 규제에서 지하수의 저장·이동·수질 위험을 정밀하게 설명할 때 쓰인다. `native_spoken`은 주민 설명회에서 주입수가 어디로 가고 언제 회수되는지, 우물과 건물에 어떤 영향이 없는지를 풀어 말할 때 자연스럽다. 저장량만 강조하지 않고 수질 혼합, 관측 자료, 허가 조건과 장기 책임을 한 묶음으로 이해하는 것이 핵심이다.
