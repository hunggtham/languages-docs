# 디지털 문해력과 공공서비스 길찾기

공공서비스가 온라인으로 옮겨가도 필요한 제도를 찾고 신청하는 책임이 시민에게만 생기는 것은 아니다. 이 주제는 서비스 정보를 탐색하고, 자격과 서류를 확인하고, 막힌 화면에서 다른 도움으로 전환하는 과정을 다룬다.

## 학습 범위

`news_formal`은 공공기관이 디지털 전환과 서비스 접근 격차를 설명할 때 쓰이는 정책어다. `native_spoken`은 주민센터 상담과 이용자 지원 현장에서 자연스럽다. 사용자의 조작 능력만 강조하지 않고 정보 구조, 대체 채널과 기관의 책임까지 함께 익힌다.
