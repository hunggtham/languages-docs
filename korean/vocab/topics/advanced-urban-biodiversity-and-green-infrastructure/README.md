# 도시 생물다양성과 녹색 인프라의 언어

도시를 콘크리트와 교통의 집합으로만 보지 않고, 종의 서식·이동·번식과 빗물·열을 함께 관리하는 생태적 경관으로 읽는다. 도시계획 문서, 주민 협의와 현장 대화에서 녹색 인프라가 어떤 기능과 접근성의 문제로 연결되는지 익힌다.

## 학습 범위

`news_formal`은 생물다양성 계획, 환경영향평가와 도시 기반시설 정책에서 공간의 기능과 성과를 정밀하게 설명할 때 쓰인다. `native_spoken`은 주민참여형 설계, 옥상·벽면 식재와 동네 녹지 이용을 이야기할 때 자연스럽다. 전문어는 단순히 '친환경'으로 번역하지 말고, 어떤 종과 물의 흐름, 사람의 이동을 바꾸는지 함께 파악해야 한다.
