# 지역사회 조정과 회복적 정의를 말하는 언어

지역사회 갈등은 법정의 판결만으로 관계와 신뢰가 저절로 회복되지 않는다. 이 주제는 중립적인 조정자가 당사자의 목소리를 안전하게 연결하고, 피해를 인정하며, 합의가 실제 행동으로 이어지도록 하는 고급 한국어를 다룬다. 회복적 정의를 낭만화하지 않고 자발성, 안전, 책임과 후속 지원을 함께 살피는 것이 핵심이다.

## 학습 범위

`news_formal`은 분쟁 조정 정책, 회복적 사법과 지역사회 안전망을 보도하거나 평가할 때 쓰인다. `native_spoken`은 당사자와 지원자가 사과, 경청, 안전 조건과 합의 이행을 협의하는 실제 대화에 가깝다. 화해를 서두르기보다 피해자의 선택권과 안전, 책임 있는 참여를 먼저 확인한다.
