# 도시 쿨루프와 열 정의의 언어

쿨루프는 지붕 표면의 반사·방사 성능을 바꾸는 기술이지만, 도료를 칠했다는 사실만으로 모두가 시원해지는 것은 아니다. 어떤 건물이 먼저 개보수를 받고, 냉방비와 임대료 부담이 누구에게 돌아가며, 최상층 거주자가 실제로 열 혜택을 얻는지를 함께 살피는 도시 정책·주거권 어휘를 익힌다.

## 학습 범위

`news_formal`은 건축 성능, 도시 열 정책과 공공투자 평가에서 표면 물성·건물 부하·분배 결과를 정밀하게 연결할 때 쓰인다. `native_spoken`은 주민 회의와 임차인 상담에서 “누가 먼저 시원해지고 누가 비용을 내는가”를 설명할 때 자연스럽다. 이 lesson은 기존의 일반적인 쿨루프·열섬 완화 소개를 반복하지 않고, 기술 성능을 실제 주거권과 투자 우선순위로 번역하는 어휘에 초점을 둔다.
