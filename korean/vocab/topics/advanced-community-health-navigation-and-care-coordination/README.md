# 지역사회 건강 길찾기와 돌봄 조정의 언어

주민이 필요한 의료·복지 서비스를 찾고, 의뢰와 회송을 거쳐 치료와 생활 지원을 이어 가는 과정을 설명하는 고급 어휘를 익힌다. 기관의 숫자를 늘리는 것만이 아니라 정보 장벽, 이동 부담, 통역과 가족돌봄의 현실을 함께 살피는 주제다.

## 학습 파일

- [지역사회 건강 길찾기와 돌봄 조정](./01-community-health-navigation-and-care-coordination.md) — `보건의료자원지도`, `서비스탐색지원`, `진료의뢰회송`, `다학제협진`, `전환기돌봄`, `돌봄조정자`, `건강복지연계`, `보건의료복지연계`, `건강취약성평가`, `의뢰조정`, `진료동행`, `가족돌봄자지원`, `복약조정`, `의료통역연계`, `권리옹호연계`

`news_formal`은 지역보건 계획과 의료전달체계 개편을 분석할 때, `native_spoken`은 주민·가족·상담자가 실제로 어느 기관에 무엇을 요청할지 말할 때 유용하다. 서비스 연결을 효율성만으로 평가하지 않고 당사자의 동의, 선택권과 생활 맥락까지 함께 확인하는 것이 핵심이다.
