# 도시 폭염의 야간 피난처와 냉각 운영의 언어

도시 폭염은 해가 진다고 자동으로 끝나지 않는다. 건물과 도로가 저장한 열, 열대야와 냉방비 부담 때문에 밤에도 회복하지 못하는 주민이 생긴다. 이 주제는 야간에 문을 여는 피난처, 냉방 운영, 취약 가구 확인과 건강 감시를 하나의 생활권 대응으로 읽는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 폭염 행동계획, 야간 취약성 조사와 냉방 시설 운영을 보도·평가할 때 쓰인다. `native_spoken`은 주민이 밤에 더위를 피할 곳, 이동 방법과 증상 신고를 상의할 때 자연스럽다. 냉방 시설의 개수만 세지 말고 실제 운영 시간, 걸어갈 수 있는 거리, 수면 회복과 전기요금 부담까지 함께 살피는 것이 핵심이다.
