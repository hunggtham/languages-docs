# 민속 신앙과 공동체 의례

무당과 무속 의례를 문화적·사회적 맥락에서 이해하고, 점술·금기·제사와 관련된 표현을 구분해 학습한다. 의례의 존재와 사회적 의미를 설명하되 초자연적 효능을 사실로 단정하지 않는다.

## 학습 파일

- [의례를 기록하고 믿음을 설명하는 말](./01-rituals-and-belief-language.md) — `무당`, `무속`, `굿`, `굿판`, `신내림`, `신당`, `부적`, `액막이`, `길흉`, `점괘`, `점집`, `제사`, `금기`, `신령`, `퇴마`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 문화적 관습·개인적 믿음·검증 가능한 사실을 서로 섞지 않도록 context를 설계한다.
