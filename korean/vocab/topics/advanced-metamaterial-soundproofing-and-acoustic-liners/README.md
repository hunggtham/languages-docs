# 음향 메타물질과 음향 라이너의 언어

본 단원은 현대 음향공학 및 재료과학의 최첨단 분야인 음향 메타물질(Acoustic Metamaterials)과 음향 라이너(Acoustic Liners) 관련 전문 어휘를 다룹니다. 초저주파 소음 차단, 서브파장 공진 구조, 통기성 초경량 흡음 패널, 헬름홀츠 공명기 어레이, 부의 밀도·탄성률 및 음의 굴절률 제어, 항공기 제트 엔진 라이너와 고속철도 소음 저감 벽체, 그리고 도심 모빌리티 정숙성 엔지니어링에 이르는 핵심 개념과 실무 표현들을 체계적으로 학습할 수 있습니다.
