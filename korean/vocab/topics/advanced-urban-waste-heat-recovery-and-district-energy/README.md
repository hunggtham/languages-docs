# 도시 폐기물 열회수와 지역에너지의 언어

도시의 폐기물 처리 시설과 산업·상업 시설에서 버려지는 열을 지역의 난방 수요와 연결하는 과정을 다룬다. 소각 공정, 열망의 온도, 저장과 요금 계약을 한 시스템으로 읽으며, 단순히 “폐기물을 태워 에너지를 만든다”는 설명을 넘어 회수 가능한 열의 품질과 공급 책임을 구별한다.

## 학습 범위

`news_formal`은 자원순환 정책, 소각시설의 배출 관리와 지역에너지 계획을 보도하거나 평가할 때 쓰인다. `native_spoken`은 시설 운영자, 지자체 담당자와 주민이 비용·소음·공급 안정성을 조율할 때 들을 수 있다. 핵심은 열을 회수하는 장치만 보는 것이 아니라, 수요 밀도와 배관 손실, 저장·계약 구조가 실제 이용 가능성을 결정한다는 점이다.
