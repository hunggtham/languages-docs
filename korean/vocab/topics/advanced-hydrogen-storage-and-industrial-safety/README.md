# 수소 저장과 산업 안전의 언어

수소를 산업 현장에 들여오는 일은 저장 용량을 늘리는 문제만이 아니다. 금속과 수소의 상호작용, 액화·압축 과정의 열역학, 누출과 점화의 경로, 설비의 방호 계층을 함께 읽어야 안전한 설계와 사고 대응을 설명할 수 있다.

## 학습 범위

`news_formal`은 수소 인프라 투자, 저장기술과 사고조사에서 성능과 규제 책임을 정밀하게 설명할 때 쓰이는 공식·전문 register다. `native_spoken`은 운전자가 충전·정비·점검 과정의 이상 징후를 조율할 때 자연스럽다. `slang_online` 대신 실제 현장 안전어를 중심에 두어, 위험을 막연히 “조심”하는 것과 압력·온도·점화원을 통제하는 것을 구분한다.
