# 도시 수변 공공공간과 안전

강·운하·호숫가를 시민의 일상 공간으로 열면서도 보행 접근성, 수상 활동, 익수와 홍수 위험을 함께 관리하는 어휘를 익힌다.

이 파일의 지문은 도시가 수변을 휴식·보행 공간으로 개방하면서도 물가의 사고와 수위 변화에 대비하는 한 장면을 통해 15개 target을 자연스럽게 연결한다.
