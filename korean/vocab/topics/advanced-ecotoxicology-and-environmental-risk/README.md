# 생태독성과 환경 위해성의 언어

환경오염이 생물과 생태계에 미치는 영향을 분석하고, 노출과 위해성을 과장하거나 축소하지 않으면서 설명하는 고급 어휘를 익힌다. 독성 시험의 수치와 생태계에서 일어나는 축적·증폭 과정을 연결해 읽는 데 초점을 둔다.

## 학습 파일

- [생태독성과 위해성평가의 기준](./01-ecotoxicity-and-environmental-risk.md) — `생태독성`, `생물축적`, `노출평가`, `생태위해성`

## 학습 원칙

- 각 표제어는 생태독성학, 환경 규제, 위해성 소통에서 실제로 쓰이는 고급 전문어다.
- 단일 측정값만으로 위험을 단정하지 않고, 독성의 시간적 양상과 노출 경로, 생태계 수준의 불확실성을 함께 읽는다.
- 각 항목의 예문과 읽기 지문은 새로 작성했으며, 참고 자료의 문장을 복사하지 않았다.
