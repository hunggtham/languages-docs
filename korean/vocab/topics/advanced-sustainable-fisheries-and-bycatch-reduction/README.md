# 지속 가능한 어업과 혼획 저감의 언어

바다에서 물고기를 잡는 일은 어획량만의 문제가 아니다. 어구가 남기는 피해, 생태계의 회복 속도, 어민의 생계와 추적 가능한 공급망을 함께 판단하는 어휘를 익힌다.

어획 규제의 기술적 수단과 정책 집행을 한 어촌의 관리 회의라는 맥락에서 연결한다.
