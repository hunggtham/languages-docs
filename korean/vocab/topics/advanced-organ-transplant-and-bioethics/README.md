# 장기이식과 생명윤리의 경계

장기이식은 수술 기술만의 문제가 아니다. 누구를 이식 대상으로 볼지, 공여자의 위험을 어디까지 감수할지, 면역 반응과 새로운 이종장기의 가능성을 어떻게 설명할지 함께 판단해야 한다.

## 학습 범위

`news_formal`은 이식의학 연구, 병원 정책, 장기 배분과 규제 보도에서 면역 반응·근거 수준·자원 배분을 정확히 구분할 때 쓰인다. `native_spoken`은 이식 상담과 다학제 회의에서 생체공여자의 선택, 공여자위험, 면역관용의 기대와 한계를 설명할 때 들을 수 있는 전문 구어 register다. 장기를 기술적 자원으로만 다루지 않고 환자·공여자·가족의 동의와 부담까지 한 흐름으로 읽는다.
