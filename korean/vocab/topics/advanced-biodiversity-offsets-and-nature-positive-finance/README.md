# 생물다양성 상쇄와 자연긍정 금융의 언어

개발사업이 자연에 남기는 영향을 계산하고 줄이는 일은 크레딧을 사는 데서 끝나지 않는다. 무엇을 피하고 복원할지, 남은 영향을 어떤 생태적 등가성으로 보완할지, 금융기관이 자연 의존성과 위험을 어떻게 공개할지를 함께 판단하는 어휘를 익힌다.

## 학습 범위

`news_formal`은 개발 인허가, 환경영향평가, 금융 공시와 투자 심사에서 기준선·등가성·위험을 정밀하게 말할 때 쓰인다. `native_spoken`은 주민 협의와 사업 검토에서 “무엇을 먼저 피하고, 남은 영향을 어떻게 책임질 것인가”를 풀어 설명할 때 자연스럽다. `slang_online`은 이 주제의 전문어를 조롱하거나 검증하는 온라인 반응을 설명할 때 제한적으로 참고한다. 상쇄를 면죄부로 다루지 않고 회피·최소화·복원·보완의 순서를 함께 판단한다.
