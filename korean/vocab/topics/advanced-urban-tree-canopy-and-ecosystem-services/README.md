# 도시 나무 그늘과 생태계서비스를 설계하는 언어

도시의 나무는 경관 장식에 그치지 않고 열, 빗물, 대기질, 생물다양성과 건강을 함께 조절하는 기반 시설이다. 이 lesson은 수관을 어떻게 측정하고, 어디에 심으며, 토양과 연결성을 어떻게 관리하는지 정책·설계·주민 협의의 언어로 읽는다.

## 학습 범위

`news_formal`은 도시계획, 기후적응, 산림·환경 정책과 설계 보고서에서 지표와 공간 효과를 정밀하게 말할 때 쓰인다. `native_spoken`은 현장 조사, 주민 설명회와 조경 실무 회의에서 나무의 상태와 관리 우선순위를 풀어 말할 때 자연스럽다. 단순히 나무를 많이 심는 것보다 수관의 연속성, 토양 조건, 안전과 형평성을 함께 판단하는 것이 핵심이다.
