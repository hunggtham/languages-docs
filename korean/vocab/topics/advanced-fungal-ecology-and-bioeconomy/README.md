# 균류 생태와 바이오경제의 전환 언어

숲과 농지에서 균류가 물질을 분해하고 생물 사이의 관계를 조정하는 방식은 식품·소재·환경 산업의 새로운 자원이 되고 있다. 이 주제에서는 균류의 생태적 구조를 읽는 말과 목질계 원료를 고부가가치 물질로 바꾸는 공정 언어를 함께 익힌다.

## 학습 범위

`news_formal`은 산림 생태, 생물자원 정책, 바이오산업 보고서에서 균류의 기능과 산업적 전환을 정밀하게 설명할 때 쓰인다. `native_spoken`은 연구실·생산 현장에서 배양 상태, 수율과 오염 위험을 서로 확인할 때 자연스럽다. 균류를 단순히 버섯으로 축소하지 않고, 생태계의 분해자이자 소재·효소·대사산물의 생산 플랫폼으로 이해하는 것이 핵심이다.
