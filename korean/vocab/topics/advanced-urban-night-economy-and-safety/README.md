# 도시 야간경제와 안전의 언어

도시는 해가 진 뒤에도 일하고 이동하고 만나는 생활권이다. 이 lesson은 야간상권의 활력과 야간 이동의 안전을 함께 살피며, 행정 보고서와 주민 대화에서 밤의 도시를 설명하는 어휘를 묶는다.

## 학습 파일

- [도시 야간경제와 귀가 안전](./01-urban-night-economy-and-safety.md) — `야간상권`, `야간관광`, `심야교통`, `유동인구`, `안전귀가`, `방범순찰`, `순찰거점`, `보행안전`, `조도개선`, `비상벨`, `안심귀가서비스`, `상권회복`, `야간활동`, `안전취약지대`, `지역안전망`

야간경제를 단순히 술집과 소비의 문제로 축소하지 않고, 노동 시간·교통·조명·치안·주민의 휴식이 어떻게 조정되는지 설명한다. `news_formal`은 도시정책과 상권 분석에, `native_spoken`은 실제 귀갓길과 동네 안전을 말할 때 유용하다.
