# 도시 폐품수집인과 순환적 포용의 언어

도시의 자원순환은 시설과 기술만으로 이루어지지 않는다. 매일 거리를 다니며 재사용 가능한 물질을 찾아내는 노동자와 비공식 수거망이 실제 회수량과 생계의 일부를 떠받친다. 이 lesson은 그 노동을 지우지 않으면서 안전, 권리, 협동조합과 제도적 포용을 말하는 어휘를 묶는다.
