# 도시 공공도서관 접근과 디지털 문해

도시의 공공도서관을 책을 빌리는 장소에만 가두지 않고, 지식·기기·교육·정보 판단에 접근하는 생활 기반시설로 이해하는 어휘를 익힌다. 이 주제는 지역별 이용 격차와 전자자료 이용, 디지털 문해교육이 서로 어떻게 연결되는지에 초점을 둔다.

## 학습 범위

도서관 접근권, 도서관 이용격차, 공공도서관 서비스, 도서관 분관, 생활권 도서관, 이동도서관, 전자자료 이용권, 디지털 문해교육, 정보문해력, 미디어정보문해, 검색전략, 정보탐색능력, 출처비판, 온라인 독해, 개인정보 문해력을 다룬다. 이미 다룬 일반적 디지털 포용이나 공공서비스 안내 어휘와 겹치지 않도록, 공공도서관의 실제 접근 경로와 자료 판단 능력에 집중한다.
