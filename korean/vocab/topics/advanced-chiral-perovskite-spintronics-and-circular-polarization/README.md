# 카이랄 페로브스카이트 스핀트로닉스 및 원편광 제어 기술의 언어

카이랄 페로브스카이트 스핀트로닉스 및 원편광 제어 기술은 거울상 비대칭성을 갖는 카이랄(chiral, 손대칭성) 유기 분자를 페로브스카이트 결정 격자에 통합하여, 외부 강자성체 박막이나 거대한 영구자석 없이도 오직 분자의 입체 구조와 스핀-궤도 결합(SOC)만으로 전자의 업·다운 스핀을 100%에 가깝게 분극·필터링하고 좌·우원편광(CPL)을 선택적으로 흡수·발광하는 차세대 양자 정보 전자소자 분야입니다. 상온 스핀 선택적 수송(CISS 효과), 초거대 원편광 이색성, 라쉬바-드레스하우스 스핀 분할 제어, 그리고 저비용 용액 공정 단결정 성장을 바탕으로, 차세대 양자 암호 통신, 고밀도 스핀 메모리, 3D 무안경 홀로그래픽 디스플레이 및 초고감도 바이오 광센서의 새로운 지평을 열고 있습니다. 본 단원에서는 양자 스핀트로닉스와 첨단 키랄 광전자공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
