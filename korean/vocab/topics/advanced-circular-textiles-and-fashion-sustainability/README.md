# 섬유를 오래 쓰고 패션의 순환 경로를 설계하는 언어

패션 산업의 지속가능성은 친환경 소재를 하나 고르는 데서 끝나지 않는다. 얼마나 많이 만들고, 얼마나 오래 입고, 혼방 원단을 어떻게 분리하며, 사용이 끝난 섬유를 어떤 원료로 되돌릴지를 함께 따져야 한다. 이 주제는 생산 과잉과 재판매, 염색 공정, 섬유 재활용의 기술적 한계를 하나의 물질 흐름으로 읽는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 생산량, 재활용 기술, 염색 공정과 환경 규제를 보도하거나 기업의 지속가능성 자료를 검토할 때 쓰인다. `native_spoken`은 옷을 오래 입을지, 중고로 되팔지, 렌털 서비스를 이용할지 말하는 소비자 대화와 실무 대화에서 들을 수 있다. 소재 이름만 친환경적으로 바꾸는 것보다 실제 착용 기간, 회수 경로와 공정의 물·화학물질 사용량을 함께 확인하는 것이 핵심이다.
