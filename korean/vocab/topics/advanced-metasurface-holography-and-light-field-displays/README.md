# 메타표면 홀로그래피와 라이트 필드 디스플레이의 언어

메타표면 홀로그래피와 라이트 필드 디스플레이 분야는 나노 구조를 통해 빛의 위상, 진폭, 편광을 초정밀 제어하여 3차원 입체 영상을 허공에 구현하는 최첨단 광학 및 나노 기술의 집합체입니다. 본 학습 모듈에서는 서브파장 나노 안테나 배열을 이용한 위상 변조 초표면 소자부터 차세대 증강현실(AR) 및 무안경 3차원 디스플레이에 이르는 핵심 전문 어휘 15개를 다룹니다.

- [메타표면 홀로그래피와 라이트 필드 디스플레이 전문 어휘](./01-metasurface-holography-and-light-field-displays.md) — 메타표면홀로그래피, 위상변조초표면소자, 광시야각입체영상, 영차절절면파초점제어, 다파장풀컬러재생, 공간광변조기대체, 동작시차완전구현, 단일평면초박형광학계, 무안경삼차원디스플레이, 차세대광학보안암호화, 서브파장나노격자배열, 홀로그래픽광학소자, 공간해상도초정밀제어, 차세대입체영상플랫폼, 실감형증강현실디스플레이
