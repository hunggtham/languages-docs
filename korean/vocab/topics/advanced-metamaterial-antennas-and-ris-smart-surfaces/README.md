# 재구성 가능 지능형 표면과 6G 메타 안테나의 언어

본 토픽은 6G 이동통신에서 차세대 핵심 기술로 주목받는 재구성 가능 지능형 표면(RIS)과 메타 물질 안테나의 전파 제어 원리, 밀리미터파 및 테라헤르츠 대역의 전파 음영 해소, 초저전력 위상 변위기 및 스마트 무선 환경 구축과 관련된 전문 어휘를 심도 있게 다룹니다.
