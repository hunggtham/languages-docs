# 콘텐츠 모더레이션과 플랫폼 거버넌스의 언어

플랫폼이 유해한 게시물을 판별하고 이용자에게 설명·구제하는 과정을 신뢰·안전 정책의 고급 한국어로 읽는다.

## 학습 파일

- [콘텐츠 모더레이션의 판정과 집행](./01-content-moderation-and-enforcement.md)

## 학습 범위

자동 분류의 한계, 사람 검토의 역할, 신고 시스템의 악용, 제재의 비례성과 합성 미디어의 출처 표시를 한 흐름으로 연결한다. 정책 문서와 플랫폼 투명성 보고서에서 만나는 표현을 실제 운영 회의와 이용자 공지의 register 차이까지 함께 익힌다.
