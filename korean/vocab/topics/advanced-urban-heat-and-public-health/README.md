# 도시 열과 공중보건의 언어

도시의 더위는 단순한 기상 현상이 아니라 건물·도로·그늘·소득·건강 서비스가 겹쳐 만들어 내는 노출 위험이다. 이 주제는 도시 열을 측정하고 줄이는 설계 언어와, 폭염이 누구에게 더 큰 건강 부담이 되는지를 설명하는 공중보건 담화를 한 장면으로 연결한다.

## 학습 범위

`news_formal`은 폭염 보도, 도시계획, 기후 적응 예산과 보건 당국의 위험 소통에서 쓰이는 정밀한 표현을 다룬다. `native_spoken`은 주민·설계자·보건 담당자가 실제 동네의 그늘, 냉방비와 체감 위험을 이야기할 때 자연스러운 표현이다. `slang_online` 대신 현재 정책·현장 담화에서 굳어진 건축·환경 용어를 선택해, 더위의 물리적 지표와 불평등한 건강 결과를 혼동하지 않도록 한다.
