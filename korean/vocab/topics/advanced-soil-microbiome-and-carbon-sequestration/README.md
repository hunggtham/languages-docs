# 토양 미생물과 탄소 저장의 언어

토양 탄소를 늘리는 일은 유기물을 흙에 넣는 데서 끝나지 않는다. 식물 뿌리와 미생물이 탄소를 어떤 형태로 바꾸고, 토양 구조와 산소 조건이 그 탄소를 얼마나 오래 붙잡아 두는지 함께 살펴야 한다. 이 주제는 농업·기후 보도와 현장 연구에서 미생물 생태, 탄소 흐름, 온실가스 배출을 정밀하게 설명하는 고급 어휘를 연결한다.

## 학습 범위

`news_formal`은 토양 탄소 정책, 기후 완화 사업과 배출량 산정의 근거를 설명할 때 쓰인다. `native_spoken`은 연구자·농민·현장 기술자가 뿌리 주변의 상태와 관리 효과를 논의할 때 쓰이며, `slang_online`은 이 주제에 억지로 끼워 넣지 않고 실제 전문 담화에 필요한 두 source lane을 중심으로 구성했다. 탄소 저장량만 높다고 단정하지 않고 미생물 활동, 토양 구조와 아산화질소까지 함께 봐야 한다.
