# 관계와 정서 회복

상실감과 고립을 지나 회복하는 과정, 그리고 사람 사이의 친밀감·애착·화해를 함께 학습한다. 각 파일은 하나의 하위 주제를 다루며, 15개 headword마다 짧은 읽기 지문을 하나씩 둔다.

## 학습 파일

- [고립감에서 회복으로](./01-isolation-and-recovery.md) — `고독하다`, `비참하다`, `연약하다`, `낙담`, `결핍`, `초조`, `허무`, `후유증`, `치유`, `치오르다`, `간직`, `현명하다`, `생생히`, `면목`, `자원봉사`
- [유대와 관계의 긴장](./02-bonds-and-relationship-tension.md) — `친밀`, `유대감`, `애착`, `돈독`, `끈끈하다`, `재회`, `화해`, `외사랑`, `꺼리다`, `집착`, `집요하다`, `매달리다`, `귀띔`, `어장관리`, `밀당`

## 읽기 지문 원칙

각 지문은 최대 15개 target headword를 자연스럽게 포함한다. target set은 HTML comment metadata로 기록하고, 지문 아래에 베트남어 번역을 둔다. 단어 수는 파일 크기를 제한하는 quota가 아니라 context를 나누는 단위다.
