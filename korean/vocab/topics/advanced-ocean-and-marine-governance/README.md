# 해양 생태계와 바다 거버넌스의 언어

바다는 단순한 자연 배경이 아니라 기후, 식량, 통신, 안보와 지역 생계가 겹치는 공공 영역이다. 이 주제는 해양 생태계의 변화를 진단하고, 어업과 해저 인프라를 조정하며, 여러 이해관계자의 책임을 묻는 현대 한국어를 연결한다.

## 학습 범위

`news_formal`은 기후·해양 과학 보도, 수산 정책, 국제 협약과 인프라 논의에서 자료와 책임을 정밀하게 말할 때 쓰인다. `native_spoken`은 연구자, 어민, 정책 담당자와 시민이 현상을 설명하거나 우려를 나눌 때 실제로 들을 수 있는 표현이다. 생태계의 변화는 단일 원인으로 단정하기보다 관측 범위, 지역 조건과 관리 목표를 함께 확인해야 한다.
