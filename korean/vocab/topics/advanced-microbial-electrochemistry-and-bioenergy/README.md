# 미생물 전기화학과 바이오에너지

미생물이 전자를 주고받는 방식을 전극과 연결해 전기와 연료를 만드는 연구·산업 현장의 어휘를 익힌다.

## 학습 파일

- [미생물 전기화학과 에너지 회수](./01-microbial-electrochemistry-and-bioenergy.md) — 전자 흐름을 측정하고 생물전기화학 공정을 설계하다

## 학습 초점

이 주제의 표제어는 미생물의 대사, 전극 반응, 전기 생산과 연료 합성을 설명하는 고급 과학기술어다. `전기활성미생물`부터 `전기발효`까지의 연결을 따라가며, 단순히 전기를 만드는 장치가 아니라 전자공여체·전자수용체와 산화환원 조건을 조절하는 시스템이라는 관점을 익힌다.
