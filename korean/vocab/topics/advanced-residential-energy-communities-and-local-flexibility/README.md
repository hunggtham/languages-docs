# 주거 에너지 공동체와 지역 유연성의 운영 언어

가정의 에너지관리, 공유 태양광, 양방향 전력 흐름과 지역 배전망의 유연성을 하나의 운영 장면에서 읽는다. 주민이 단순한 소비자가 아니라 요금 신호에 반응하고, 남는 전력을 나누며, 유연성의 편익과 부담을 함께 협의하는 과정을 살핀다.
