# 음식과 일상의 살림

시장과 주방에서 재료를 고르고 조리하며, 맛·영양·보관과 안전을 관리하는 어휘를 학습한다.

## 학습 파일

- [재료를 고르고 음식을 안전하게 다루기](./01-food-and-household-routines.md) — `식재료`, `조리`, `간`, `식감`, `향토`, `발효`, `제철`, `보관`, `유통기한`, `알레르기`, `영양`, `포장`, `재료`, `레시피`, `공급`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 맛의 표현과 식품 안전 정보를 구분해 설명한다.
