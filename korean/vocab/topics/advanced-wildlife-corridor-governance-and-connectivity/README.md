# 야생동물 이동과 경관 거버넌스

도로와 개발로 나뉜 서식지를 다시 잇는 과정에서 과학적 지표, 토지 권리, 주민 합의와 행정 책임이 어떻게 만나는지 읽는 어휘를 익힌다.
