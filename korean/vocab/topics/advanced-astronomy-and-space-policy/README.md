# 우주를 관측하고 미래의 활동을 조정하는 언어

우주 과학은 먼 천체를 설명하는 데서 끝나지 않고 관측 장비, 지구 방어, 상업 활동과 국제 규범까지 연결된다. 이 주제는 천문학 보도와 연구자·시민의 대화에서 우주의 구조와 인간의 책임을 함께 말하는 현대 한국어를 다룬다.

## 학습 범위

`news_formal`은 천문 관측, 우주 정책과 국제 협력에서 증거와 불확실성을 정밀하게 말할 때 쓰인다. `native_spoken`은 연구자 인터뷰나 과학관 대화에서 복잡한 개념을 일상 언어로 풀어 말할 때 들을 수 있다. 우주 개발을 낙관이나 공포로 단정하지 않고 관측 자료, 위험 분포와 공공 책임을 함께 살피는 것이 핵심이다.
