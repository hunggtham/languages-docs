# 탄소 포집과 지중 저장의 언어

온실가스 감축의 한계를 넘어서기 위해 탄소를 직접 포집하고 영구히 격리하는 CCUS 기술은 현대 기후 정책과 에너지 산업의 핵심 의제다. 이 topic은 배출원과 대기에서 이산화탄소를 회수하는 공정부터 지하 깊은 암석층에 주입하여 수천 년간 안전하게 가두는 지질학적·공학적 메커니즘을 다룬다. 단순한 환경 구호를 넘어 포집 설비의 효율, 주입 압력과 지층 밀폐성, 누출 위험 감시 및 탄소 배출권 시장과의 제도적 연계를 아우르는 전문적인 담론을 이해하도록 돕는다.

## 학습 범위

`news_formal`은 탄소 포집·저장(CCS) 인프라 구축, 기후변화 협약, 국가 온실가스 감축목표(NDC)와 배출권 거래제를 다루는 정책·학술 보도의 공식 register다. `native_spoken`은 포집 플랜트 현장, 시추 플랫폼, 모니터링 관제실 등에서 엔지니어와 운영 인력이 공정 변수와 안전성을 조율할 때 사용하는 실무 구어 표현이다. 탄소를 단지 모으는 것과 지하 깊은 지층에 영구 격리하는 것의 차이를 명확히 이해하고, 공학적 타당성과 지질학적 안전성을 균형 있게 설명할 수 있는 어휘 체계를 구축한다.
