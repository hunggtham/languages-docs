# 음식 포장 순환과 재사용 시스템을 설계하는 언어

일회용 포장을 줄이는 일은 용기를 한 번 더 쓰자는 구호만으로 끝나지 않는다. 어떤 재질을 고르고, 누가 용기를 회수하며, 어디서 세척하고, 식품 안전을 어떻게 입증할지까지 하나의 운영 체계로 설계해야 한다. 이 주제는 식품 기업, 배달 플랫폼, 지자체와 소비자가 포장의 전환 비용과 책임을 논의할 때 필요한 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 포장 규제, 식품 안전, 자원 순환과 기업의 전환 계획을 보도하거나 분석할 때 쓰인다. `native_spoken`은 매장 직원과 소비자가 보증금, 반납 동선과 용기 상태를 이야기할 때 들을 수 있고, `slang_online`에 가까운 `풀링` 같은 표현은 업계 실무 대화에서 영어식 명사로 굳어진 용례를 보여 준다. 재사용을 무조건 친환경이라고 단정하지 않고, 세척 에너지와 회수 거리까지 포함해 시스템 전체를 비교하는 것이 핵심이다.
