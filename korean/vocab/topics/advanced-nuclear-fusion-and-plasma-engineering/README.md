# 핵융합과 플라스마 공학의 언어

핵융합과 플라스마 공학은 바닷물에 무한히 존재하는 중수소와 삼중수소를 원료로 삼아 태양의 에너지 생성 원리를 지상에서 안전하게 재현하려는 인류 문명의 궁극적인 청정에너지 기술이다. 수억 도에 달하는 초고온 플라스마를 공중에 띄워 가두는 첨단 전자기 제어에서부터 막대한 중성자 열부하를 흡수하고 연료를 스스로 증식시키는 극한 재료·원자로 공학까지 물리학과 기계·전기 공학의 정수가 집약되어 있다. 본 주제에서는 현대 핵융합 발전 연구와 차세대 에너지 실증 현장에서 필수적으로 쓰이는 핵심 전문 용어를 체계적으로 익힌다.
