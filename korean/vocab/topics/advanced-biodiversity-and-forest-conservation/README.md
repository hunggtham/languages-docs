# 생물다양성과 산림 보전의 언어

숲을 단순한 녹지로 보지 않고 종의 관계, 서식지의 연결, 유전적 회복력과 보전 정책의 언어로 읽는다. 과학 보도와 현장 대화에서 생태계의 변화를 설명하고 시민의 보전 활동을 조정하는 표현을 익힌다.

## 학습 파일

## 학습 범위

`news_formal`은 생물다양성 정책, 환경영향평가와 과학 보도에서 종과 서식지의 변화를 정밀하게 설명할 때 쓰인다. `native_spoken`은 조사 현장, 시민 과학 모임과 산림 관리 대화에서 전문어를 풀어 말할 때 자연스럽다. 전문 용어는 단순한 번역어로 외우기보다 어떤 생태적 관계와 관리 결정을 지시하는지 함께 파악해야 한다.
