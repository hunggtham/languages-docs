# 히트펌프 계통 연계와 유연성의 언어

히트펌프를 많이 설치하는 것만으로는 전기화가 완성되지 않는다. 난방 수요가 몰리는 시간, 배전망의 제약, 실내 쾌적도와 전력시장 신호를 함께 읽고 장비의 운전 시점을 조정해야 한다. 이 주제에서는 열수요를 전력계통이 활용할 수 있는 유연한 자원으로 바꾸는 말과, 그 과정에서 생기는 기술적·시장적 판단을 익힌다.

## 학습 범위

`news_formal`은 전력시장, 계통운영과 전기화 정책을 설명할 때 쓰인다. `native_spoken`은 설비 운영자와 수요관리 담당자가 실제 운전 시간, 불편 허용 범위와 비용을 조율할 때 자연스럽다. 핵심은 히트펌프를 개별 제품으로만 보지 않고, 건물의 열관성과 제어 가능성을 묶어 계통의 피크와 제약에 응답하는 자원으로 이해하는 데 있다.
