# 민속식물학과 전통지식의 생태 언어

식물 이름과 약용 경험을 단순한 민간 정보가 아니라 공동체의 기억, 권리, 연구 윤리와 연결해 읽는다. 이 주제는 현장 조사에서 기록한 전통지식을 유전자원 접근, 이익공유, 종자와 생태계 보전의 언어로 확장한다.

## 학습 범위

`news_formal`은 생물자원 정책, 연구 윤리와 국제 협약을 정확하게 설명할 때 쓰인다. `native_spoken`은 마을 조사, 씨앗 나눔과 채집 경험을 이야기할 때 자연스럽다. 특정 공동체의 지식을 낭만화하거나 무료로 가져갈 수 있는 정보처럼 다루지 않고, 누가 알고 누가 결정하며 어떤 보상을 받을지를 함께 묻는 것이 이 주제의 핵심이다.
