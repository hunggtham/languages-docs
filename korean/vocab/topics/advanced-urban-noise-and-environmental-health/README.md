# 도시 소음과 환경 건강의 언어

교통과 공사에서 생기는 소리가 단순한 불편을 넘어 수면, 청각, 스트레스와 도시의 권리 문제로 이어지는 과정을 읽는다. 측정값을 건강 영향과 주민 협의에 연결하는 전문어를 익힌다.

## 학습 범위

`news_formal`은 환경 측정, 건강영향평가와 도시 정책을 정밀하게 말할 때 쓰인다. 주민 설명과 상담에서는 `정온권`, `소음민감도`처럼 체감과 권리를 드러내는 표현이 중요하다. 숫자 하나로 결론을 내리지 않고 시간대, 반복성, 개인의 취약성과 공간의 음향환경을 함께 판단하는 어휘 묶음이다.
