# 신경기술과 뇌-컴퓨터 인터페이스의 언어

뇌의 활동을 읽고 자극하는 기술이 재활과 의사소통을 어떻게 바꾸는지 살핀다. 연구실의 신호 처리, 환자와 개발자의 협업, 그리고 신경 데이터의 권리를 한 흐름으로 연결해 배운다.

## 학습 범위

`news_formal`은 신경공학·재활의학·규제 논의에서 신호와 기전, 증거 수준을 구분할 때 쓰인다. `native_spoken`은 연구자·임상의·개발자가 장치의 반응과 사용 경험을 설명할 때 들을 수 있는 전문 구어 register다. 침습적 장치의 가능성을 과장하지 않고, 안전·자율성·신경 데이터의 권리를 함께 말하는 표현을 익힌다.
