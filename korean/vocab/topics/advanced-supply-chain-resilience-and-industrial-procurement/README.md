# 공급망 회복력과 산업 조달

원자재와 부품이 국경을 여러 번 오가는 산업에서는 가격만 낮추는 조달 전략이 갑작스러운 수출 규제, 물류 지연과 품질 문제를 견디지 못할 수 있다. 이 topic은 공급처를 분산하고 재고·생산능력·원산지를 확인하면서도 비용과 납기를 함께 관리하는 언어를 하나의 업무 흐름으로 연결해 읽도록 돕는다.

## 학습 범위

`news_formal`은 무역 규제, 산업정책과 기업의 공급망 위험을 분석하는 공식·정책 register다. `native_spoken`은 구매·생산 회의에서 납기, 물량과 생산능력을 조율할 때 쓰이는 현재적 업무 표현이다. 공급망을 단순히 “국산화”하거나 “재고를 많이 쌓는 것”으로 오해하지 않도록, 위험 분산·검증·운영 속도를 서로 다른 층위로 나누어 익힌다.
