# 연속 흐름 화학과 마이크로리액터의 언어

마이크로리액터와 연속 흐름 화학은 기존의 배치(Batch) 방식 반응기의 한계를 극복하고, 초고속 열교환, 탁월한 질량 이동, 그리고 극한 반응 제어를 통해 의약품 및 정밀 화학 제조 공정을 혁신하는 최첨단 그린 화학 기술 분야입니다. 이 토픽에서는 연속 흐름 공정에서 쓰이는 전문 어휘와 콜로케이션을 체계적으로 학습합니다.
