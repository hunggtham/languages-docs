# 사용후 배터리와 전력망 저장의 순환 설계

전기차에서 나온 배터리를 전력망 저장장치로 돌려 쓰려면 단순히 배터리를 다시 연결하는 것만으로는 부족하다. 성능 열화와 안전 여유를 진단하고, 전력망의 피크저감 요구와 회수·재활용 공정을 한 흐름으로 설계해야 한다. 이 주제는 산업 기사, 정책 보고서, 현장 회의에서 사용후 배터리의 이차사용과 금속 회수까지 논의하는 고급 어휘를 연결한다.

## 학습 범위

`news_formal`은 배터리 규제, 순환경제와 전력시장 보고서에서 쓰이는 표현이고, `native_spoken`은 엔지니어가 안전성과 운영 조건을 조율할 때 쓰이는 표현이다. 이 파일은 배터리의 수명 연장만 강조하지 않고, 진단 불확실성·전력망 운전·최종 금속 회수까지 함께 살피는 관점을 연습하도록 구성했다.
