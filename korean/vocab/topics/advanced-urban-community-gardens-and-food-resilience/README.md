# 도시 공동체 텃밭과 먹거리 회복력의 언어

이 lesson은 텃밭을 단순한 취미 공간이 아니라 지역의 생산·분배·돌봄·비상 대응을 연결하는 생활 기반으로 읽는다.

## 학습 파일

- [도시 텃밭과 지역 먹거리 회복력](./01-urban-community-gardens-and-food-resilience.md) — `도시텃밭분양`, `유휴부지경작`, `공공급식연계`, `잉여농산물매칭`, `식품나눔냉장고`, `지역농산물우선구매`, `소규모생산자판로`, `공동조리공간`, `비상먹거리지원`, `주민먹거리계획`, `식생활교육거점`, `식품회수체계`, `도시형식량비축`, `취약계층식품접근`, `먹거리위기대응`
