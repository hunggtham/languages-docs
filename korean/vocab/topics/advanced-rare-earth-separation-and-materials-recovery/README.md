# 희토류 분리와 소재 회수

폐영구자석과 산업 부산물에서 희토류를 골라내는 공정을 따라가며, 액상 분리·고체 회수·자석 소재의 관계를 익힌다. 실험실의 수치와 산업 현장의 공급망 판단을 함께 읽을 수 있도록 전문어의 공정상 역할과 register를 구별한다.

각 target은 희토류 정제와 폐자석 회수라는 한 공정 서사 안에서 설명하며, 읽기 지문은 15개 target을 모두 자연스럽게 포함한다.
