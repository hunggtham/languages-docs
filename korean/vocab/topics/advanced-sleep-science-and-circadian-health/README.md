# 수면 과학과 일주기 건강의 언어

잠을 단순히 오래 자는 문제가 아니라 생체 시계, 빛 노출, 수면 압력과 사회적 일정이 서로 맞물리는 조절 체계로 읽는다. 이 주제는 수면 연구 기사와 교대근무·건강 담화에서 수면의 질과 시간대를 정밀하게 설명하는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 수면의학 연구, 공중보건 보고서와 교대근무 정책에서 쓰인다. `native_spoken`은 수면 습관, 출퇴근과 생활 리듬을 설명하는 일상 대화에서 들을 수 있다. 같은 “잠을 못 잔다”라도 수면량, 수면 구조, 생체 시계의 위상과 사회적 시간표 중 무엇이 어긋났는지 구분하는 것이 핵심이다.
