# 신경다양성과 일터 접근성

신경다양한 구성원이 자신의 강점을 발휘하려면 개인에게 적응을 요구하기보다 감각, 소통, 업무 설계를 함께 조정해야 한다. 이 주제에서는 진단명을 소비하지 않고 실제 일터에서 필요한 편의와 협업 언어를 익힌다.

## 학습 파일

## 학습 범위

`news_formal`은 장애인 고용 정책과 조직 설계의 공적 담화에서, `native_spoken`은 동료 간 협업과 면담에서 쓰인다. 개인을 문제로 규정하지 않고 환경과 업무 방식의 선택지를 넓히는 관점을 중심으로 읽는다.
