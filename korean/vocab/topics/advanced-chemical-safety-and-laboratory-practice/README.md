# 화학 분석과 실험실 안전의 언어

시료를 측정하는 일은 숫자를 얻는 데서 끝나지 않는다. 분석법의 성능, 오염 가능성, 측정 불확실성, 작업자 노출을 함께 점검해야 결과를 재현하고 안전하게 보고할 수 있다.

## 학습 파일

- [분석법을 검증하고 실험실 위험을 줄이다](./01-method-validation-and-laboratory-safety.md) — `분석법 밸리데이션`, `정량한계`, `매질효과`, `교차오염`, `인증표준물질`, `검량선`, `회수율`, `측정불확도`, `측정소급성`, `희석배수`, `시약공백`, `공정서`, `위해성평가`, `노출경로`, `국소배기`

## 학습 범위

`news_formal`은 시험기관 보고서, 규제 문서와 사고 조사에서 분석 결과의 신뢰도와 책임을 설명할 때 쓰인다. `native_spoken`은 연구자와 실험실 담당자가 시료 준비, 장비 점검과 작업자 보호를 협의할 때 자연스럽다. 수치 하나를 확정적 사실로 과장하지 않고, 오차·오염·노출의 경로를 분리해 말하는 연습까지 함께 한다.
