# mRNA 치료제와 지질 나노입자의 언어

mRNA 치료제와 지질 나노입자(LNP) 기술은 유전 암호 정보를 세포 내로 직접 전달하여 체내에서 치료용 단백질이나 방어 항원을 스스로 생산하게 만드는 현대 바이오 의약학의 혁신적 분야이다. 불안정한 단일 가닥 RNA를 분해 효소로부터 보호하고 세포막을 안전하게 통과시키기 위한 정밀한 나노 제형 설계와 엔도솜 탈출, 그리고 표적 전달 기술이 이 분야의 핵심을 이룬다. 본 주제에서는 분자 수준의 염기 변형 및 전달체 합성 공정에서부터 체내 동태, 정맥 투여, 면역 반응 유도, 유통 안정성에 이르는 mRNA-LNP 플랫폼 전반의 첨단 전문 어휘를 체계적으로 학습한다.
