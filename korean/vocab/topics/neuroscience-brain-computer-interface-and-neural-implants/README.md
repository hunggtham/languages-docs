# 뇌-컴퓨터 인터페이스 및 신경보철학의 뇌과학적 언어

뇌-컴퓨터 인터페이스 및 신경보철학(Brain-Computer Interface, Neural Prosthetics, and Neuroengineering)은 대뇌 피질의 신경세포 신호를 전극으로 포착하고 인공지능 디코딩 알고리즘으로 해석하여 사지 마비 환자의 로봇 의수를 제어하거나 감각을 복원하는 융합 뇌신경공학 분야입니다. 본 단원에서는 침습형 뇌컴퓨터 인터페이스 전극, 신경신호 디코딩 머신러닝 알고리즘, 대뇌피질 운동영역 신경신호 기록, 광유전학 신경회로 정밀제어 기술, 뇌파 기반 정서인식 생체피드백, 신경보철장치 인공망막 시각복원, 미세유체 신경인터페이스 프로브, 경두개 자기자극 비침습 뇌조절, 시냅스 가소성 장기강화 메커니즘, 신경염증 생체적합성 하이드로겔, 뇌신경망 기능적 자기공명영상, 무선 생체삽입형 신경신호 송수신기, 척수손상 신경재생 전자약 치료, 신경윤리 인간증강 뇌프라이버시, 미래 뇌신경공학 뉴로모픽 융합에 이르는 15개 핵심 전문 어휘를 학습합니다.
