# 정신건강 위기 대응과 지역사회 돌봄의 언어

정신응급 상황에서 안전을 확보하고, 입원 중심 대응을 지역사회 회복과 연결하는 전문 어휘를 익힌다. 위기 당사자의 권리와 선택을 존중하면서 위험 평가, 사례관리, 동료지원, 퇴원 이후의 연속성을 함께 읽는다.

## 학습 범위

`news_formal`은 정신건강 정책, 법적 절차와 공공서비스를 설명할 때 쓰인다. `native_spoken`은 상담·응급 현장에서 당사자와 가족에게 절차를 풀어 말할 때 자연스럽다. `slang_online` 대신 권리와 회복을 다루는 contemporary 전문어를 중심으로, 위기 순간의 조치와 장기적인 지역사회 정착을 하나의 흐름으로 묶는다.
