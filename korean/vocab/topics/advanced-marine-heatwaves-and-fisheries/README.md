# 해양열파와 수산업 변화의 언어

바닷물이 비정상적으로 따뜻해질 때 생물의 내열 범위, 먹이망, 산란과 어장의 위치가 어떻게 달라지는지 읽는다. 관측 자료의 전문어와 어민·정책 담당자가 현장에서 조업 변화를 조율할 때 쓰는 표현을 하나의 흐름으로 익힌다.

## 학습 범위

`news_formal`은 해양 관측, 수산자원 평가와 기후 정책을 정밀하게 말할 때 쓰인다. `native_spoken`은 어민·연구자·공무원이 조업 시기, 어장 위치와 수입 위험을 조율할 때 들을 수 있는 표현이다. 수온 자체만 보지 않고 서식 한계, 종조성, 번식 시기와 어획 결과가 연결되는 과정을 함께 판단하는 어휘 묶음이다.
