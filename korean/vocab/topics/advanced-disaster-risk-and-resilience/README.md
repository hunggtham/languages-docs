# 재난 위험과 공동체 회복의 언어

재난을 단순한 사건이 아니라 위험을 줄이고, 피해를 분배하며, 현장에서 회복하는 사회적 과정으로 읽는다. 정책 기사와 현장 대화에서 함께 쓰이는 고급 표현을 통해 대응의 단계와 책임의 구조를 구별한다.

## 학습 범위

`news_formal`은 재난 정책·도시 계획·공공 보고서에서 쓰이는 분석어이고, `native_spoken`은 주민 설명회와 현장 브리핑에서 실제로 조정과 행동을 말할 때 쓰이는 표현이다. 같은 재난이라도 위험의 분포, 대피할 수 있는 조건, 복구의 속도가 다를 수 있으므로 피해를 개인의 준비 부족으로만 설명하지 않는다.
