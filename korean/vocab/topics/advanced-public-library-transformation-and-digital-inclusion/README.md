# 공공도서관 전환과 디지털 포용

공공도서관이 책을 보관하는 곳을 넘어 디지털 접근, 정보 중개, 시민 학습을 연결하는 기반으로 어떻게 바뀌는지 살펴본다. 디지털 기기와 인터넷을 제공하는 데서 그치지 않고, 장애·언어·소득·세대에 따른 접근 조건과 이용자의 권리까지 함께 설명하는 고급 어휘를 익힌다.

## 학습 범위

`news_formal`은 도서관 정책, 공공서비스 전환과 권리 담론을 설명할 때 쓰이고, `native_spoken`은 사서와 이용자가 기기 사용, 상담과 프로그램 참여를 조율할 때 자연스럽다. `slang_online`은 이 주제의 전문성과 권리 감각을 흐릴 수 있어 억지로 넣지 않았다. 서비스가 “온라인으로 있다”는 사실보다 실제로 누구나 이해하고 이용할 수 있는지, 그리고 도서관이 중립적인 정보 매개 공간으로 책임을 지는지를 함께 읽는다.
