# 정밀영농과 센서 거버넌스의 언어

작물의 상태를 세밀하게 읽는 기술이 농가의 의사결정과 공공 데이터 정책에 어떻게 연결되는지 익힌다. 위성·토양·기계 센서가 내놓는 수치만 보는 것이 아니라, 측정의 한계와 데이터 권한, 현장 자율성까지 함께 읽는 주제다.

## 학습 파일

- [센서 데이터를 농업 의사결정으로 연결하다](./01-precision-agriculture-and-sensor-governance.md) — `정밀영농`, `가변시비`, `처방지도`, `토양수분장력`, `생육모니터링`, `다중센서융합`, `데이터동화`, `엣지분석`, `측정사각지대`, `교정주기`, `센서드리프트`, `데이터출처사슬`, `기기호환성`, `농가자율성`, `디지털농정`

## 학습 범위

`news_formal`은 농업 정책, 데이터 표준과 기술 실증을 보고할 때 쓰이는 정밀한 공식어다. `native_spoken`은 농업기술센터, 장비 업체와 농가가 수치의 신뢰도와 실제 작업 가능성을 협의할 때 나타난다. 이 lesson은 자동화가 늘어날수록 누가 측정값을 해석하고 결정권을 갖는지 묻는 읽기 습관을 연습한다.
