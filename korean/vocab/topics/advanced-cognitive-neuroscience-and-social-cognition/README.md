# 뇌와 사회적 인지를 읽는 언어

뇌의 작동을 단순히 지능이나 의지의 문제로 환원하지 않고, 학습·감정·타인 이해가 어떤 예측과 조절 과정을 거치는지 살핀다. 이 주제는 연구 보도, 임상적 대화와 일상적인 자기 관찰에서 만나는 인지신경과학 어휘를 연결한다.

## 학습 범위

`news_formal`은 뇌 영상, 학습 연구와 인지과학 보도에서 기전과 증거 수준을 구분할 때 쓰인다. `native_spoken`은 상담, 교육과 직장 대화에서 집중·감정·피로를 설명할 때 들을 수 있는 전문 구어 register다. `뇌안개`처럼 최근 일상에서 널리 쓰이는 표현은 의학적 진단명과 혼동하지 않도록 맥락을 함께 익힌다.
