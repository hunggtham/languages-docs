# 플랫폼 노동과 노동시장 전환

플랫폼이 일을 배분하고 평가하는 방식, 그리고 자동화와 산업 재편 속에서 노동자가 수입과 경력을 옮겨 가는 과정을 설명하는 고급 어휘를 익힌다. 법적 지위와 일상의 체감 사이를 연결해 읽도록 구성했다.

플랫폼 노동자가 겪는 대기·평가·수입 변동을 노동시장 전환과 연결해, 개인의 적응만이 아니라 계약 구조와 공공 지원의 책임까지 함께 생각하게 한다.
