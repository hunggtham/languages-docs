# 우주 비행 운용과 궤도 임무

우주 임무는 발사 순간에 끝나지 않는다. 위성을 원하는 궤도에 올리고, 자세와 통신을 유지하며, 제한된 연료와 열 환경 속에서 임무를 오래 수행하려면 정밀한 운용 언어가 필요하다. 이 주제에서는 우주 비행의 물리적 과정과 지상 운용을 설명하는 고급 어휘를 익힌다.

## 학습 범위

`news_formal`은 발사체·위성·우주정책 보도와 기술 보고서에서 궤도, 안전, 임무 성능을 정확하게 설명할 때 쓰인다. `native_spoken`은 관제팀과 엔지니어가 운용 순서와 이상 징후를 협의할 때 자연스럽다. 전문어를 단순히 외우기보다 우주선의 움직임, 지상 통제와 임무 설계가 어떻게 연결되는지 읽는 데 초점을 둔다.
