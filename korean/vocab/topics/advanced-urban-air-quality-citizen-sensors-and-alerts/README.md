# 도시 대기질 시민센서와 경보의 언어

도시의 공기는 한 개의 측정소 숫자로 끝나지 않는다. 이 lesson은 주민이 설치한 센서가 공공 측정망과 어떻게 비교되고, 불확실한 수치를 어떻게 보정하며, 위험 경보를 누구에게 어떤 행동으로 전달해야 하는지 다룬다.

## 학습 파일

- [도시 대기질 시민센서와 공공경보](./01-urban-air-quality-citizen-sensors-and-alerts.md) — `대기질측정망`, `저가센서`, `센서교정`, `보정계수`, `교차검증`, `공간해상도`, `이동측정망`, `오염도지도`, `데이터품질관리`, `고농도예보`, `초과경보`, `경보발령`, `비상저감조치`, `취약계층보호`, `노출추정`

`news_formal` 어휘는 측정의 신뢰도, 지자체 경보와 저감 정책을 정확히 논할 때 쓰인다. `native_spoken` 어휘는 주민이 센서를 함께 설치하고 앱 알림을 해석하는 장면에서 살아난다. 핵심은 숫자를 많이 모으는 것이 아니라, 비교 가능한 자료와 실행 가능한 공공 안내로 연결하는 일이다.
