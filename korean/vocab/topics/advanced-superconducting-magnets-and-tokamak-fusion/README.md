# 고온 초전도 자석과 토카막 핵융합의 언어

고온 초전도 자석과 토카막 핵융합 기술은 섭씨 1억도 이상의 초고온 플라스마를 강력한 자기장으로 진공 용기 내부에 완벽히 가두어 인공태양 에너지를 지상에서 구현하려는 현대 에너지 물리학과 극한 전자기 공학의 최전선이다. 기존 저온 초전도체의 물리적 한계를 뛰어넘는 희토류 기반 고온 초전도 선재의 상용화는 소형·고효율 핵융합로 설계를 가능하게 하여 상업용 핵융합 발전의 실현 시기를 획기적으로 앞당기고 있다. 본 주제에서는 테슬라 단위의 극한 자기장을 형성하는 초전도 도체 제작, 극저온 헬륨 냉각 시스템, 기가파스칼급 로렌츠 전자기력 제어, 그리고 플라스마 열부하 분산과 중성자 차폐에 이르는 토카막 핵심 시스템 전반의 고도화된 전문 학술 어휘를 체계적으로 학습한다.
