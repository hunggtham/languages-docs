# 재생농업과 토양 탄소의 언어

재생농업은 투입재를 줄이는 구호가 아니라 토양 생태계의 기능을 회복하면서 생산성과 회복력을 함께 설계하는 농업 전환이다. 이 주제에서는 농법의 원리, 탄소 측정, 농가의 전환 비용과 보상 제도를 한 흐름으로 읽는다.

## 학습 범위

`news_formal`은 농업 정책, 탄소 검증과 보상 설계를 설명할 때 쓰인다. `native_spoken`은 농민·기술자·연구자가 농법을 바꾸며 겪는 토양 상태와 작업성의 변화를 말할 때 쓰인다. 농법 이름만 나열하지 않고 탄소 저장의 측정 불확실성, 추가 비용과 장기 회복력을 함께 살피도록 구성했다.
