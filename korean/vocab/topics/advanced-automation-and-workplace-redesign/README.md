# 자동화와 일의 재설계

자동화는 사람의 일을 단순히 없애거나 기계로 바꾸는 과정이 아니다. 어떤 판단을 시스템에 맡기고, 어떤 숙련을 남기며, 문제가 생겼을 때 누가 개입하고 책임질지를 다시 설계하는 과정이다. 이 주제에서는 기술 도입의 효율만이 아니라 노동의 질, 통제권과 책임 구조를 함께 읽는 고급 어휘를 익힌다.

## 학습 범위

`news_formal`은 자동화 정책, 노동시장 보고서와 AI 거버넌스에서 구조적 효과와 책임을 말할 때 쓰인다. `native_spoken`은 현장 관리자와 실무자가 도구의 불편, 적응 과정과 사람의 재량을 협의할 때 자연스럽다. 자동화의 도입을 무조건 진보나 위협으로 단정하지 않고, 숙련·판단·감독의 분배가 어떻게 바뀌는지 설명하는 데 초점을 둔다.
