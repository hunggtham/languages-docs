# 디지털 증거와 포렌식 절차의 언어

휴대전화, 클라우드와 업무 시스템에 남은 자료는 사건의 실마리가 될 수 있지만, 발견됐다는 사실만으로 곧바로 증거가 되는 것은 아니다. 이 주제는 디지털 자료를 수집하고 보존하며, 법정에서 신뢰할 수 있는 근거로 설명하는 과정을 다룬다.

## 학습 범위

`news_formal`은 수사기관·법원이 자료의 수집 근거와 증거 능력을 설명할 때 쓰는 법률·정책 register다. `native_spoken`은 보안 담당자와 포렌식 분석가가 실제 장치와 기록을 확인하며 쓰는 전문 구어 register다. 자료를 확보했다는 사실과 그 자료를 믿을 수 있게 제시하는 절차를 구분하는 것이 핵심이다.
