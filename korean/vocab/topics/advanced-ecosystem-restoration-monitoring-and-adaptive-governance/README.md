# 생태계 복원 모니터링과 적응형 거버넌스의 언어

생태계 복원을 나무를 심는 단일 사업이 아니라 기준선·반응·책임을 함께 관리하는 학습 과정으로 읽는다. 장기 모니터링 자료를 주민·과학자·행정이 공동으로 해석하고, 불확실성에 맞춰 개입을 조정하는 정책 언어를 익힌다.

## 학습 범위

`news_formal`은 복원 평가, 환경 행정과 과학 보도에서 기준·성과·책임을 정밀하게 설명할 때 쓰인다. `native_spoken`은 주민 협의와 현장 조사에서 자료의 한계와 관리 조정을 풀어 말할 때 자연스럽다. 각 표현은 결과를 단정하는 말이 아니라 증거를 모아 다음 결정을 조정하는 말로 익힌다.
