# 뉴로모픽 비전 센서와 이벤트 기반 카메라의 언어

생체 망막의 정보 처리 방식을 모방하여 고속 변화만을 비동기적으로 감지하는 뉴로모픽 비전 센서(DVS)와 이벤트 기반 카메라의 핵심 전문 용어와 어휘를 다룹니다. 기존 프레임 기반 카메라의 한계를 극복하고 초고속, 초저전력, 초고다이내믹레인지(HDR) 환경에서 시각 정보를 처리하는 차세대 머신비전 및 AI 기술을 심도 있게 학습합니다.
