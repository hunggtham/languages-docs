# 상어 비늘 리블렛 미세구조 유체 저항 저감 표면 기술의 언어

상어 피부의 미세 리블렛(riblet) 리지 구조와 난류 경계층 와류 제어 원리를 모사하여, 유체 저항 저감 및 연료 효율 극대화, 방오·초발수 표면 처리, 롤투롤 나노임프린팅 양산 공정을 다루는 첨단 생체모사 유체역학 및 기능성 표면 공학 어휘 단원이다.
