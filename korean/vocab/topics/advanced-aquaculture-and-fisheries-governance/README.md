# 양식 산업과 수산 자원 거버넌스의 언어

양식 생산성을 높이는 기술만이 아니라, 질병·사료·유전 자원·배출수와 어장 공간을 함께 관리할 때 쓰는 고급 한국어를 학습한다. 연구실의 종자 관리, 양식장 운영, 행정 규제와 지역 어민의 협의를 하나의 흐름으로 읽는다.

## 학습 범위

`news_formal`은 수산 과학, 양식 정책, 식품 안전과 환경 규제의 자료를 정밀하게 말할 때 쓰인다. `native_spoken`은 양식업자·연구자·공무원이 생산 차질과 관리 대안을 조율할 때 실제로 들을 수 있는 표현이다. 생산량만 비교하지 않고 질병 위험, 사료 효율, 배출 영향과 지역 생태계의 수용력을 함께 판단하는 어휘 묶음이다.
