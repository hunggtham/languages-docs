# 뉴로모픽 동적 시각 센서와 이벤트 카메라의 언어

이 토픽은 생체 망막을 모사하여 빛의 명암 변화만을 비동기적으로 감지하는 뉴로모픽 동적 시각 센서(DVS) 및 이벤트 카메라 기술과 관련된 전문 어휘를 다룹니다. 마이크로초 단위의 초고속 시간 분해능, 모션 블러 없는 고속 인지, 스파이킹 신경망(SNN) 비전 처리를 포함한 차세대 광전자 지능 센서의 핵심 개념들을 체계적으로 학습할 수 있습니다.

## 학습 파일
- [뉴로모픽 동적 시각 센서와 이벤트 카메라의 이해](./01-neuromorphic-visual-sensors-and-event-cameras.md) — 뉴로모픽동적시각센서, 이벤트기반비동기픽셀, 마이크로초초고속시간분해능, 생체모사망막신경칩, 스파이킹신경망시각처리, 고동적범위저조도촬영, 모션블러원천차단센서, 자율주행초고속물체인식, 초저전력시각정보인코딩, 온디바이스뉴로모픽비전, 실시간엣지컴퓨팅비전, 차세대광전자지능센서, 생체신경모사시각소자, 고속인지비전프로세서, 미래지능형컴퓨터비전

이 학습 자료는 첨단 컴퓨터 비전, 로보틱스, 자율주행 분야에서 활용되는 뉴로모픽 센서 및 이벤트 기반 비전 기술의 전문 용어를 정확하게 이해하고 구사하는 데 도움을 줍니다.
