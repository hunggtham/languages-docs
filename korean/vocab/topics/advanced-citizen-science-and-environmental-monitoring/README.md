# 시민 참여로 환경 변화를 기록하고 검증하는 언어

환경 문제를 관찰하는 일은 전문 연구자만의 몫이 아니다. 시민이 같은 규칙으로 사진과 위치, 관찰 조건을 기록하면 넓은 지역의 변화를 포착할 수 있지만, 자료의 품질과 개인정보 보호를 함께 설계해야 한다. 이 주제는 참여관측을 환경 정책에 연결하고 관측 편향과 검증 절차를 설명하는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 시민 자료를 연구와 정책에 활용할 때 필요한 품질관리, 개인정보 보호와 공개 기준을 설명하는 데 쓰인다. `native_spoken`은 동네 하천이나 공원에서 함께 관찰하고 이상 현상을 신고하는 대화에서 자연스럽다. 참여자가 많다는 사실만으로 자료가 대표성을 갖는 것은 아니므로 관찰 조건, 검증 방식과 공개 범위를 함께 읽는 것이 핵심이다.
