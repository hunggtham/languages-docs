# 시민 기록과 디지털 기억

시민이 직접 남긴 기록을 공동체의 기억으로 연결하고, 공개·접근·철회·맥락화의 원칙을 함께 판단하는 어휘를 익힌다. 이 주제는 기록과 공공기억의 일반론보다 참여형 운영과 시민 데이터의 책임 있는 사용에 초점을 둔다.

## 학습 범위

시민기록, 기록주권, 증언채록, 기억지도, 공동기술, 시민큐레이터, 출처계보, 기여이력, 열람이력, 공개등급, 접근협의, 삭제유예, 철회요청, 맥락주석, 관계망시각화를 다룬다. 기존의 전문 기록관리나 문화유산 디지털화 어휘를 반복하지 않고, 시민 참여와 플랫폼 운영에서 실제로 필요한 판단 표현을 골랐다.
