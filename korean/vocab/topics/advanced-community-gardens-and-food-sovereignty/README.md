# 공동체 텃밭과 먹거리 주권의 언어

주민이 땅을 함께 사용하고 씨앗·재배 지식·수확물을 나누면서 자기 지역의 먹거리 결정을 직접 만들어 가는 실천을 다룬다. 식량 공급의 거시적 안정성이나 일반적인 도시농업 소개와 겹치지 않도록, 공동체 소유·참여 규칙·돌봄과 정의의 언어에 초점을 둔다.

## 학습 파일

- [공동체 텃밭에서 먹거리 주권을 실천하는 말](./01-community-gardens-and-food-sovereignty.md) — `공동체텃밭`, `먹거리주권`, `농지접근권`, `도시농업공유지`, `주민경작협약`, `토종종자보전`, `수확물공유체계`, `생산자소비자연계`, `지역먹거리순환`, `기후적응재배`, `참여형먹거리거버넌스`, `먹거리정의`, `농사기술공유`, `텃밭돌봄순환`, `공동경작책임`

## 학습 범위

`news_formal`은 먹거리 정책, 주민 자치와 토지 이용을 분석하는 보고서에서 쓰인다. `native_spoken`은 주민 회의와 텃밭 현장에서 역할, 수확과 갈등을 조정할 때 자연스럽다. 토지를 함께 쓴다는 말이 곧 모든 책임과 권한이 같다는 뜻은 아니므로, 접근권·돌봄·의사결정의 차이를 구분해 익힌다.
