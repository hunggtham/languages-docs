# 도시 대피 경로와 접근 가능한 안내의 언어

도시 재난에서 대피는 출구를 알려 주는 일만이 아니다. 길을 읽기 어려운 사람, 이동 속도가 다른 사람, 구조 차량이 들어와야 하는 현장을 함께 고려해 안전한 이동 조건을 설계하는 일이다.

## 학습 범위

`news_formal`은 재난안전 계획·건축 기준·도시 운영 문서에서 쓰이는 표현이고, `native_spoken`은 주민 안내와 현장 브리핑에서 행동을 조정할 때 쓰인다. 접근 가능한 길찾기는 별도의 복지 서비스가 아니라 모든 사람이 경보를 이해하고 실제로 이동할 수 있게 만드는 대피 계획의 조건이다.
