# 전기열량 고분자와 고체 냉각 기술의 언어

전기열량 효과(Electrocaloric Effect, ECE)와 강유전체 고분자 기반의 고체 냉각 기술은 기존의 가스 압축식 냉동 시스템을 대체할 수 있는 차세대 친환경 냉각 기술입니다. 이 어휘집은 반도체 핫스팟 국소 냉각, 초박형 전자소자 열관리, 기계적 가동부가 없는 무소음 냉각 시스템 등 최첨단 고체 냉각 분야에서 사용되는 전문 어휘와 콜로케이션을 깊이 있게 다룹니다.

## 학습 파일
- [전기열량 고분자와 고체 냉각 기술](./01-solid-state-cooling-and-electrocaloric-polymers.md) — 전기열량고분자소재, 전기장유도온도변화, 강유전체박막냉각기, 고효율고체냉각소자, 극성쌍극자엔트로피변화, 상온무소음냉각시스템, 초박형전자소자열관리, 반도체핫스팟국소냉각, 유연전기열량냉각필름, 초저전력히트싱크대체, 기계적가동부없는냉동, 차세대열전기열량복합체, 고전계내전압신뢰성, 초소형마이크로칩열제어, 친환경스마트냉각플랫폼

이 학습 모듈을 통해 학습자는 최첨단 소재 공학 및 반도체 열관리 분야의 전문 한국어 표현을 완벽히 습득할 수 있습니다.
