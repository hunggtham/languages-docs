# 감염병 감시와 원헬스 대응을 설계하는 언어

감염병 대응은 환자가 생긴 뒤 치료를 늘리는 일만이 아니라, 사람·동물·환경 사이에서 위험이 어떻게 이동하는지 미리 읽고 개입하는 과정이다. 이 주제는 항생제 내성, 병원체 유전체, 하수 감시와 백신 정책을 함께 다루며 보건 당국의 보고서와 현장 협업에서 자주 만나는 고급 어휘를 연결한다.

## 학습 범위

`news_formal`은 감염병 감시, 내성 관리와 공중보건 정책을 근거와 불확실성에 맞게 보고할 때 쓰인다. `native_spoken`은 의사, 역학자, 수의사와 현장 담당자가 검사 결과와 대응 우선순위를 조율할 때 들을 수 있는 전문 구어 register다. 감시 수치 하나를 확정적 예언처럼 말하지 않고, 표본·검사 지연·행동 변화라는 조건을 함께 설명하는 것이 핵심이다.
