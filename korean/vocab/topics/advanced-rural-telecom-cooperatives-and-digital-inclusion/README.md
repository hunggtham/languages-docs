# 농촌 통신 협동조합과 디지털 포용의 언어

통신망을 외부 사업자가 설치하는 기반시설로만 보지 않고, 주민이 함께 소유하고 운영하며 누구나 참여할 수 있게 만드는 농촌의 디지털 포용을 읽는다.

## 학습 범위

`news_formal`은 협동조합의 소유 구조, 공공 지원과 지역 통신 정책을 설명하는 공식 담화에 쓰인다. `native_spoken`은 주민 회의와 현장 운영자가 비용, 신호와 이용 방법을 조정할 때 쓰는 실무어다. 이미 별도 주제로 다룬 광대역 구축·원격의료·공동체 광대역의 일반론과 겹치지 않도록, 이 파일은 주민 소유와 운영 역량, 참여의 조건에 초점을 둔다.
