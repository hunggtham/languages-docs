# 출판과 편집 실무의 언어

한 권의 책은 아이디어만으로 완성되지 않는다. 원고를 다듬고 권리를 조정하며, 독자에게 닿는 경로와 출간 뒤의 생명까지 설계해야 한다. 이 주제는 편집자·작가·출판사·독자가 출판 현장의 판단과 흐름을 말할 때 쓰는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 출판 계약, 편집 판단, 유통 구조와 시장의 변화를 보도하거나 분석할 때 쓰인다. `native_spoken`은 편집자와 작가가 원고를 논의하거나 독자가 책의 경험을 나눌 때 들을 수 있는 말이다. 한 권의 책을 만드는 과정과 독자가 책을 만나는 장면을 연결해, 단순한 번역어가 아니라 실제 선택의 기준을 익히는 것이 핵심이다.
