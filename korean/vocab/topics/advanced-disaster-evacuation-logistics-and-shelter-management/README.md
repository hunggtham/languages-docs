# 재난 대피 물류와 임시거처 운영

재난 때 사람을 단순히 안전한 곳으로 옮기는 데서 그치지 않고, 이동 경로·수용 능력·지휘·물자·귀환을 하나의 운영 체계로 설계하는 어휘를 익힌다.

## 학습 파일

- [대피 물류와 임시거처 운영](./01-disaster-evacuation-logistics-and-shelter-management.md) — `긴급수송`, `대피 동선`, `분산 대피`, `생활권 대피`, `임시거주시설`, `대피소 과밀`, `대피소 접근성`, `초과 수용`, `수용 한계`, `지휘 일원화`, `통합상황판`, `구호물자 우선배분`, `대피 지원 우선순위`, `귀환 기준`, `대피소 전환`

사람을 숫자로만 세지 않고 이동의 병목, 사람마다 다른 접근 조건, 임시거처의 운영 한계, 안전한 귀환의 판단까지 연결해 읽는다.
