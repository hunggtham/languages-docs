# 생체 삽입형 마찰대전 발전기와 무배터리 의료기기의 언어

최근 바이오메디컬 공학과 나노기술의 융합으로 환자의 신체 움직임과 생체역학적 에너지를 전기로 변환하여 구동하는 **인체삽입형마찰대전발전기(iTENG)** 연구가 활발히 진행되고 있습니다. 이러한 **무배터리체내이식의료기기**는 주기적인 배터리 교체 수술을 없애어 환자의 신체적·경제적 부담을 획기적으로 줄여주는 **미래지속가능의료전자기술**의 핵심으로 주목받고 있습니다. 본 레슨에서는 심장 박동 구동 인공심박조율기, 생체흡수성 마찰대전 박막, 체내 기계적 운동 전력 수확, 생체적합성 고분자 패키징 등 첨단 의공학 어휘를 상세히 학습합니다.

## 학습 파일
- [체내 삽입형 마찰대전 발전기와 무배터리 의료기기 전문 어휘](./01-implantable-triboelectric-medical-devices.md) — 인체삽입형마찰대전발전기, 심장박동구동인공심박조율기, 생체흡수성마찰대전박막, 체내기계적운동전력수확, 생체적합성고분자패키징, 무배터리체내이식의료기기, 횡격막호흡자가발전센서, 혈관맥동실시간혈류모니터링, 유연생체전기출력최적화, 면역거부반응최소화코팅, 자가구동신경자극의료기, 차세대바이오의공학소재, 체내삽입자가발전시스템, 생체분해성전자기계소자, 미래지속가능의료전자기술

이 학습 패키지는 고급 의공학 및 마찰대전 발전(Triboelectric Nanogenerator) 분야의 전문 어휘와 실제 연구 문맥에서 활용할 수 있는 풍부한 예문, 콜로케이션, 독해 지문을 제공합니다.
