# 물 안보와 기후 회복력

가뭄과 홍수에 대응하는 물 정책을 수자원 배분, 유역 관리, 도시 기반시설의 관점에서 읽는다. 기후 위기를 단순한 자연 현상이 아니라 공공 자원과 지역의 회복력을 설계하는 문제로 설명하는 표현을 익힌다.
