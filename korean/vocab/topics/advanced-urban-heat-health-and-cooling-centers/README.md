# 폭염 건강과 냉방 거점의 언어

폭염 대응은 기온을 예보하는 데서 끝나지 않는다. 누구나 잠깐 쉬고, 증상을 알아차리고, 필요한 의료·복지 지원으로 연결될 수 있도록 냉방 거점과 건강 안전망을 설계해야 한다. 이 주제는 행정 안내, 현장 대화, 역학 보고서가 만나는 표현을 다룬다.

## 학습 범위

`news_formal`은 폭염 대책, 건강 영향과 자원 배분을 보도·평가할 때 쓰인다. `native_spoken`은 주민, 돌봄 인력과 시설 운영자가 “어디서 쉬고 누구에게 연락할지”를 조정하는 말에서 자연스럽다. 임시 쉼터의 수를 늘리는 것뿐 아니라 운영시간, 접근성, 증상 대응과 의료 연계를 함께 살피는 것이 핵심이다.
