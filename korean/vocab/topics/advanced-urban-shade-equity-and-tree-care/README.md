# 도시 그늘 형평성과 가로수 돌봄의 언어

폭염에 강한 도시는 나무 수만 늘리는 곳이 아니라, 누구의 통학로와 생활권에 그늘이 끊기는지 확인하고 나무가 오래 자랄 조건까지 책임지는 곳이다. 이 lesson은 그늘의 분포를 형평성 지표로 읽고, 식재 뒤의 뿌리·토양·전정·갱신을 공공 관리의 언어로 연결한다.

## 학습 범위

`news_formal`은 폭염 적응, 예산 배분, 설계 기준과 수목 진단을 정밀하게 말할 때 쓰인다. `native_spoken`은 주민 회의와 현장 점검에서 그늘이 실제로 이어지는지, 나무를 베기 전에 무엇을 고쳐야 하는지 논의할 때 자연스럽다. 나무의 경관 가치를 칭찬하는 데서 멈추지 않고 접근성·건강·안전과 장기 돌봄을 함께 판단하는 것이 핵심이다.
