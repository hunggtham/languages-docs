# 전산언어학 및 자연어 처리 인공지능의 언어

전산언어학 및 자연어 처리 인공지능(Computational Linguistics and Natural Language Processing AI)은 인간 고유의 소통 체계인 자연어의 음운론, 형태론, 통사론, 의미론, 화용론을 컴퓨터 알고리즘과 심층 신경망을 통해 모델링하여 인간과 기계 사이의 지능적 소통을 가능케 하는 최첨단 인공지능 융합 학문 분야입니다. 본 단원에서는 LLM 파인튜닝, 시맨틱 롤 라벨링(의미역할부여), 단어 임베딩 벡터 공간, 트랜스포머 어텐션 메커니즘, 신경망 기계번역 정렬, 음성인식 음향음운 모델, 코퍼스 연어 분포, 감성분석 극성판별, 개체명 인식 및 지식그래프, 의존구문분석 트리 매핑, 생성형 AI 환각 완화, 다국어 음성합성 자연스러움, 형태소 분석 및 POS 태깅, RAG 검색증강생성, 그리고 미래 전산언어학에 이르는 15개 핵심 전문 어휘를 심도 있게 학습합니다.
