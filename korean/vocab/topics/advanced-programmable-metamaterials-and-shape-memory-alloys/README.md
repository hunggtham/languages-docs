# 프로그래머블 메타물질과 형상기억합금의 언어

이 주제는 최첨단 소재공학과 기계공학의 융합 분야인 프로그래머블 메타물질(Programmable Metamaterials)과 형상기억합금(Shape Memory Alloys, SMA)을 다룹니다. 가역적 기계적 변형, 온도 감응형 자가 변형 구조, 4차원 프린팅 자가 조립, 다중 안정성 메타구조, 소프트 모핑 날개 공학 등 차세대 능동 지능형 소재의 핵심 개념과 전문 어휘를 심도 있게 학습합니다.

## 학습 파일
- [프로그래머블 메타물질과 형상기억합금](./01-programmable-metamaterials-and-shape-memory-alloys.md) — 프로그래머블메타물질, 형상기억합금복합체, 기계적물성가역적변형, 온도감응형자가변형구조, 격자구조강성능동조절, 생체모사적응형외피, 사차원프린팅자가조립, 충격흡수다공성단위포, 열기계적히스테리시스제어, 초탄성우주전개구조물, 외력적응자가치유소재, 다중안정성기계적메타구조, 소프트모핑날개공학, 차세대능동지능형소재, 항공우주변형외피기술

본 주제의 어휘들은 항공우주, 로보틱스, 스마트 구조물 설계 분야에서 사용되는 고급 전문 어휘로 구성되어 있습니다.
