# 자산운용 및 퀀트 금융공학의 언어

자산운용 및 퀀트 금융공학(Asset Management and Quantitative Financial Engineering)은 현대 금융 시장의 방대한 데이터와 첨단 통계·수학 알고리즘을 융합하여 포트폴리오를 과학적으로 구축하고 리스크를 체계적으로 통제하는 금융의 최전선 학문 분야입니다. 본 단원에서는 팩터 기반 멀티팩터 포트폴리오, 베이지안 블랙-리터만 모형, 위험 기여도를 균등 분배하는 리스크 패리티, 통계적 차익거래 페어트레이딩, 공포지수(VIX) 헤지, 몬테카를로 확률 시뮬레이션, 사모대출펀드(Private Credit) 대체투자, 백테스팅 과적합(Overfitting) 방지 검증, 스마트 베타 ETF, 위험조정 수익 척도인 샤프지수, 절대수익 추구 헤지펀드 운용, 시장 충격 최소화 알고리즘 집행, 최적 리밸런싱 주기 설계, 최대낙폭(MDD) 방어 손절매, 그리고 차세대 인공지능 기반 미래 자산운용 퀀트 금융공학에 이르는 15개 핵심 전문 어휘를 체계적으로 학습합니다.
