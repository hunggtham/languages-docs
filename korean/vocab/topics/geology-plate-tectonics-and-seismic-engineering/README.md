# 판구조론 및 지진공학 방재의 언어

판구조론 및 지진공학 방재(Plate Tectonics, Seismic Engineering, and Geotechnical Disaster Mitigation)는 지구 판의 상대적 수렴과 섭입 메커니즘, 활성단층 고지진학 연대측정, 지진파 전파 특성, 그리고 건축물과 도심 인프라의 면진·제진·내진 보강 공학을 아우르는 지구물리학 및 구조공학 융합 분야입니다. 본 단원에서는 판구조론 섭입대 지진발생 단층, 지진격리받침 면진장치 설계, 활성단층 고지진학 연대측정, 지진파 스펙트럼 가속도 해석, 모호로비치치 불연속면 탐사, 건축물 점탄성 제진댐퍼 시공, 해구형 거대지진 쓰나미 경보, 지반 액상화 모래분출 위험평가, 지진조기경보 P파 감지 시스템, 변환단층 수평 주향이동 변위, 비선형 구조동역학 내진 해석, 도심 지하 단층선 3차원 모델링, 내진보강 철골 가새 보강공법, 지진 단층 파쇄대 암반역학, 미래 지구물리 지진공학 방재에 이르는 15개 핵심 전문 어휘를 학습합니다.
