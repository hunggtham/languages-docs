# 해양 플라스틱 오염과 미세 잔해의 흐름

눈에 보이는 폐기물부터 나노미터 규모의 입자까지 플라스틱이 바다로 들어오고 풍화되며 생태계와 어업으로 이동하는 과정을 읽는다. 현장 조사, 해양 정책, 어민의 경험이 만나는 지점에서 오염의 원인과 책임을 정밀하게 말하는 어휘를 익힌다.

## 학습 범위

`news_formal`은 해양 관측, 오염원 추적과 환경 정책을 정밀하게 말할 때 쓰인다. `native_spoken`은 어민·잠수 조사자·지자체 담당자가 해변과 양식장에 쌓이는 잔해를 설명하고 대응 우선순위를 조율할 때 들을 수 있는 표현이다. 입자의 크기만 외우지 않고 유출원, 표면의 화학적 성질, 생물체 안에서의 이동과 조사 방법을 하나의 인과 흐름으로 연결한다.
