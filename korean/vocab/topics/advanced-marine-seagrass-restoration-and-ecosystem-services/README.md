# 잘피 복원과 연안 생태계 서비스를 읽다

잘피는 얕은 바다의 경관을 꾸미는 식물에 그치지 않고 퇴적물, 탄소, 어류의 생활사를 함께 움직이는 생태계 기반시설이다. 이 폴더에서는 잘피장을 복원할 때 무엇을 측정하고 어떤 조건에서 회복을 판단하는지, 현장 연구와 환경정책에서 자주 만나는 표현을 묶어 익힌다.

## 학습 범위

이 lesson의 표제어는 해양 생태복원·연안 관리의 고급 명사와 전문적 결합 표현이다. `잘피장`과 `해초림`처럼 가까워 보이는 말도 공간 규모와 연구·관리 맥락이 어떻게 다른지 구분하고, 이식의 성공을 단순 생존이 아닌 서식처와 기능의 회복으로 해석한다.
