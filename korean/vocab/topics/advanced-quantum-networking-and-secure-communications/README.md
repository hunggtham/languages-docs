# 양자 네트워크와 보안 통신

양자 상태를 먼 거리로 보내고 여러 노드를 연결할 때 생기는 손실·측정·보안 문제를 하나의 네트워크 흐름으로 읽는다. 양자 기술을 만능 보안으로 과장하지 않고, 중계·메모리·인증·장치 의존성까지 함께 설명하는 고급 통신 어휘를 익힌다.

## 학습 범위

`news_formal`은 양자 네트워크 연구, 통신 표준과 국가 보안 정책을 정확히 설명하는 공식 register다. `native_spoken`은 연구자·관제자·보안 담당자가 장비 성능과 장애 대응을 회의에서 조율할 때 자연스럽다. `slang_online` 대신 현재 산업·연구 담론에서 실제로 쓰이는 contemporary 전문어를 중심으로 구성하되, 양자 채널의 물리적 한계와 보안 주장 사이의 간격을 함께 살핀다.
