# 미생물 연료전지와 환경 바이오센싱의 언어

현대 환경공학과 바이오테크놀로지 분야에서 미생물 연료전지(MFC) 기술은 폐수 내 유기물을 산화시키는 동시에 전기에너지를 회수하는 혁신적인 친환경 시스템으로 주목받고 있습니다. 특히 전기활성 박테리아의 세포외 전자전달 메커니즘을 활용한 바이오센서는 수질 생물학적 산소요구량(BOD) 측정과 무전원 수질 독성 실시간 감시를 가능하게 합니다. 본 학습 과정에서는 나노다공성 탄소 전극 복합체, 미생물 촉매 양극 계면, 바이오 전기화학적 신호 변환 등 최첨단 미생물 연료전지 및 바이오센싱 분야의 전문 어휘 15개를 엄선하여 심도 있게 다룹니다.
