# 사이버물리시스템 및 하이브리드 오토마타와 정형 검증의 언어

사이버물리시스템(CPS), 하이브리드 오토마타(Hybrid Automata), 도달 가능성 분석(Reachability Analysis), 모델 체킹(Model Checking), 시간 논리(LTL/CTL) 및 안전성 보장 무결성 검증을 다루는 소프트웨어공학 핵심 어휘

## 학습 구성
- 학습 본문: [08-formal-verification-and-hybrid-automata.md](./08-formal-verification-and-hybrid-automata.md)
- 포함 표제어 수: 15개 (B2-C2 고급 전문 학술 어휘)
- 종합 독해 단락: 15개 표제어를 모두 유기적으로 결합한 전문 학술 텍스트 (정확히 105어절) 및 베트남어 번역 수록

## 표제어 목록

1. **사이버물리시스템정형기법검증** - kiểm chứng phương pháp hình thức hệ thống thực-ảo CPS
2. **하이브리드오토마타도달가능성분석** - phân tích tính tới được của automata lai
3. **선형시상논리안전성성질모델체킹** - kiểm tra mô hình tính chất an toàn bằng logic thời gian tuyến tính LTL
4. **상태공간폭발문제추상화완화기법** - kỹ thuật giảm tải trừu tượng hóa vấn đề bùng nổ không gian trạng thái
5. **제어장벽함수전진불변성보장제어** - điều khiển bảo đảm tính bất biến thuận hàm rào cản điều khiển CBF
6. **연속동역학이산제어상태전이모델** - mô hình chuyển trạng thái điều khiển rời rạc động lực học liên tục
7. **동등성검증정형수학적증명엔진** - công cụ chứng minh toán học hình thức kiểm chứng tương đương
8. **실시간임베디드소프트웨어데드락검출** - phát hiện deadlock phần mềm nhúng thời gian thực
9. **사이버물리공격침입탐지복원력제어** - điều khiển phục hồi và phát hiện xâm nhập tấn công mạng-vật lý CPS
10. **통계적모델체킹몬테카를로시뮬레이션** - kiểm tra mô hình thống kê mô phỏng Monte Carlo
11. **무결성보증안전필터런타임모니터링** - giám sát thời gian thực bộ lọc an toàn bảo đảm tính toàn vẹn
12. **계약기반설계사양명세합성기법** - kỹ thuật tổng hợp đặc tả thiết kế dựa trên hợp đồng
13. **자율주행차량제어기정형안전검증** - kiểm chứng an toàn hình thức bộ điều khiển xe tự hành
14. **산업용제어시스템보안취약점정형분석** - phân tích hình thức lỗ hổng bảo mật hệ thống điều khiển công nghiệp
15. **하이브리드시스템불변집합안전보장** - bảo đảm an toàn tập bất biến trong hệ thống lai
