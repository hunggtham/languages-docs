# 기후 회복력형 의료시설의 언어

폭염·홍수·정전·물 부족이 겹쳐도 환자 진료가 이어지려면 의료시설을 단순한 건물이 아니라 서로 의존하는 서비스 체계로 보아야 한다. 이 주제는 병원의 전력·물·환기·병상·대피 설계를 기후위험과 필수의료의 연속성이라는 관점에서 연결한다.

## 학습 범위

`news_formal`은 병원 건축, 재난의료 계획, 시설 운영과 보건 정책에서 쓰이는 정밀한 표현을 다룬다. `native_spoken`은 시설 관리자와 의료진이 정전·폭염·침수 때 실제 운영 문제를 설명할 때 자연스러운 표현을 포함한다. 시설의 물리적 안전과 환자 치료의 연속성을 같은 말로 뭉뚱그리지 않고, 위험·운영·형평성의 층위를 구별하는 데 초점을 둔다.
