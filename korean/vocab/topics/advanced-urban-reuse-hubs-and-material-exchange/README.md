# 도시 재사용 거점과 자재 교환의 언어

도시에서 물건을 오래 쓰게 하려면 버리는 사람, 고쳐 쓰는 사람, 필요한 수요처와 조달 기준이 한 흐름으로 만나야 한다. 이 주제는 재사용 거점의 운영부터 공공 구매까지, 물건의 다음 사용처를 설계할 때 쓰는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 지자체 자원순환 정책, 건설·조달 기준과 운영 보고서에서 쓰인다. `native_spoken`은 수리점, 공유 작업장과 공공시설 실무자가 물건을 맡기고 필요한 곳으로 보내는 대화에서 들을 수 있다. 핵심은 재사용을 막연한 선의가 아니라 품질, 정보와 책임이 이어지는 공급 경로로 읽는 데 있다.
