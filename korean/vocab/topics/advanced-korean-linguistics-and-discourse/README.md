# 한국어의 구조와 담화 맥락

말의 표면적인 뜻만 보지 않고, 문장 구조와 사회적 맥락이 해석을 어떻게 이끄는지 살펴본다. 의미의 여러 층위와 화자의 관점 조절을 함께 익혀 Korean 담화를 더 정밀하게 읽는다.

## 학습 파일

- [말의 구조와 맥락을 읽다](./01-meaning-structure-and-discourse-context.md) — `함축성`, `다의성`, `중의성`, `유표성`, `무표성`, `관용화`, `문법화`, `담화 표지`, `발화 행위`, `전경화`, `직시`, `공손성`, `결속성`, `지시성`, `상호주관성`

## 학습 범위

`news_formal`은 언어 연구와 공적 문서에서 개념을 정확히 구분할 때 쓰이는 분석어이고, `native_spoken`은 실제 대화에서 화자·청자·상황의 관계를 조정하는 말이다. 같은 표현도 문장 구조와 공유된 배경지식에 따라 해석이 달라질 수 있으므로, 사전식 번역만으로 의미를 고정하지 않는다.
