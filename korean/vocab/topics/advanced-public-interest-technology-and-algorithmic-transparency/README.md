# 공익기술과 알고리즘 투명성의 언어

공공서비스에 기술을 도입할 때 효율성만 보지 않고, 영향을 받는 시민이 무엇을 알 수 있고 어떻게 이의를 제기하며 누가 책임지는지를 말하는 어휘를 익힌다.

## 학습 파일

- [공공기술을 공개하고 시민의 판단을 돕다](./01-public-interest-technology-and-algorithmic-transparency.md) — `공익기술`, `자동화영향평가`, `시스템설명가능성`, `알고리즘공시`, `의사결정기록`, `모델설명서`, `독립감독기구`, `이의제기경로`, `사람검토절차`, `서비스영향지도`, `알고리즘영향보고서`, `공공조달알고리즘`, `공익설계원칙`, `시민감독패널`, `공공알고리즘목록`

## 학습 범위

`news_formal`은 공공 조달, 규제와 영향 평가에서 시스템의 설명책임을 정확히 말할 때 쓰인다. `native_spoken`은 시민 설명회와 제품 검토에서 자동화가 누구에게 어떤 결과를 내는지 풀어 말할 때 자연스럽다. 이 lesson은 기술 공개를 소스코드 공개와 동일시하지 않고, 시민이 이해하고 문제를 제기하고 수정 결과를 확인할 수 있는 책임 사슬로 읽는 연습을 한다.
