# 사이버 침해사고 대응의 언어

사이버 침해사고는 악성 파일 하나를 지우는 일로 끝나지 않는다. 무엇이 노출됐는지 확인하고, 공격자의 침투 경로와 시스템 안에서의 움직임을 재구성한 뒤, 확산을 막고 재발을 줄이는 운영 언어가 필요하다.

## 학습 범위

`news_formal`은 기업·공공기관의 침해 사실, 위험 범위와 대응 체계를 보고하는 정책·보안 보도에 쓰인다. `native_spoken`은 보안관제센터와 사고 대응팀이 경보를 확인하고 장비를 격리하며 공격 흐름을 좁혀 갈 때 쓰는 실무어다. 단순히 공격이 있었다고 말하는 것과, 어떤 근거로 범위를 확정하고 다음 조치를 선택했는지를 구분하는 것이 핵심이다.
