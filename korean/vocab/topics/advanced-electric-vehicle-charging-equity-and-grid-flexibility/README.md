# 전기차 충전 형평성과 계통 유연성

전기차가 늘어날수록 충전기는 단순한 편의 시설이 아니라 주거 형태, 소득, 장애, 지역별 전력망 조건이 만나는 공공 인프라가 된다. 이 topic은 충전 접근의 격차를 줄이면서 충전 수요를 계통 운영의 유연한 자원으로 다루는 정책 언어를 연결해 읽도록 돕는다.

## 학습 범위

`news_formal`은 충전 인프라 계획, 요금 설계와 전력시장 제도를 분석할 때 쓰이는 정책·전문 register다. `native_spoken`은 주민 회의와 운영 현장에서 충전 불편과 조정 방법을 설명할 때 들을 수 있는 표현이다. 충전기를 많이 설치하는 것과 누구나 실제로 쓸 수 있게 만드는 것을 구분하고, 이용자의 권리와 계통의 운영 조건을 함께 익힌다.
