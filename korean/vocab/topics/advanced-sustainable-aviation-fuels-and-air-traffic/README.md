# 지속가능항공유와 항공교통 전환의 언어

항공의 탈탄소화는 연료만 바꾸는 일이 아니라 원료의 이력, 정책 의무, 공역 운영과 지연의 책임을 함께 조정하는 일이다. 이 주제에서는 지속가능항공유의 근거와 항공교통의 운항 언어를 한 흐름으로 익힌다.

연료의 탄소 성과를 과장하지 않으려면 생산·운송·사용 전 과정을 따져야 하며, 실제 운항에서는 슬롯과 공역을 조정해 연료 절감과 안전을 동시에 달성해야 한다.
