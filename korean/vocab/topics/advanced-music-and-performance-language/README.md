# 음악과 공연을 읽는 언어

소리를 단순히 좋고 나쁘다고 평가하는 데서 멈추지 않고, 음색·배음·선율의 조직과 무대에서 발생하는 신체적·사회적 경험을 분석한다. 음악 평론, 공연 기사, 창작자 인터뷰와 관객의 실제 대화에서 만나는 전문어와 현대적 표현을 하나의 공연 장면으로 연결한다.

## 학습 파일

- [소리의 결, 무대의 몸, 관객의 현장](./01-sound-stage-and-performance-language.md) — `음색`, `배음`, `공명하다`, `음향성`, `선율선`, `다성성`, `오스티나토`, `카덴차`, `시노그래피`, `신체성`, `수행성`, `즉흥성`, `양식화`, `전위성`, `떼창`

## 학습 범위

`news_formal`은 음악 평론과 공연 보도에서 소리의 구조, 무대 미학과 예술적 전략을 정밀하게 설명할 때 쓰인다. `native_spoken`은 연주자와 관객이 실제 무대의 반응과 현장감을 이야기할 때 자연스러운 표현이며, `slang_online`은 팬덤과 공연 후기에서 현재 활동 중인 참여 문화를 포착한다. 전문어는 사전식 번역만 외우기보다 어떤 소리·몸·관객 관계를 지시하는지 함께 파악해야 한다.
