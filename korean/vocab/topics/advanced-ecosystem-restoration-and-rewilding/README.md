# 생태계 복원과 재야생화의 언어

훼손된 자연을 단순히 녹화하는 데서 나아가, 생태적 관계와 자연의 자기 회복 과정을 되살리는 정책·현장 언어를 익힌다. 재야생화, 서식지 연결, 종의 기능과 복원 성과를 과학 보도와 지역 대화의 맥락에서 함께 읽는다.

## 학습 범위

`news_formal`은 생태 복원 계획, 보전 정책과 과학 보도에서 원인·기준·성과를 정밀하게 설명할 때 쓰인다. `native_spoken`은 조사 현장, 주민 협의와 시민 과학 모임에서 전문어를 풀어 말할 때 자연스럽다. 각 표현은 단순한 번역어가 아니라 종의 관계와 관리 결정을 지시하는 말로 익힌다.
