# 프로그래머블 액체 금속과 소프트 머신의 언어

프로그래머블 액체 금속과 소프트 머신 분야는 첨단 재료 과학, 로보틱스, 그리고 미세유체학이 융합된 최첨단 학문 영역입니다. 본 토픽에서는 갈륨-인듐 합금(EGaIn) 등의 액적을 활용한 전기화학적 표면장력 제어, 자기장 및 전기장을 이용한 형상 가변형 로봇, 초유연 자가복원 도전 배선, 재구성 가능한 전자회로, 그리고 차세대 유연 소프트 머신의 핵심 어휘와 전문 용어를 다룹니다.

## 학습 파일
- [프로그래머블 액체 금속과 소프트 머신 어휘 및 독해](./01-programmable-liquid-metal-machines.md) — 프로그래머블액체금속구동체, 갈륨인듐액체합금액적, 전기화학적표면장력제어, 자기장유도형상변형로봇, 초유연자가복원도전배선, 가역적상변화액체금속, 미세유체통로자가추진액적, 재구성가능전자회로기판, 생체모사소프트로봇액추에이터, 액체금속나노입자잉크, 신축성웨어러블배선소재, 차세대유연소프트머신, 과냉각액체금속열계면재료, 자율변형소프트로보틱스, 미래액체금속메카트로닉스

이 학습 세트를 통해 연구자들과 학습자들은 최신 소프트 머신 및 액체 금속 기술과 관련된 전문적인 한국어 표현을 정확히 이해하고 구사할 수 있게 됩니다.
