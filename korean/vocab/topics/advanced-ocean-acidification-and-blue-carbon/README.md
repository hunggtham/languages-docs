# 해양 산성화와 블루카본의 정밀한 언어

바닷물의 화학적 균형과 연안 생태계의 탄소 저장은 서로 떨어진 주제가 아니다. 이 lesson은 해양산성화가 탄산염을 이용하는 생물과 탄소 순환에 어떤 조건을 만드는지, 염생식물과 퇴적물이 탄소를 어떻게 붙잡는지, 복원 성과를 어떤 지표로 검토하는지 설명하는 어휘를 연결한다.

## 학습 파일

- [탄산염 화학과 연안 탄소를 추적하는 말](./01-carbonate-chemistry-and-blue-carbon-storage.md) — `탄산염포화도`, `해양알칼리도`, `탄산염완충능`, `석회화`, `산호백화`, `용존무기탄소`, `탄소매몰률`, `연안퇴적물`, `염생식물`, `조간대`, `퇴적물재부유`, `연안탄소저장고`, `탄소흡수잠재력`, `복원잠재력`, `탄산염 보상수심`

## 학습 범위

`news_formal`은 해양 관측, 기후 과학, 연안 복원과 탄소 회계에서 화학 지표와 저장 효과를 정밀하게 구분할 때 쓰인다. `native_spoken`은 연구자·어민·복원 현장 주민이 산호와 갯벌의 변화를 설명하거나 관리 방식을 협의할 때 자연스럽다. pH 하나만으로 위험을 단정하지 않고 알칼리도, 포화도, 생물의 석회화, 퇴적물의 이동과 장기 매몰을 함께 살피는 것이 핵심이다.
