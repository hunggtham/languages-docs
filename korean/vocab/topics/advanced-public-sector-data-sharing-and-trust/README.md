# 공공부문 데이터 공유와 신뢰의 언어

공공기관이 보유한 자료를 함께 사용하려면 기술적 연결만으로는 충분하지 않다. 누가 어떤 목적에 접근하고, 사용 조건을 어겼을 때 누가 설명하고 고칠지까지 합의해야 시민이 데이터 공유를 신뢰할 수 있다. 이 주제에서는 기관 간 협약, 이용자 심사, 안전한 분석 환경, 품질과 변경 이력, 책임 구조를 함께 말하는 어휘를 익힌다.

## 학습 범위

`news_formal`은 행정 협약, 감사 보고서와 정책 설계에서 기관의 권한·의무·검증 절차를 정확히 말할 때 쓰인다. `native_spoken`은 실무 회의에서 “어디까지 같이 쓰고, 문제가 생기면 누가 설명할 것인가”를 조율할 때 자연스럽다. 이 주제는 데이터를 무조건 많이 공개하는 태도보다 목적, 품질, 접근 기록과 시민의 이익을 함께 설계하는 공공 신뢰의 언어에 초점을 둔다.
