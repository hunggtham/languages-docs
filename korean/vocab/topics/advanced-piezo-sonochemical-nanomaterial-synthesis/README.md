# 압전 소노케미컬 나노재료 합성 기술의 언어

압전 소노케미컬 나노재료 합성 기술은 초음파 조사에 의해 액체 매질 내에서 발생하는 음향 공동 현상(acoustic cavitation)과 압전 나노결정의 기계-전기 변환 특성을 결합하여, 유독한 화학 환원제나 고온·고압의 외부 에너지 공급 없이 상온·상압에서 고순도 기능성 나노물질을 친환경적으로 합성하고 가공하는 첨단 나노화학 융합 기술 분야입니다. 수중 기포 붕괴 시 발생하는 수천 도의 국소 초고온과 수천 기압의 순간 압력파가 압전 반도체 결정에 강력한 변형을 유발하고, 이때 형성된 강한 압전 전위차(piezopotential)가 전자를 직접 방출하여 금속 이온을 환원시키거나 유기 오염물을 분해합니다. 본 단원에서는 초음파 캐비테이션, 압전 분극, 무환원제 나노촉매 합성, 라디칼 반응, 반도체 자가조립 성장, 그리고 무독성 그린 제조 공정에 이르는 첨단 압전 소노케미스트리의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
