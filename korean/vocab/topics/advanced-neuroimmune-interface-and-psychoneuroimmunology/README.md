# 뇌와 면역이 서로 신호를 주고받는 방식

스트레스와 염증을 따로 떼어 보지 않고, 뇌·면역계·장내 환경이 서로 영향을 주고받는 과정을 읽는다. 연구 기사, 정신건강 담론과 보건 안내에서 신경면역학 어휘가 어떤 근거와 한계를 지니는지 익힌다.

## 학습 범위

`news_formal`은 뇌질환·감염·만성질환 연구와 보건 정책을 설명할 때 쓰인다. `native_spoken`은 스트레스, 수면, 장 건강을 이야기하는 현재의 건강 담론에서 자연스럽다. `slang_online`은 의학적 표현을 과장해 자기진단하는 문맥을 비판적으로 읽을 때만 보조적으로 다룬다. 이 어휘들은 상관관계를 곧바로 인과관계나 개인 진단으로 바꾸지 않도록 근거의 범위를 함께 표시한다.
