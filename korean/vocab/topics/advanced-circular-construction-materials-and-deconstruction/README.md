# 건설 재료를 다시 쓰고 해체를 설계하는 언어

건물을 지을 때부터 나중에 어떻게 분해하고, 부재를 선별하며, 재료를 다시 공급망에 넣을지 생각해야 한다. 이 주제는 해체설계와 가역접합에서 시작해 선택해체, 구조재사용, 순환골재와 저탄소 시멘트까지 이어지는 고급 한국어를 다룬다.

## 학습 파일

- [해체를 전제로 한 건설 재료의 순환](./01-circular-construction-materials-and-deconstruction.md) — `해체설계`, `가역접합`, `선택해체`, `구조재사용`, `순환골재`, `내재탄소`

## 학습 범위

`news_formal`은 건축 정책, 자원순환 규정과 재료 공학을 설명할 때 쓰이고, `native_spoken`은 설계자·시공자·철거업체가 현장에서 공법과 비용을 조율할 때 들을 수 있다. 새 건물을 친환경이라고 부르기 전에 접합부의 가역성, 부재의 추적성, 해체 뒤 재사용 품질과 내재탄소까지 함께 따져 보는 것이 핵심이다.
