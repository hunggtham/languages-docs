# 메타물질 완전 흡수체 및 스텔스 기술의 언어

메타물질 완전 흡수체 및 첨단 스텔스 공학은 인공적으로 설계된 서브파장 금속-유전체 공진기 구조를 통해 매질의 유효 유전율과 유효 투자율을 정밀 조절하여, 자유공간과의 파동 임피던스를 완벽히 일치시키고 입사하는 전자기파의 반사율과 투과율을 0으로 만들어 100% 흡수·소산시키는 최첨단 전자기파 제어 기술 분야입니다. 마이크로파 레이더 신호(1~18GHz)의 반사 면적(RCS)을 광대역으로 저감하는 것은 물론, 적외선 열복사 신호까지 동시에 차폐하여 다중 스펙트럼 스텔스를 달성하고 차세대 항공기, 함정 및 유도무기의 생존성을 극대화합니다. 본 단원에서는 초광대역 임피던스 정합, 옴 손실 소산, 능동 가변 메타표면, 세라믹 내열 메타소재, 롤투롤 인쇄 공정 및 방열 복합 설계에 이르는 첨단 스텔스 전자기파 공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
