# 재구성 가능 지능형 표면과 차세대 전파 통신의 언어

재구성 가능 지능형 표면(Reconfigurable Intelligent Surfaces, RIS)은 6G 무선 통신 환경에서 전파의 반사, 굴절, 산란 특성을 인공적으로 제어하여 무선 통신의 성능을 극대화하는 핵심 기술입니다. 프로그래머블 전자기 초표면과 PIN 다이오드 위상 가변 셀을 활용하여 고주파 스마트 무선 반사판 및 능동 전파 지능형 반사체 역할을 수행하며, 무선 전파 음영 지역을 해소하고 초저지연 공간 다중화 통신을 지원합니다. 또한 에너지 효율 무선 중계 기술과 테라헤르츠 전파 제어 표면을 결합하여 미래 초연결 통신 전파 공학의 지능형 무선 환경 엔지니어링을 선도합니다.

## 학습 파일
- [재구성 가능 지능형 표면과 차세대 전파 통신 전문 어휘](./01-programmable-metasurface-reconfigurable-intelligent-surfaces.md) — 재구성가능지능형표면소자, 육세대무선통신스마트전파, 핀다이오드위상가변셀, 초고주파빔형성능동제어, 무선전파음영지역해소, 프로그래머블전자기초표면, 초저지연공간다중화통신, 에너지효율무선중계기술, 테라헤르츠전파제어표면, 능동전파지능형반사체, 지능형무선환경엔지니어링, 차세대이동통신네트워크, 위상배열전파조향시스템, 고주파스마트무선반사판, 미래초연결통신전파공학

이 학습 문서는 6G 이동통신 네트워크 및 지능형 무선 환경을 구성하는 핵심 전파 공학 어휘들을 체계적으로 정리하여 고급 기술 독해력과 실무적 표현력을 배양합니다.
