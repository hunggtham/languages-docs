# 핵심광물과 희토류 재활용

에너지 전환과 첨단 제조에 필요한 광물은 채굴량만으로 안정적인 공급을 보장할 수 없다. 이 주제에서는 광석의 품위, 정제 공정의 병목, 폐배터리와 폐영구자석에서 금속을 되찾는 기술을 하나의 자원순환 흐름으로 연결해 읽는다. 재활용을 말할 때도 회수율만 보지 않고 순도, 오염, 에너지 사용과 실제 수요까지 함께 판단하도록 구성했다.

## 학습 범위

`news_formal`은 핵심광물 공급망, 정제 능력과 재활용 정책을 분석하는 산업·정책 보도의 register다. `native_spoken`은 연구소·제조업 회의에서 공정의 병목과 실제 처리 가능성을 조율할 때 쓰이는 현재적 업무 표현이다. 같은 “재활용”이라도 원료의 순도와 회수된 금속의 다음 사용처를 확인해야 한다는 점에 초점을 둔다.
