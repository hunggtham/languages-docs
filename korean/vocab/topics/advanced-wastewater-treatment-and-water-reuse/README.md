# 하수를 자원으로 되돌리고 물의 순환을 설계하는 말

도시의 하수는 버려지는 물이 아니라 오염물질을 제거하고 에너지와 영양분을 회수한 뒤 다시 쓸 수 있는 자원이다. 이 주제는 고도 하수처리 공정, 방류 기준, 슬러지 관리와 물 재이용을 정책·시설 운영·주민 설명의 맥락에서 읽는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 수질 규제, 처리 기술, 자원 회수와 물 재이용 정책을 보도하거나 분석할 때 쓰인다. `native_spoken`은 시설 운영자와 주민이 처리수의 안전성, 요금과 재이용률을 설명하거나 묻는 상황에서 들을 수 있다. 처리 기술의 이름만 나열하지 않고 오염물질 제거, 에너지 회수, 방류 책임과 음용수 신뢰를 하나의 순환으로 읽는 것이 핵심이다.
