# 로봇과 인간 협업 설계의 언어

로봇을 단순히 빠른 기계로 보지 않고, 사람이 감각·판단·책임을 나누어 맡는 협업 시스템으로 읽는다. 생산 현장과 재활·돌봄 현장에서 동작을 계획하고 안전을 확보하는 고급 어휘를 연결한다.

## 학습 범위

`news_formal`은 산업 로봇, 재활공학, 안전 규정과 연구 결과를 설명할 때 쓰이는 정밀한 기술어다. `native_spoken`은 엔지니어와 현장 작업자가 로봇의 움직임과 책임 경계를 조정하면서 실제로 주고받는 말에 가깝다. 같은 로봇이라도 사람 곁에서 작동하는지, 원격으로 조작되는지에 따라 위험과 말투가 달라진다는 점을 함께 익힌다.
