# 도시 표면수 홍수 모형의 언어

도시의 불투수면에서 시작한 빗물이 관망과 저류 시설을 거쳐 어디에 넘치는지, 그리고 모형의 불확실성을 어떻게 읽는지 익힌다.

## 학습 파일

- [도시 빗물의 흐름을 모의하고 불확실성을 읽다](./01-urban-surface-water-flood-modelling.md) — `강우-유출모형`, `유역분할`, `불투수율`, `초과우량`, `저류지`, `배수분구`, `관망해석`, `첨두유량`, `침수심`, `범람모의`, `격자해상도`, `매개변수 보정`, `불확실성 전파`, `시나리오 앙상블`, `불확실성 정량화`

각 항목은 강우 입력부터 도시 배수망, 침수 지도, 모형 검증과 의사결정까지 하나의 표면수 홍수 분석 흐름으로 연결된다.
