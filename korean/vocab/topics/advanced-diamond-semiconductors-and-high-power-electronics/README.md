# 다이아몬드 반도체와 초고전력 전자기술의 언어

다이아몬드 반도체는 탄소 원자가 삼차원 격자 구조를 이루어 뛰어난 전기적·물리적 특성을 발휘하는 초광대역밴드갭(UWBG) 소재 기술입니다. 기존 실리콘이나 실리콘 카바이드(SiC)의 한계를 뛰어넘어 극한의 절연파괴전계, 압도적인 열전도도, 그리고 고온·고방사선 환경에서의 높은 동작 신뢰성을 제공함으로써 차세대 전력 반도체 및 그린 전력망 혁신을 주도하고 있습니다.
