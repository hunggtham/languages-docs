# 탄성열량 냉각 기술과 고체 냉동 공학의 언어

탄성열량 냉각 기술(Elastocaloric cooling technology)은 형상기억합금의 응력 유도 상변태 과정에서 방출되거나 흡수되는 잠열을 이용하는 혁신적인 무냉매 고체 냉각 기술입니다. 이 분야는 기존의 증기 압축 식 냉각 방식을 대체할 차세대 친환경 냉동 공학의 핵심으로, 지구온난화지수(GWP)가 제로에 가까운 친환경 열역학 사이클을 구현합니다.
