# 소재 정보를 조달과 순환의 책임으로 연결하는 언어

제품을 한 번 사고 버리는 조달에서 벗어나려면 소재의 이력, 성능, 수리와 회수 가능성을 계약과 예산의 판단에 넣어야 한다. 이 주제는 소재여권에서 시작해 조달사양서, 총소유비용, 분해와 회수의 책임까지 이어지는 고급 한국어를 다룬다.

## 학습 파일

- [소재 정보와 순환 조달의 설계](./01-material-passports-and-circular-procurement.md) — `소재여권`, `순환조달`, `성능기반조달`, `총소유비용`, `분해용이성`, `회수의무`

## 학습 범위

`news_formal`은 공공조달, 제품 규제와 산업 전환을 설명할 때 쓰이고, `native_spoken`은 구매 담당자와 공급자가 비용·수리·회수 조건을 협의할 때 들을 수 있다. 친환경 문구만 보는 대신 제품의 정보가 실제 계약, 사용 기간과 폐기 이후 책임으로 이어지는지 확인하는 것이 핵심이다.
