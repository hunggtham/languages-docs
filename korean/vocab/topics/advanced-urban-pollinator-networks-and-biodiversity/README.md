# 도시 수분매개자 네트워크와 생물다양성의 언어

도시의 공원과 옥상정원을 연결해 벌·나비 같은 수분매개자가 먹이와 은신처를 이어 가도록 설계하는 고급 어휘를 다룬다. 단순히 꽃을 심는 데서 그치지 않고 개화 시기의 연속성, 농약과 인공조명의 교란, 자생종 복원과 생태적 함정까지 하나의 경관 네트워크로 읽는다.

## 학습 범위

`news_formal`은 도시계획, 생태복원, 농약 관리와 생물다양성 정책을 보도하거나 보고서로 검토할 때 쓰인다. `native_spoken`은 주민 회의와 환경 커뮤니티에서 옥상정원, 야생화와 야간 조명을 논의할 때 들을 수 있다. 꽃의 숫자보다 계절 전체의 먹이 흐름, 이동 경로와 관리 방식이 실제 수분서비스를 좌우한다는 관점이 핵심이다.
