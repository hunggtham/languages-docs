# 합성생물학과 대사공학의 언어

합성생물학과 대사공학은 미생물의 유전체와 대사 회로를 공학적으로 재설계하여 고부가가치 화학물질, 바이오 의약품, 청정 에너지를 생산하는 핵심 첨단 기술이다. 세포 내부의 미세한 효소 반응을 제어하고 대사 흐름을 최적화하는 분자적 접근부터 자동화된 연구 인프라를 활용하는 산업적 공정까지 포괄적인 이해가 필요하다. 본 주제에서는 현대 생명공학 연구와 바이오 산업 현장에서 필수적으로 쓰이는 핵심 전문 용어를 체계적으로 익힌다.
