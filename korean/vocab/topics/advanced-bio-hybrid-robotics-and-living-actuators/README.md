# 생체 융합 로봇공학과 생체 구동기의 언어

생체 융합 로봇공학(Bio-hybrid Robotics)과 생체 구동기(Living Actuator) 기술은 살아있는 생체 근육 조직과 유연 인공 골격을 융합하여 기존 전기 모터로는 구현할 수 없는 초유연성, 고효율 화학-역학 에너지 변환, 자가 치유 능력을 달성하는 첨단 생체기계융합(Biomechatronics) 분야이다. 골격근 모세포의 정밀 배양과 배향 제어, 하이드로겔 3차원 지지체 설계, 광유전학 및 생체 전기 자극을 통한 수축력 제어, 신경근 접합부 모사를 통한 내인성 신호 제어 기술이 이 분야의 핵심을 이룬다. 본 주제에서는 골격근 세포 배양, 하이드로겔 골격 지지체, 광유전학 및 생체 전기 자극 제어, 신경근 접합을 모사한 자가 치유 생체 근육 구동기 및 유연 유영 로봇에 이르는 생체 로봇 전반의 첨단 전문 어휘를 체계적으로 학습한다.
