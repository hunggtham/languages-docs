# 보험 위험과 보장의 설계

보험은 위험을 없애는 약속이 아니라 여러 계약자가 위험을 나누고, 사고가 났을 때 보장 범위와 책임을 판단하는 제도다. 이 topic은 보험사의 재무 건전성부터 가입자가 약관을 읽을 때 마주치는 공백과 한도까지 하나의 흐름으로 연결해 익히도록 돕는다.

## 학습 범위

`news_formal`은 보험 감독, 재보험과 위험관리 보고서에서 쓰이는 공식·전문 register다. `native_spoken`은 상담 창구와 소비자 대화에서 보장 범위, 면책과 청구 책임을 확인할 때 쓰이는 표현이다. 보험료가 싸다는 말만으로 상품을 판단하지 않고 위험의 분산, 계약자의 행동, 재무 여력과 실제 보장 한도를 구분해 읽는다.
