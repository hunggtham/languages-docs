# 자율 구동 나노모터와 표적 약물 전달 마이크로로봇의 언어

현대 의학은 최소침습 수술과 정밀 치료의 한계를 극복하기 위해 생체 내에서 스스로 움직이며 질병을 치료하는 나노 및 마이크로 로보틱스 기술을 주목하고 있습니다. 이 어휘집은 자율 구동 나노모터, 생체연료 기반 마이크로모터, 자기장 유도 표적 지향 이동, 혈관 내 미세 유영 및 종양 미세환경 침투, 그리고 생체분해성 스마트 캡슐 등 최첨단 의료용 나노로보틱스 분야의 핵심 학술 용어 15개를 엄선하여 심도 있는 어휘적 분석과 실전 예문을 제공합니다.
