# 복사 냉각 메타물질과 열 복사 제어의 언어

복사 냉각(Radiative Sky Cooling)은 지구의 물체에서 우주(절대영도에 가까운 외계 공간)로 대기 투명창(8–13 μm)을 통해 직접 열을 복사 방출하여 전력 소비 없이 온도를 낮추는 혁신적인 열 관리 기술입니다. 본 학습 세트는 태양광 초고반사율(>96%), 중적외선 파장 선택 방사, 다공성 고분자 필름, 건축물 외장 코팅, 도심 열섬 현상 완화, 자가 냉각 광학 메타표면 등 첨단 열역학 및 소재 공학 어휘 15개를 다룹니다.
