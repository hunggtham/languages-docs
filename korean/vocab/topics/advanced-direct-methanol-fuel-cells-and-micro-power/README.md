# 직접 메탄올 연료전지와 휴대용 전원의 언어

직접 메탄올 연료전지(Direct Methanol Fuel Cell, DMFC) 기술은 고분자 전해질막을 통한 메탄올 크로스오버를 최소화하고, 백금-루테늄 나노촉매 합금을 활용한 메탄올의 전기화학적 산화 반응을 극대화하여 차세대 초소형 휴대용 전원을 구현하는 핵심 공학 분야입니다. 탄소나노튜브 담지 전극과 미세유체 연료 공급 채널을 결합함으로써 드론의 장기 체공 하이브리드 전원 및 고에너지 밀도 휴대용 배터리 대체재로 널리 주목받고 있습니다. 본 단원에서는 이러한 DMFC 시스템과 관련된 고급 기술 어휘를 체계적으로 학습합니다.
