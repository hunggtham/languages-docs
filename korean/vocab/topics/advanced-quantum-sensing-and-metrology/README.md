# 양자 현상을 정밀하게 재는 언어

양자 기술의 경쟁력은 장비 이름이나 센서 수만으로 결정되지 않는다. 어떤 물리량을 어떤 기준으로 측정하고, 잡음과 교정 오차를 어떻게 분리하며, 결과를 다른 기관과 비교할 수 있는지가 핵심이다. 이 주제는 양자 센싱과 정밀 계측의 연구·정책 보도, 그리고 실험실 협업에서 자주 쓰이는 어휘를 연결한다.

## 학습 범위

`news_formal`은 국가측정표준, 과학기술 정책과 연구 성과를 설명할 때 정밀도·불확도·비교 가능성을 말하는 어휘다. `native_spoken`은 연구자와 엔지니어가 실험 결과를 검토하며 센서의 실제 한계와 교정 상태를 풀어 말할 때 자연스럽다. 수치가 더 세밀해 보인다는 이유만으로 측정이 더 정확하다고 단정하지 않고, 기준·잡음·공간 구배를 함께 확인하는 태도가 이 주제의 중심이다.
