# 자율운항선박과 해양로봇의 언어

바다는 거대한 자연의 물리적 변수와 전 지구적 공급망이 교차하는 복합 공간이다. 인공지능, 원격 제어, 해양 로봇 기술의 융합은 승무원의 경험에만 의존하던 전통적인 항해 패러다임을 육상과 해상을 실시간 데이터로 잇는 지능형 무인 시스템으로 전환하고 있다. 이 주제는 거친 파도 속에서 선박이 스스로 상황을 인지하고 충돌을 회피하는 자율운항 메커니즘, 심해와 수면을 누비는 해양 로봇의 정밀 제어, 그리고 육상 관제탑 및 스마트 항만과 연결되는 현대 해양 공학의 정밀 어휘를 체계적으로 다룬다.

## 학습 범위

`news_formal`은 첨단 조선 해양 공학 기술 보고서, 국제해사기구(IMO) 표준 규범, 스마트 물류 정책과 해사 보도에서 정확한 시스템 명칭과 안전 기준을 서술할 때 쓰인다. `native_spoken`은 해양 현장의 엔지니어, 원격 관제사, 연구원들이 통신 상황이나 제어 상태를 신속히 공유하고 비상 대응을 논의할 때 생생하게 쓰이는 표현들이다. 무인화와 자동화가 진행되더라도 대양 항해의 본질은 안전과 신뢰성에 있으므로, 각 어휘가 가리키는 기계적 제어와 통신 프로토콜의 상호작용 맥락을 함께 이해해야 한다.
