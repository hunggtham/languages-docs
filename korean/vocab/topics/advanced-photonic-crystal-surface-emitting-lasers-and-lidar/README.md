# 광자 결정 표면 발광 레이저 및 라이다 센서

광자 결정 표면 발광 레이저(Photonic-Crystal Surface-Emitting Laser, PCSEL)와 첨단 라이다(LiDAR) 센서 기술은 자율주행, 인공지능 로보틱스, 초고속 광컴퓨팅 분야의 미래를 선도하는 차세대 광전 융합 하드웨어의 핵심입니다. 2차원 주기적 나노 구조를 통해 빛의 군속도를 제어하고 대면적 단일 모드 공진을 유도하는 PCSEL 기술은 외부 렌즈 없이도 완벽한 원형 빔과 극저 발산각, 와트급 고출력을 동시에 구현합니다. 아울러 기계식 모터 회전체가 필요 없는 광위상배열(OPA) 기반의 전고체 빔 조향 및 온칩 광집적 기술은 기존 라이다의 부피와 단가 한계를 극복하고 손톱 크기의 초소형 3차원 감각 시스템을 현실화하고 있습니다. 본 단원에서는 2차원 밴드 에지 공진의 기초 물리 원리부터 고휘도 광원 설계, 초고해상도 3차원 거리 계측 및 차세대 광센싱 엔지니어링에 이르는 필수 전문 어휘 15개를 엄선하여 체계적으로 학습합니다.
