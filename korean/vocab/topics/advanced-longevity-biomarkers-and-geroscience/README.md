# 장수 생체표지와 노화생물학의 언어

노화를 단순한 연령이 아니라 여러 생물학적 경로가 누적되고 서로 얽히는 과정으로 읽는다. 실험실의 기전어와 건강 담론의 표현을 함께 익히면서, 건강수명 연장과 회춘을 과장하지 않고 근거의 수준을 말하는 어휘를 배운다.

이 주제는 노화 관련 신호를 측정하는 일과 실제 건강 결과를 바꾸는 개입을 구별하고, 연구 결과를 개인의 수명 예언이나 만능 항노화 광고로 확대하지 않는 contemporary Korean discourse를 보여 준다.
