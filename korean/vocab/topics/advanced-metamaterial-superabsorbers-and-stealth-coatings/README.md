# 메타물질 완전 흡수체와 스텔스 외피의 언어

현대 국방 과학과 전자기학에서 메타물질 완전 흡수체(Metamaterial Perfect Absorbers)와 스텔스 외피(Stealth Skins)는 레이더 탐지를 무력화하고 적외선 및 마이크로파 스펙트럼을 제어하는 핵심 첨단 기술입니다. 본 주제 영역은 광대역 전자기파 흡수, 임피던스 정합, 레이더 반사면적(RCS) 극소화, 그리고 항공우주 전투기용 차세대 스텔스 소재의 전문 어휘를 다룹니다.

## 학습 파일
- [메타물질 완전 흡수체와 스텔스 외피 전문 어휘](./01-metamaterial-superabsorbers-and-stealth-coatings.md) — 메타물질완전흡수체, 광대역전자기파완전흡수, 임피던스정합초표면, 레이더반사면적극소화, 적외선열신호위장차폐, 다대역스텔스나노외피, 전자기유도투과제어, 초박형경량전파흡수재, 유전손실자성손실복합체, 마이크로파반사원천차단, 항공우주전투기스텔스외피, 비반사완전무반사코팅, 능동주파수선택성표면, 차세대국방스텔스소재, 전자기스펙트럼우세기술

이 학습 자료를 통해 첨단 국방 메타물질 및 전자기 스텔스 분야의 전문적이고 정교한 한국어 표현을 완벽히 마스터할 수 있습니다.
