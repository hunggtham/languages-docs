# 생체 태양전지와 조류 생물에너지의 언어

생체 태양전지(Bio-photovoltaics, BPV)와 조류 생물에너지는 자연의 광합성 시스템을 활용하여 전기를 생산하고 동시에 탄소를 포집하는 차세대 친환경 기술입니다. 광합성 미세조류 생물막, 세포외 전자 추출, 생체전극 전도성 하이드로겔, 그리고 분산형 자가 생태 발전망 등을 통해 지속 가능한 미래 에너지 패러다임을 제시합니다.

## 학습 파일

- [생체 태양전지와 조류 생물에너지 전문 어휘](./01-bio-photovoltaics-and-living-algae-energy.md) — 생체태양전지바이오시스템, 광합성조류생물막발전, 세포외광전기화학전자추출, 탄소네거티브자가발전소재, 생체전극전도성하이드로겔, 살아있는식물조류복합전지, 미세조류지속가능광합성, 미세전류연속발전메커니즘, 바이오광전변환효율개선, 이산화탄소포집동시발전, 무독성친환경에너지수확, 친환경바이오태양광패널, 차세대생명공학에너지원, 분산형자가생태발전망, 지속가능한미래생체에너지

이 모듈은 첨단 생체 태양전지 및 조류 생물에너지 분야의 전문 어휘와 실제 연구 논문, 기술 보고서에서 사용되는 고급 표현들을 체계적으로 학습할 수 있도록 구성되었습니다.
