# 하수에서 항생제 내성의 경로를 추적하다

하수는 병원·지역사회에서 배출된 항균제와 미생물의 흔적을 한데 모아 보여 주지만, 검출 결과를 곧바로 환자 진단이나 감염 확산의 증거로 읽을 수는 없다. 이 lesson은 하수 감시와 임상 자료를 연결하면서 내성의 선택, 유전자 이동, 측정 불확실성을 정밀하게 말하는 어휘를 다룬다.

## 학습 파일

- [하수 기반 항생제 내성 감시와 임상 연계](./01-wastewater-antimicrobial-resistance-surveillance.md) — 항생제내성, 내성균, 내성유전자, 잔류항균제, 최소억제농도, 감수성시험, 수평적유전자전달, 공동선택, 선택압, 환경저장소, 내성표현형, 내성유전자형, 임상환경연계, 생물막, 희석효과

## 학습 범위

`news_formal`은 항생제 내성 정책, 환경보건 연구와 실험실 보고서에서 쓰이는 정밀한 표현이다. `native_spoken`은 연구자·병원 감염관리팀·지자체 담당자가 결과의 의미와 대응 수위를 조율할 때 들을 수 있는 말이다. 검출량을 환자 수로 단순 환산하지 않고, 잔류물·미생물 군집·유전자와 실제 표현형 사이의 간극을 설명하는 데 초점을 둔다.
