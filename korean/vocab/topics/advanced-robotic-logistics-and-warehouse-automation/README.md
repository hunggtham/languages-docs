# 로봇 물류와 자동화 창고의 운영 언어

로봇이 창고에서 물건을 옮기는 장면만 보면 자동화의 핵심을 놓치기 쉽다. 주문의 마감, 재고 배치, 사람과 기계의 예외 대응, 도크의 흐름을 함께 읽으며 물류 현장에서 쓰이는 고급 어휘를 익힌다.

각 항목은 자동화 장비의 이름만 나열하지 않고, 주문 우선순위와 현장 판단이 어떻게 연결되는지 보여 준다.
