# 열전 발전과 폐열 회수 기술의 언어

본 토픽은 산업 현장, 자동차, 그리고 일상생활에서 무심히 버려지는 열에너지를 전기에너지로 직접 변환하는 친환경 열전 발전(Thermoelectric Generation)과 폐열 회수(Waste Heat Harvesting) 기술에 관한 핵심 전문 어휘를 다룹니다. 제베크 효과(Seebeck Effect)를 활용한 에너지 변환 원리부터 나노구조 포논 산란 조절, 무차원 열전 성능지수(zT) 극대화, 그리고 모듈 제작 공정에 이르는 최신 공학 기술 어휘를 체계적으로 학습할 수 있습니다.

## 학습 파일
- [제베크 효과 나노 복합 열전 소재 기반 산업 폐열 회수 발전 기술](./01-thermoelectric-generators-and-waste-heat-harvesting.md) — 열전발전시스템, 제베크효과에너지변환, 무차원열전성능지수극대화, 포논산란나노구조화, 산업폐열발전기술, 고온내산화성열전소재, 차량배기가스열회수, 웨어러블체온발전기, 열전소자열팽창정합, 직류전력변환효율, 열전모듈내구성신뢰성, 고신뢰성금속화계면, 비자성열전박막소자, 무소음친환경발전기, 분산형폐열수확인프라
