# 생체분해성 마찰전기 발전기와 에코 전자의 언어

생체분해성 마찰전기 발전기(Biodegradable Triboelectric Nanogenerators, BD-TENG)와 에코 전자는 환경오염과 전자 폐기물(E-waste) 문제를 극복하기 위해 자연에서 유래하여 자연으로 돌아가는 친환경 과도기 전자소자(transient green electronics) 기술을 다룹니다. 친환경 천연 고분자 마찰층, 수용성 천연 다당류 필름, 토양 자연분해 에너지 수확재, 식물 유래 셀룰로오스 나노섬유, 해양 생태계 친화형 모니터링 태그, 퇴비화 가능 마찰대전 박막, 생체적합성 천연 단백질 지지체, 전자 폐기물 제로화 친환경 소재 등을 바탕으로, 에너지를 스스로 수확하고 소임을 다한 뒤 흙과 바닷속에서 무해하게 소멸하는 지속 가능한 생태 순환형 미래 전자의 핵심 어휘들을 체계적으로 학습합니다.

## 학습 파일

- [생체분해성 마찰전기 발전기와 에코 전자 전문 어휘](./01-biodegradable-triboelectric-nanogenerators-and-ecoelectronics.md) — 생체분해성마찰전기발전기, 친환경천연고분자마찰층, 수용성천연다당류필름, 환경친화적과도기전자소자, 토양자연분해에너지수확재, 식물유래셀룰로오스나노섬유, 해양생태계친화형모니터링태그, 퇴비화가능마찰대전박막, 생체적합성천연단백질지지체, 단기수명환경자가발전센서, 전자폐기물제로화친환경소재, 차세대그린나노에너지기술, 가용성도전성생물복합체, 지속가능생태계순환소재, 미래친환경에코전자공학

이 모듈은 첨단 생체분해성 마찰전기 발전기 및 친환경 에코 전자공학 분야의 전문 어휘와 실제 연구 논문, 기술 보고서에서 사용되는 고급 표현들을 체계적으로 학습할 수 있도록 구성되었습니다.
