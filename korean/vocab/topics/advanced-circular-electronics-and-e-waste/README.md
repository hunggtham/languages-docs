# 전자제품의 수명을 늘리고 폐기물의 경로를 다시 설계하는 언어

전자제품은 판매되는 순간부터 폐기물이 되는 것이 아니라, 수리·재사용·회수·분해·재활용의 선택지가 이어지는 물질 흐름 안에 놓인다. 이 주제는 스마트폰, 노트북, 가전과 배터리를 오래 쓰고 안전하게 되돌리는 과정에서 필요한 고급 한국어를 다룬다. 제품의 친환경성을 광고 문구로만 판단하지 않고, 설계 단계의 책임과 데이터 보안, 생산자 의무, 실제 회수 경로까지 함께 읽는 것이 핵심이다.

## 학습 범위

`news_formal`은 전자제품 설계 기준, 생산자 책임, 환경성과 지표와 자원 흐름을 정책·산업 기사에서 분석할 때 쓰인다. `native_spoken`은 중고 기기를 되팔거나 수리할지, 데이터를 어떻게 지울지, 리퍼비시 제품을 믿을 수 있는지 말할 때 들을 수 있다. 전자폐기물의 회수량만 늘리는 것보다 제품을 오래 쓰고, 개인정보를 보호하며, 회수된 부품과 소재가 실제로 다음 공정에 들어가는지를 따져야 한다.
