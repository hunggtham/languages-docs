# 페로브스카이트 단결정과 차세대 방사선 검출기의 언어

페로브스카이트 단결정 소재는 우수한 X선 흡수 계수와 뛰어난 전하 운반체 이동도를 바탕으로, 기존의 실타래 같은 복잡한 신호 처리 단계를 획기적으로 간소화하며 고효율 반도체 직접 변환 방식의 차세대 방사선 검출기를 구현하는 핵심 기술로 주목받고 있습니다. 본 주제에서는 저선량 의료용 방사선 계측, 실시간 디지털 방사선 센서, 비파괴 검사 산업용 디텍터 및 초고감도 엑스선 영상화 등 첨단 방사선 공학과 관련된 전문 어휘와 표현을 체계적으로 학습합니다.
