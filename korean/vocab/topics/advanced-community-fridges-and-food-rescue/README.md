# 공동체 냉장고와 식품 구조를 말하는 언어

공동체 냉장고는 남는 음식을 아무 데나 옮겨 놓는 장소가 아니라, 안전하게 기부하고 필요한 사람이 존중받으며 가져갈 수 있도록 주민·상점·자원봉사자가 함께 관리하는 생활 인프라다. 이 묶음은 도시 식품 접근성이나 일반적인 음식물 폐기 정책보다, 냉장 보관·기부 선별·이용 규칙·책임 있는 재분배를 설명하는 어휘에 초점을 둔다.

## 학습 범위

`news_formal`은 식품 기부, 지역 복지와 안전 관리 사업을 보도하거나 평가하는 데 쓰인다. `native_spoken`은 냉장고를 채우고 점검하면서 무엇을 넣고 가져갈 수 있는지 설명할 때 자연스럽다. 남는 음식을 줄이는 것만 강조하지 않고, 안전 기준과 이용자의 존엄·선택권을 함께 말하는 연습을 한다.
