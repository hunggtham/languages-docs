# 우주 잔해와 궤도 지속가능성의 언어

위성 발사가 늘어날수록 궤도는 비어 있는 공간이 아니라 추적·회피·폐기 책임을 나누어야 하는 공동 인프라가 된다. 이 주제는 우주물체를 식별하고 충돌 위험을 낮추며 임무 종료 뒤 환경 부담을 줄이는 고급 어휘를 다룬다.
