# 도시 감지망과 사물인터넷 거버넌스의 언어

도시는 카메라와 환경 센서가 늘어나는 것만으로 똑똑해지지 않는다. 어떤 장치가 어떤 신호를 읽고, 누가 접근하며, 고장과 오용의 책임을 누가 지는지를 함께 설계해야 한다. 이 lesson은 도시 감지망의 보안·상호작용·데이터 권리를 설명하는 고급 어휘를 하나의 공공사업 흐름으로 묶는다.

## 학습 범위

`news_formal`은 스마트시티 조달, 공공 데이터 규칙, 사이버 보안과 시민 권리를 보도하거나 평가할 때 쓰인다. `native_spoken`은 도시 운영팀·개발자·주민이 장치의 고장, 기능 변경, 데이터 사용 범위를 협의할 때 쓰는 실무어다. 장치를 많이 설치하는 것보다 관측의 한계와 책임 경로를 공개하는 것이 핵심이다.
