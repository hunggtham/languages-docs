# 심해 내압 전자공학과 자율잠수정의 언어

심해 내압 전자공학과 자율잠수정(AUV) 분야는 수천 기압에 달하는 극한의 심해 환경에서 무거운 티타늄 압력 용기 없이도 안정적으로 작동하는 혁신적인 압력 내성 전자 소자(pressure-tolerant electronics)와 직접 실리콘 겔 침전 패키징 기술을 다룹니다. 탄화규소(SiC) 고전압 전력 반도체, 고밀도 비압축성 겔, 심해 음향 통신 신호 처리, 초음파 소나 센서, 심해저 지형 정밀 매핑 라이다(LiDAR), 그리고 장주기 해양 환경 모니터링 장치 등은 수중 심해 열수구 탐사와 해양 생태계 비파괴 관측을 가능하게 합니다. 무인잠수정의 심해 자율 항법과 극한 해양 로보틱스 시스템은 미지의 해저 세계를 정밀하게 분석하는 차세대 해양 탐사 엔지니어링의 핵심 축입니다.
