# 양자점 전계발광 소자와 QLED 디스플레이의 언어

차세대 자가발광 디스플레이 기술의 핵심인 양자점 전계발광 소자(QLED/EL-QD)는 카드뮴을 배제한 친환경 콜로이드 양자점을 활용하여 높은 색순도와 뛰어난 발광 효율을 구현합니다. 본 학습 세트는 발광층 에너지 준위 정렬, 전하이동도 균형 제어, 외부양자효율(EQE) 극대화, 무기물 전자수송층 박막 형성 및 장수명 구동 신뢰성 확보 등 첨단 디스플레이 공학과 재료 과학의 전문 어휘를 다룹니다. 이를 통해 초고화질 VR/AR 패널 및 자가발광 디스플레이의 기술 문서를 정확히 이해하고 표현할 수 있습니다.
