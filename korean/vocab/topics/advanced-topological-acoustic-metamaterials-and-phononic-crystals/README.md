# 위상 음향 메타물질과 포노닉 결정의 언어

위상 음향 메타물질과 포노닉 결정 분야는 고체역학, 파동 물리학, 위상물리학이 융합된 최첨단 공학 분야입니다. 음향 밸리 홀 효과(Acoustic Valley Hall Effect)와 후방산란이 억제되는 위상 경계 상태(Topological Edge States)를 활용하여, 장애물이나 꺾임에도 음파가 에너지 손실 없이 전달되도록 제어합니다. 또한 삼차원 위상 음향 절연체, 체르노수(Chern numbers), 비가역 음향 전송, 고집적 초음파 에너지 집속 등을 통해 초음파 비파괴 검사, 소음진동 차단, 차세대 음향 신호 처리 및 양자 음향학 응용의 지평을 넓히고 있습니다.
