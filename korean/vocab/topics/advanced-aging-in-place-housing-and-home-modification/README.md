# 고령자 계속거주 주택과 주거 개조

익숙한 집에서 오래 살아가기 위해 노후주택의 위험을 찾고, 필요한 개조를 당사자의 선택과 예산에 맞춰 설계하는 고급 한국어 어휘를 익힌다.

집을 시설처럼 바꾸는 데 그치지 않고, 안전·접근성·비용·임차권을 함께 검토하여 당사자가 원하는 생활을 계속 이어 가는 개조의 판단 흐름을 보여 준다.
