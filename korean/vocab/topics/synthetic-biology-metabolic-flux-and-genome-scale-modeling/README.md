# 합성생물학 및 대사 플럭스 분석과 게놈 스케일 모델링의 언어

합성생물학, 게놈 스케일 대사 모델링(GEM), 플럭스 균형 해석(FBA), 13C 동위원소 표지 대사 플럭스 분석(13C-MFA), 대사 제어 분석(MCA), 유전자 결실 및 세포 공장 고수율 균주 설계를 다루는 시스템생물공학 핵심 어휘

## 학습 구성
- 학습 본문: [01-metabolic-flux-and-genome-scale-modeling.md](./01-metabolic-flux-and-genome-scale-modeling.md)
- 포함 표제어 수: 15개 (B2-C2 고급 전문 학술 어휘)
- 종합 독해 단락: 15개 표제어를 모두 유기적으로 결합한 전문 학술 텍스트 (정확히 105어절) 및 베트남어 번역 수록

## 표제어 목록

1. **게놈스케일대사모델링플럭스균형해석** - phân tích cân bằng thông lượng mô hình hóa trao đổi chất quy mô bộ gen
2. **동위원소표지탄소대사플럭스분석법** - phương pháp phân tích thông lượng trao đổi chất carbon đánh dấu đồng vị
3. **단일유전자결실최적경로예측시뮬레이션** - mô phỏng dự đoán con đường tối ưu bằng loại bỏ đơn gen
4. **대사경로재설계세포공장생산수율최적화** - tối ưu hóa hiệu suất sản xuất của nhà máy tế bào bằng tái thiết kế con đường trao đổi chất
5. **미생물대사정류상태반응속도론모델링** - mô hình hóa động học phản ứng trạng thái dừng trao đổi chất vi sinh vật
6. **열역학적추진력제약대사네트워크해석** - phân tích mạng lưới trao đổi chất ràng buộc lực đẩy nhiệt động học
7. **유전체기반대사네트워크자동재구성** - tự động tái cấu trúc mạng lưới trao đổi chất dựa trên hệ gen
8. **기질소비율바이오매스생성속도상관관계** - mối tương quan giữa tốc độ tiêu thụ cơ chất và tốc độ sinh tạo sinh khối
9. **대사부산물축적억제유전자타깃선별** - sàng lọc gen mục tiêu ức chế tích tụ sản phẩm phụ trao đổi chất
10. **효소촉매효율대사제어분석탄력성계수** - hệ số đàn hồi phân tích kiểm soát trao đổi chất về hiệu quả xúc tác enzyme
11. **단백질발현비용제약대사최적화기법** - kỹ thuật tối ưu hóa trao đổi chất ràng buộc chi phí biểu hiện protein
12. **동적플럭스균형해석생물공정시뮬레이션** - mô phỏng quy trình sinh học bằng phân tích cân bằng thông lượng động
13. **유전자가위표적대사플럭스재분배유도** - dẫn hướng tái phân bổ thông lượng trao đổi chất mục tiêu bằng kéo di truyền
14. **대사체학데이터통합플럭스프로파일링** - lập hồ sơ thông lượng tích hợp dữ liệu hệ chuyển hóa học
15. **세포내에너지균형아데노신삼인산생성효율** - hiệu suất sản sinh ATP cân bằng năng lượng nội bào
