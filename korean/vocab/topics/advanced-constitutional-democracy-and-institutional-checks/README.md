# 헌법 민주주의와 제도적 견제

헌법 민주주의에서는 다수결만으로 국가 권력이 정당화되지 않는다. 법률이 기본권을 어디까지 제한할 수 있는지, 법원이 입법자의 판단을 어느 정도 심사해야 하는지, 선거와 탄핵이 어떤 절차로 민주적 정당성을 얻는지를 함께 살펴봐야 한다. 이 주제에서는 헌법재판과 의회·선거 제도를 설명할 때 필요한 고급 어휘를 익힌다.

## 학습 범위

`news_formal`은 헌법재판소 결정문, 국회 논쟁과 선거 제도 보도에서 법적 기준을 정확하게 설명할 때 쓰인다. `native_spoken`은 시민 토론이나 정치 평론에서 법원과 의회의 역할을 평가할 때 자연스럽다. 원칙의 이름을 단순히 외우기보다 기본권 보호, 다수결, 기관 간 견제가 실제 판단에서 어떻게 충돌하고 조정되는지 읽는 데 초점을 둔다.
