# 무세포 단백질 합성과 합성 생명공학의 언어

무세포 단백질 합성(Cell-Free Protein Synthesis, CFPS)과 시험관 내 전사-번역(TX-TL) 기술은 살아있는 세포의 복잡한 생리적 장벽 없이도 시험관 내에서 단백질을 초고속으로 생산할 수 있게 해 주는 차세대 합성 생명공학의 핵심 분야입니다. 본 학습 모듈에서는 비천연 아미노산의 위치 특이적 삽입, 현장 신속 백신 제조 플랫폼, 세포 추출물 기반 생물공정 및 긴급 대응형 의약품 생산망에 이르는 최첨단 무세포 생명공학 전문 용어를 다룹니다.
