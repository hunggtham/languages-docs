# 반도체 공정과 수율의 언어

반도체를 단순히 작은 부품으로 보지 않고, 설계가 웨이퍼 위에서 소자로 구현되고 양산 단계의 품질과 원가로 이어지는 흐름으로 읽는다. 공정의 물리적 단계와 현장 의사결정에서 쓰이는 고급 어휘를 연결해, 기술 기사와 제조 현장의 설명을 함께 이해한다.

## 학습 범위

`news_formal`은 반도체 산업 기사와 기업·정부 보고서에서 공정 경쟁력, 생산 안정성, 공급망을 설명할 때 쓰인다. `native_spoken`은 엔지니어가 회의와 현장에서 장비 상태, 공정 조건, 생산 전환의 현실을 조율할 때 자연스럽다. 같은 기술 용어라도 연구 단계와 양산 단계의 판단 기준이 다르므로, 단순한 성능 경쟁이 아니라 재현성·품질·시간의 균형까지 함께 익힌다.
