# 재난 위험 소통과 조기경보의 언어

재난 정보를 단순히 많이 보내는 데서 멈추지 않고, 불확실성을 설명하면서 실제 행동을 끌어내는 언어를 익힌다. 조기경보의 설계, 경보의 신뢰도, 취약한 수용자와 기관 사이의 전달 경로를 하나의 상황으로 읽는다.

## 학습 범위

`news_formal`은 재난관리 기관과 언론이 경보 성능, 위험 판단, 책임을 설명할 때 쓰인다. `native_spoken`은 주민 설명회와 현장 지휘에서 전문어를 행동 가능한 말로 풀어낼 때 자연스럽다. 경보는 기술 시스템만이 아니라 누가 무엇을 언제 이해하고 움직이는지까지 포함하는 사회적 과정으로 다룬다.
