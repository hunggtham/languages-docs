# 철도 신호와 자율 이동의 언어

열차가 서로의 위치를 알고 안전하게 양보하는 신호 논리부터, 사람이 없는 운행과 원격 개입까지 철도·자율 이동의 책임 구조를 읽는다.

신호 설비의 논리와 자율주행 시스템의 운영 한계를 한 상황 안에서 연결해, 기술 용어가 안전 책임과 어떻게 이어지는지 익힌다.
