# 공공조달과 청렴성을 읽는 언어

공공기관이 무엇을 어떻게 구매하고 계약하는지, 그리고 그 과정에서 경쟁·재량·책임이 어떻게 충돌하는지 살핀다. 입찰 공고와 감사 보도, 조직 안의 대화에서 자주 만나는 조달·부패 대응 어휘를 하나의 사례 흐름으로 연결한다.

## 학습 범위

`news_formal`은 조달 공고, 감사 결과와 정책 보도에서 절차와 책임을 정밀하게 구분할 때 쓰인다. `native_spoken`은 실무자가 평가 과정의 허점이나 조직의 묵인 구조를 설명할 때 들을 수 있는 register다. `솜방망이 처벌`처럼 평가적이고 현재적인 표현은 공식 문서의 중립어와 대비해 익힌다.
