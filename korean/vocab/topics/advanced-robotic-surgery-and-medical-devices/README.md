# 로봇수술과 의료기기의 언어

로봇이 수술자의 손을 대신한다는 단순한 서술을 넘어, 영상·계획·촉각·기기 안전이 어떻게 하나의 임상 체계를 이루는지 읽는다. 수술실의 전문어와 의료기기 규제·추적의 언어를 함께 익혀 기술의 성능과 환자 안전을 구분해 말할 수 있게 한다.

## 학습 범위

`news_formal`은 로봇수술의 임상 근거, 영상 기술, 의료기기 허가와 안전 감시를 보도하거나 평가할 때 쓰이는 정밀한 공식어다. `native_spoken`은 수술자·공학자·간호 인력이 수술 전 계획, 조작감, 장치의 한계와 환자 설명을 조정할 때 들을 수 있는 전문 구어 register다. 장치가 정교하다는 사실과 환자에게 실제 이익이 입증됐다는 판단을 분리해 말하는 데 초점을 둔다.
