# 전고체 이차전지와 고체 전해질의 언어

전고체 이차전지(All-Solid-State Lithium Secondary Battery)는 가연성 유기 액체 전해액을 불연성 무기 고체 전해질로 전면 대체하여 화재와 폭발 위험을 원천적으로 차단하고 에너지 밀도를 비약적으로 높이는 차세대 에너지 저장 공학의 핵심 혁신 분야다. 기존 리튬이온 전지가 지닌 열폭주 취약점을 극복하는 불연성 고안전성 에너지 저장은 물론, 초고이온전도성을 발휘하는 황화물계 고체 전해질막과 대기 안정성이 탁월한 산화물계 초이온전도체 세라믹 소재 기술이 융합되어 배터리의 패러다임을 전환하고 있다.

특히 충전 시 고체 전해질 결정립계를 파고드는 금속 리튬 수지상(덴드라이트) 형성 및 관통 차단 기술, 고체 입자 간 공극을 줄여 물리적 밀착을 유도하는 고체 계면 접촉 저항 극소화 전략, 균일한 등방 압력으로 결함을 제거하는 온간정수압성형(WIP) 공정, 음극 공간을 혁신적으로 없애 부피를 줄인 무음극(anodeless) 전고체 전지 설계, 4.3V 이상의 가혹한 조건에서 전해질 산화를 억제하는 고전압 양극 계면 안정화, 그리고 고온 열화 없이 치밀한 전해질 층을 형성하는 저온 소결(cold sintering) 공정에 이르는 고도화된 전기화학 공학 담론이 산업 전반을 주도하고 있다.

본 토픽에서는 차세대 전기차, 도심항공교통(UAM), 대용량 전력망 에너지 저장 장치(ESS)의 성능과 안전성을 획기적으로 견인하는 전고체 이차전지와 첨단 고체 전해질 분야의 핵심 전문 어휘 15개를 체계적으로 학습한다.
