# 디지털 치료제와 임상 근거의 언어

앱과 센서가 치료 과정에 들어오면 “기술이 작동한다”는 말만으로는 충분하지 않다. 어떤 자료를 모으고, 어떤 대조와 평가 지표를 쓰며, 사용자가 실제로 치료를 지속하는지를 함께 읽어야 한다. 이 주제는 디지털 치료기기, 임상시험 설계, 환자 경험과 데이터 품질을 하나의 판단 흐름으로 연결한다.

## 학습 범위

`news_formal`은 디지털 치료기기의 허가, 임상시험과 근거 평가를 보도하거나 심사할 때 쓰이는 정밀한 공식어다. `native_spoken`은 연구자 회의와 제품 검토에서 실제 사용 장벽, 앱 참여와 센서 자료를 풀어 말할 때 나타난다. 이 lesson은 기술의 새로움보다 비교 가능한 근거, 사용자의 지속 가능한 경험, 자료가 빠진 이유를 먼저 묻는 읽기 습관을 연습한다.
