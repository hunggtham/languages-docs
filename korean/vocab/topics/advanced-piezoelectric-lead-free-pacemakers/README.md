# 무연 압전 에너지 수확 및 무배터리 심박조율기 기술의 언어

무연 압전 에너지 수확 및 무배터리 심박조율기 공학은 독성 납(Pb)이 포함된 기존 PZT 압전 세라믹을 대체하여, 인체 무독성·생체적합성을 지닌 칼륨-나트륨 니오베이트(KNN)계 유연 복합 소재를 바탕으로 심근의 연속적인 기계적 수축·이완 운동에서 생체 운동 에너지를 고효율 전기에너지로 변환하여 수확(energy harvesting)하는 최첨단 이식형 의료기기 기술 분야입니다. 배터리의 물리적 수명(5~10년)에 따른 주기적인 개흉 재수술 위험과 감염 부작용을 원천 배제하고, 나노와트급 초저전력 심장 자극 회로, 실시간 심실 부정맥 감지 센싱, 혈관 내 카테터 경유 최소 침습 삽입 및 체외 무선 보충 기술을 통합하여 평생 자가 발전으로 구동되는 반영구적 무배터리 인공 심박조율기를 구현합니다. 본 단원에서는 무연 압전 발전, 심근 운동역학, 티타늄 기판 복합체, 생체 영구 밀봉, 폐루프 항부정맥 자극에 이르는 첨단 심장 의공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
