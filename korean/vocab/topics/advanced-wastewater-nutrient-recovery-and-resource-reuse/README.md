# 하수의 영양염을 회수해 비료 자원으로 잇는 말

하수처리의 목표는 질소와 인을 물에서 없애는 데서 끝나지 않는다. 하수·슬러지 속 영양염을 분리하고, 회수물의 오염 위험과 농업적 품질을 확인한 뒤, 실제 비료 공급망으로 연결하는 공정과 정책의 어휘를 익힌다.

## 학습 범위

`news_formal`은 하수처리장 투자, 자원화 기술과 비료 정책을 설명할 때 쓰이는 공정·규제 언어를 다룬다. `native_spoken`은 운전자가 약품 투입, 수분 제거와 회수물 판로를 설명하는 현장 표현을 다룬다. 영양염류를 단순히 제거하는 것과 쓸 수 있는 제품으로 회수하는 일을 구분하고, 회수율만이 아니라 오염물질 동반, 품질기준과 물질수지를 함께 읽는 데 초점을 둔다.
