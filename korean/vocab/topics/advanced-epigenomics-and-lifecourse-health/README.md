# 후성유전체와 생애과정 건강의 언어

환경과 생활 조건이 유전자 발현 조절에 남기는 흔적을 읽고, 그 흔적을 질병의 운명처럼 단정하지 않으면서 생애과정 건강과 연결하는 어휘를 익힌다.

이 주제는 생물학적 조절 기전과 사회적 환경을 연결하되, 연관성·인과성·가역성을 구별하는 보건의료 담화를 보여 준다.
