# 물에 반응하는 도시 설계의 언어

비를 빠르게 배출하는 데서 멈추지 않고 도시 안에서 붙잡고, 스며들게 하고, 다시 쓰는 설계의 논리를 읽는다. 스펀지시티 담론이 시설 이름의 나열이 아니라 도시수문과 공공공간, 오염 관리가 맞물리는 체계임을 이해한다.

## 학습 범위

`news_formal`은 도시계획과 기후 적응 정책을 설명할 때 쓰이고, `native_spoken`은 설계 회의와 주민 협의에서 시설의 체감과 관리 책임을 말할 때 쓰인다. 물을 하수관으로 서둘러 밀어내는 단일 해법에서 벗어나, 유출·침투·저류·수질을 한 공간에서 조정하는 사고방식을 익힌다.
