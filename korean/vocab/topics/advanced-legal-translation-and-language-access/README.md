# 법률 번역과 언어 접근의 책임

법률 문서를 다른 언어로 옮기는 일은 단어를 바꾸는 데서 끝나지 않는다. 공증과 인증, 권리 고지, 통역 자격과 비밀 유지까지 이어지는 절차를 따라가며 언어 접근이 법적 이해와 참여를 가능하게 하는 조건임을 익힌다.
