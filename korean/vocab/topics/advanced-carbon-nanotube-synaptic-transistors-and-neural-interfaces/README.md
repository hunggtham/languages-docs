# 탄소 나노튜브 시냅스 트랜지스터와 신경 인터페이스의 언어

탄소 나노튜브 시냅스 트랜지스터(carbon nanotube synaptic transistor)와 생체 신경 인터페이스(neural interface) 기술은 우수한 전기적 특성과 기계적 유연성을 지닌 나노소재를 기반으로 뇌 신경세포와 전자 소자 간의 신호 전달을 모사하고 직접 소통하는 최첨단 나노바이오전자공학 분야입니다. 유연 반도체 나노튜브 네트워크(flexible semiconductor nanotube network)와 뇌신경 모사 이온젤 게이트(brain-inspired ion-gel gate)를 통해 초저전력 인공 시냅스 가소성(ultra-low-power artificial synaptic plasticity)을 구현하며, 장기 강화·장기 억제 정밀 제어(precise control of LTP/LTD)를 달성합니다. 나아가 생체 신경세포 직접 전기 접합(direct electrical junction with biological neurons) 및 신경전달물질 감응 시냅스(neurotransmitter-sensitive synapse)를 바탕으로 생체 이온 신호-전기 신호 변환(biological ion-to-electrical signal transduction)과 신경 인터페이스 초고감도 기록(ultra-high-sensitivity neural interface recording)을 수행함으로써, 세포 부착 신경 신호 양방향 소통(cell-adhesive bidirectional neural communication)과 미래 나노바이오전자공학(future nanobioelectronics)의 핵심 토대를 마련합니다.
