# 도시 화물과 연석 관리의 언어

택배와 상업 배송이 보행·주차·대중교통과 같은 도로변 공간을 어떻게 공유하는지 읽는다. 연석을 고정된 주차면이 아니라 시간대별로 배분하고 관리하는 도시 운영의 어휘를 익힌다.

## 학습 범위

`news_formal`은 하역 구역, 화물 진입 시간, 저공해 물류와 같은 도시 물류 정책을 분석할 때 쓰인다. `native_spoken`은 배송 예약, 화물자전거, 공유 하역장처럼 현장에서 공간을 조정하고 서비스를 이용하는 상황에 초점을 둔다. 기존의 `도시물류`나 `공동배송`보다 한 단계 좁혀, 도로변의 한정된 연석 공간을 누가 언제 어떻게 사용하는지 설명하는 표현들이다.
