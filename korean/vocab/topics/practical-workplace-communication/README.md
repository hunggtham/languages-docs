# 실무 소통과 협업의 기술

직장과 비즈니스에서 예의를 지키며 협의·조율하고, 피드백과 우선순위를 통해 신뢰를 쌓는 어휘를 학습한다.

- [조정과 실행을 선명하게 만드는 실무 표현](./02-coordination-and-execution.md) — `업무 조정`, `이해 조율`, `업무 가시성`, `자원 배분`, `역할 명확화`, `조직 간 협업`, `대안 제시`, `리스크 공유`, `업무 병목`, `실행 가능성`, `문서화 수준`, `승인 절차`
