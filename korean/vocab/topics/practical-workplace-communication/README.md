# 실무 소통과 협업의 기술

직장과 비즈니스에서 예의를 지키며 협의·조율하고, 피드백과 우선순위를 통해 신뢰를 쌓는 어휘를 학습한다.

## 학습 파일

- [함께 일하기 위한 말과 태도](./01-workplace-communication-and-collaboration.md) — `매너`, `비즈니스`, `협의`, `조율`, `피드백`, `우선순위`, `마감`, `보고`, `회람`, `참조`, `재촉`, `배려`, `갈등`, `타협`, `신뢰`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 사전적 의미와 실제 직장 대화의 register를 함께 보여 준다.
