# 담수 생태와 하천 재자연화의 언어

하천을 단순한 배수로가 아니라 물·퇴적물·생물·사람이 연결된 생태계로 읽는다. 직강화와 불투수화가 만든 문제를 연속성, 생태유량, 범람원 재연결과 회복탄력성의 관점에서 설명하는 어휘를 익힌다.

## 학습 범위

`news_formal`은 하천 정책, 생태복원 설계와 수질·홍수 위험을 보도하거나 평가할 때 쓰인다. `native_spoken`은 주민 설명회와 현장 점검에서 기술어를 풀어 설명할 때 자연스럽다. 하천의 물리적 구조를 고치는 일과 생물의 회복, 지역의 안전을 하나의 복원 흐름으로 묶어 읽는다.
