# 방언학 및 언어지리학의 언어

방언학 및 언어지리학(Dialectology, Linguistic Geography, and Geolinguistics)은 지리적 격리와 사회적 계층화에 따른 방언의 음운, 형태, 어휘 변이를 현장 조사하고 등어선(Isogloss)을 도면화하여 언어의 역사적 진화와 문화적 확산 경로를 규명하는 언어학의 핵심 분야입니다. 본 단원에서는 등어선 언어지도 경계 구획, 방언구획론 음운체계 분류, 성조방언 악센트 음조 실측, 지역방언 형태음소 변이 조사, 사회방언 사회계층 변이 연구, 언어 변이형 소멸위기 보존, 구술자료 방언 음성·음향 채록, 방언 어휘 지리적 확산 경로, 도서·해안 고립방언 보존 연구, 접촉방언 언어 간섭·동화 현상, 고대어 잔존형 방언 어휘 발굴, 방언사전 어휘지리학 편찬, 화자 연령별 방언 사용 분화, 표준어 대응 토박이말 채록, 미래 방언학 언어지리학 조사에 이르는 15개 핵심 전문 어휘를 학습합니다.
