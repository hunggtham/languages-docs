# 메타표면 보텍스 빔 생성기와 궤도각운동량 다중화 기술의 언어

현대 첨단 나노광학과 차세대 통신 공학에서는 빛의 파면을 서브파장 수준에서 자유자재로 조작하여 나선형 위상을 갖는 광학 소용돌이(Optical Vortex)를 생성하고, 빛의 궤도각운동량(OAM) 모드를 활용하여 데이터 전송 대역폭을 획기적으로 확장하는 연구가 활발히 진행되고 있습니다. 메타표면 기반의 초박형 평면 광학 소자는 기존의 크고 무거운 굴절 광학 부품을 대체하여 초소형 온칩 집적을 가능하게 하며, 원편광 변환에 따른 스핀-궤도 결합 현상과 위상 특이점 배열 제어를 통해 다중 토폴로지컬 전하 모드를 초고속으로 다중화 및 역다중화할 수 있는 길을 열었습니다. 본 주제는 궤도각운동량 메타표면, 온칩 보텍스 빔 방출기, 광집게 미세입자 포획, 공간모드 분할 복합화 및 미래 나노광학 통신망을 아우르는 핵심 전문 어휘와 기술 담론을 체계적으로 다룹니다.
