# 공동체 토지 신탁과 주거 안정

토지를 공동체가 보유하고 주택의 사용권과 자산 형성 기회를 분리해 주거비 상승과 퇴거 위험을 낮추는 정책·운영의 언어를 익힌다.

토지의 공공성, 주택의 사용권, 주민의 자치와 자산 형성을 한 지역 협약의 흐름으로 연결해 읽는다.
