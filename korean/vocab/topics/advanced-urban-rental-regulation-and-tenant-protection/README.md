# 도시 임대차 규제와 임차인 보호

임대료 조정, 계약 갱신, 보증금의 우선순위, 퇴거 절차를 둘러싼 법적 언어를 익히며 임대인과 임차인의 권리가 어떻게 조정되는지 읽는다.
