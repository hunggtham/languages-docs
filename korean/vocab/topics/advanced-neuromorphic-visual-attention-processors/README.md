# 뉴로모픽 시각 어텐션 프로세서 및 사카딕 시각 기술의 언어

뉴로모픽 시각 어텐션 프로세서(Neuromorphic Visual Attention Processors) 및 사카딕(Saccadic) 안구 운동 공학은 인간 시각계의 고효율 선택적 주의집중(Selective Visual Attention)과 안구 도약 기작을 실리콘 반도체 아키텍처로 모사하여, 초당 수 기가바이트에 달하는 고밀도 시각 스트림 중 인지적으로 가장 현저한(salient) 핵심 영역에만 비동기 스파이크 연산 자원을 집중 배치하는 차세대 초저전력 인공지능 시각 하드웨어 분야입니다. 주변 시야의 배경 잡음과 중복된 시각 정보를 하드웨어 레벨에서 사전에 희소화하고, 초소형 구동기 및 전자식 조향 제어를 통해 관심 영역(ROI)으로 시선을 즉시 도약시킴으로써 마이크로초 단위의 초저지연 객체 추적과 고정밀 패턴 분류를 동시에 달성합니다. 본 단원에서는 뉴로모픽 시각 어텐션 프로세서, 사카딕 도약 안구 운동 하드웨어, 선택적 초점 현저성 지도 생성, 초저전력 시각 정보 희소화, 사건 구동 비동기 스파이크 연산, 공간 시간 필터 기반 특징 추출, 온칩 동적 동공 반사 제어, 시각 주의집중 메커니즘 모사, 엣지 컴퓨팅 초고속 객체 추적, 배경 잡음 억제 관심 영역 추출, 초저지연 시각 피질 다층 신경망, 적응형 해상도 스케일링 회로, 비동기 이벤트 기반 패턴 분류, 자율 에이전트 초소형 시각 엔진, 미래 신경모사 시각 어텐션 공학에 이르는 최첨단 생체모사 시각 컴퓨팅 분야의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
