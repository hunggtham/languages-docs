# 페로브스카이트 멤리스터와 뉴로모픽 어레이의 언어

차세대 인공지능 하드웨어와 뇌모사 컴퓨팅 분야에서 할라이드 페로브스카이트 멤리스터(Halide perovskite memristors)와 아날로그 시냅스 가소성(analog synaptic plasticity)은 초저전력 엣지 연산을 구현하는 핵심 기술로 주목받고 있습니다. 본 주제는 도전 경로 제어, 크로스포인트 어레이, 스파이크 타이밍 의존 가소성(STDP) 등 전공 기술 어휘를 체계적으로 학습하여 고급 학술 및 공학적 소통 능력을 배양합니다.
