# 정밀 영양과 대사체 프로파일링의 언어

정밀 영양(Precision Nutrition)과 대사체 프로파일링(Metabolomic Profiling)은 유전체, 장내 미생물, 대사 산물 및 실시간 생체 신호를 융합하여 개인 맞춤형 식이 전략을 도출하는 첨단 생명·영양의학 분야이다. 전통적인 획일적 식이지침에서 벗어나, 개개인의 영양소 대사 효율과 식후 혈당 반응을 정량적으로 추적하고 만성 염증 및 대사증후군을 예방·관리하는 과학적 임상 중재를 핵심 축으로 삼는다. 본 주제에서는 오믹스(Omics) 분석, 디지털 헬스케어 기기, 임상 영양 중재 현장에서 통용되는 핵심 전문 어휘를 체계적으로 학습한다.
