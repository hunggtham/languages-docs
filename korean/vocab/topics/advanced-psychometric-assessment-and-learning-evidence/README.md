# 고급 평가와 학습 증거의 언어

학습자의 능력을 한 번의 점수로 단정하지 않고, 문항·과제·채점·추적 자료가 무엇을 얼마나 정확히 보여 주는지 살핀다. 교육 현장의 대화와 연구·정책 보고서에서 평가 결과를 해석하고 한계를 설명하는 어휘를 익힌다.

## 학습 파일

- [평가 설계와 학습 궤적](./01-assessment-design-and-learning-trajectories.md) — `문항반응이론`, `잠재변수`, `준거참조평가`, `규준참조평가`, `수행평가`, `형성평가`, `총괄평가`, `타당도`, `신뢰도`, `판별도`, `문항난이도`, `루브릭`, `채점자간신뢰도`, `종단자료`, `추적조사`

## 학습 범위

`news_formal`은 교육 연구·정책 보고서에서 측정 모형과 근거의 수준을 구분할 때 쓰인다. `native_spoken`은 교사·연구자·평가 담당자가 실제 과제와 채점 결과를 조정하며 설명할 때 들을 수 있는 전문 구어 register다. 점수를 능력 그 자체로 오해하지 않고 타당도, 신뢰도, 표본의 한계와 시간에 따른 변화를 함께 말하는 데 초점을 둔다.
