# 하이드로겔 구동기와 소프트 로보틱스의 언어

하이드로겔 구동기와 소프트 로보틱스 분야는 생체 조직의 유연성과 적응성을 모방하여 정밀한 자극 감응형 변형을 구현하는 첨단 융합 학문입니다. 온도, pH, 전기장, 자기장 등의 외부 환경 변화를 인지하고 자체적으로 팽창, 수축, 굽힘 등의 기계적 움직임을 수행하는 고성능 연성 로봇 시스템의 핵심 원리를 다룹니다.
