# 프라이버시 공학과 데이터 거버넌스의 언어

데이터를 많이 모으는 것보다 어떤 위험을 예측하고, 처리 목적과 접근 권한을 어떻게 통제하며, 분석 가치를 남기면서 개인을 보호하는지가 중요하다. 이 topic은 설계 단계의 위협 모델링부터 암호 기술, 데이터 운영 계약과 감사까지 한 흐름으로 연결해 익히도록 돕는다.

## 학습 범위

`news_formal`은 개인정보 감독, 암호 연구, AI·데이터 거버넌스 보고서에서 쓰이는 전문 register다. `native_spoken`은 보안·데이터 팀이 설계 검토와 운영 회의에서 위험과 책임을 설명할 때 쓰이는 실무 register다. 기술 이름만 외우지 않고, 위험의 측정과 완화, 주체 간 신뢰, 데이터의 생애주기를 함께 읽는다.
