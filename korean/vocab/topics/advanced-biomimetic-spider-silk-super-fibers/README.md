# 생체 모사 인공 거미줄 초고강도 섬유 기술의 언어

생체 모사 인공 거미줄 초고강도 섬유 기술은 자연계에서 가장 우수한 기계적 인성(toughness)과 비강도를 지닌 거미줄 단백질(spidroin)의 나노 분자 구조와 거미의 방사 메커니즘을 규명하고, 이를 합성생물학 및 정밀 방사 공학으로 모방하여 방탄 복합재, 초경량 항공우주 구조재, 인체 무해 외과 수술용 봉합사 등으로 실현하는 첨단 바이오 신소재 공학 분야입니다. 단단한 베타-시트 나노결정과 유연한 비정질 단백질 사슬이 이상적으로 결합된 하이브리드 나노구조를 유전자 재조합 미생물로 발현시키고, 미세유체 습식 방사와 분자 정렬 연신 공정을 통해 케블라(Kevlar)를 능가하는 충격 흡수 에너지와 뛰어난 생분해성을 동시에 구현합니다. 본 단원에서는 초고인성 구조 단백질 공학과 차세대 생체 모사 섬유의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
