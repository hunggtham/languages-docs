# 문화유산 디지털화와 반환의 책임

문화유산을 디지털로 기록하는 기술과, 그 자료와 실물을 원소장 공동체와 다시 연결하는 책임을 함께 살핀다. 디지털 복제물이 원본의 권리와 맥락을 대신할 수 있는지, 반환 협상에서 어떤 기록과 동의가 필요한지 판단하는 표현을 익힌다.

## 학습 파일

- [디지털 기록과 문화재 반환을 잇는 언어](./01-cultural-heritage-digitization-and-repatriation.md) — `문화유산 기록화`, `3차원 기록화`, `디지털 표준화`, `디지털 진본성`, `영구식별자`, `디지털 수장고`, `디지털 큐레이션`, `접근 제한`, `문화재 반환 협상`, `반환 협정`, `원소장국`, `강제 취득`, `취득 경위`, `전통지식 권리`, `문화적 민감성`

이 파일은 박물관·아카이브·원소장 공동체가 디지털 자료를 만들고 반환을 협의하는 상황을 하나의 맥락으로 묶는다. 기록 기술의 `news_formal` 표현과 공동체 협의에서 쓰이는 `native_spoken` 표현을 함께 익히며, 디지털 접근이 곧 소유권이나 무제한 공개를 뜻하지 않는다는 점을 구별한다.
