# 정밀농업 및 스마트 온실 생명공학의 언어

정밀농업 및 스마트 온실 생명공학(Precision Agriculture, Smart Greenhouses, and Agri-Tech Biotechnology)은 사물인터넷(IoT) 센서, 다중분광 드론, 인공지능 생육 모델을 결합하여 온·습도와 광량을 최적화하고, 순환식 수경재배와 로봇 수확으로 농업 생산성을 극대화하며 기후변화에 대응하는 첨단 미래 농업기술 분야입니다. 본 단원에서는 스마트온실 복합환경제어 시스템, 정밀농업 다중분광 드론 원격탐사, 양액재배 순환식 수경재배 장치, 생육단계별 인공지능 관수제어, 농업용 로봇 자동수확 선별시스템, 토양센서 질소·인·칼륨 비옥도 측정, 수직농장 인공광 광합성 효율화, 디지털농업 디지털트윈 생육모델, 친환경 천적 활용 해충방제 기술, 작물 미소기상 데이터 모니터링, 유전자교정 내염성 작물 품종 개발, 농업부산물 바이오차 탄소격리, 농산물 스마트 산지유통센터 구축, 기후변화 적응 아열대 작물 실증, 미래 정밀농업 애그리테크 혁신에 이르는 15개 핵심 전문 어휘를 학습합니다.
