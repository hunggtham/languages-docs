# 도시 열저장과 상변화 소재의 언어

도시 건물의 냉난방 피크를 낮추기 위해 열을 저장하고 필요한 시간에 꺼내 쓰는 원리를 익힌다. 상변화물질의 재료 거동과 건물 운영의 수요 조정을 하나의 현장 이야기로 연결한다.

## 학습 파일

- [상변화 소재로 냉난방 수요를 옮기다](./01-thermal-storage-and-phase-change-materials.md) — `잠열`, `상변화물질`, `축열밀도`, `과냉각`, `핵생성`, `열이력`, `상안정성`, `열화`, `피크부하`, `부하이동`, `열저항`, `열관성`, `온도구배`, `축열조`, `열손실계수`

재료 내부의 상변화와 건물 운영의 시간 이동을 함께 읽으며, 실험실 성능과 실제 도시 에너지 서비스가 왜 다를 수 있는지 살핀다.
