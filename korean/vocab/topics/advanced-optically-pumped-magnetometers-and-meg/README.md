# 광학 펌핑 자력계와 뇌자도 계측의 언어

광학 펌핑 자력계(Optically Pumped Magnetometers, OPM)와 웨어러블 뇌자도(MEG) 기술은 기존의 극저온(액체 헬륨) 환경이 필수적이던 SQUID 기반 뇌자도 계측의 한계를 극복하고, 상온에서 초고감도로 생체 자기장을 측정할 수 있게 해주는 최첨단 양자 센싱 분야입니다. 루비듐 원자증기셀 내부의 원자 스핀을 레이저로 펌핑하고 광자기 공명을 검출함으로써 극미세 뇌신경 전류에 의해 발생하는 자기장을 머리에 착용한 가벼운 헬멧 형태로 실시간 매핑할 수 있습니다. 본 교육 과정에서는 OPM 및 뇌자도 계측과 관련된 고도화된 전문 어휘들을 학습합니다.
