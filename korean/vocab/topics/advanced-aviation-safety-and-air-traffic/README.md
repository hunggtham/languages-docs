# 항공 안전과 운항 흐름의 언어

항공편이 정시에 뜨는 문제만이 아니라 공역을 배분하고 위험을 기록하며 승무원과 정비 조직이 안전을 관리하는 과정을 고급 한국어로 읽는다. 전문 보고서와 사고 조사, 현장 브리핑에서 자주 만나는 항공 안전 어휘를 하나의 운항 시나리오로 연결한다.

## 학습 초점

이 lesson은 `항공교통흐름관리`, `공역 혼잡`, `슬롯 배정`처럼 공항과 하늘의 용량을 조정하는 말에서 출발해 `활주로 침범`, `조류 충돌`, `사고 근접 사건`처럼 위험을 기록하는 표현으로 이어진다. 마지막에는 `피로 위험 관리`, `승무원 자원 관리`, `항공 안전 감독`, `안전 관리 체계`를 통해 개인의 실수보다 조직이 위험을 발견하고 줄이는 구조를 설명하는 방식을 연습한다.
