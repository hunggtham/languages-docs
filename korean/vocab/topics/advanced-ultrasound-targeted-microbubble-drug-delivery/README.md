# 집속 초음파 표적 미세기포와 약물 전달의 언어

현대 의학과 나노바이오융합기술의 발전으로, 뇌신경질환 및 난치성 암 치료에서 비침습적 약물 전달의 중요성이 급부상하고 있습니다. 특히 **집속초음파표적미세기포** 기술과 **혈뇌장벽가역적개방기술**은 단단한 생체 장벽을 안전하게 우회하여 고분자 약물을 목적 부위에 정확히 도달시키는 혁신적인 음향 의학 분야입니다. 

본 단원에서는 음향 공진, 공동현상, 지질 나노기포 외피, 실시간 영상 모니터링 등 초음파 기반 표적 치료와 관련된 고급 전문 어휘 15개를 엄선하여 심층적으로 학습합니다.

## 학습 파일
- [초음파 미세기포와 표적 약물 전달](./01-ultrasound-targeted-microbubble-drug-delivery.md) — 집속초음파표적미세기포, 혈뇌장벽가역적개방기술, 음향공진유도약물방출, 초음파조영기포약물전달, 공동현상국소항암치료, 표적지향성지질나노기포, 초음파유도혈관투과증진, 뇌신경질환정밀약물주입, 실시간초음파영상모니터링, 생체적합성인지질외피, 국소부위약물축적극대화, 차세대비침습약물송달, 음향치료초음파변환기, 나노바이오메디컬융합기술, 미래초정밀음향치료의학
