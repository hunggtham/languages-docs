# 고고학 자료와 문화유산의 맥락

유물을 따로 떼어 외우기보다 층위, 연대, 환경, 보존이라는 연결망으로 문화유산을 읽는다. 발굴 현장의 판단과 박물관의 설명에서 자료가 놓인 맥락을 복원하는 고급 표현을 익힌다.

## 학습 파일

- [자료의 층위와 보존 맥락](./01-archaeological-evidence-and-heritage-context.md) — `층위학`, `편년`, `유구`, `문화층`, `출토맥락`, `고고자료`, `고환경`, `탄소연대측정`, `동위원소 분석`, `미세잔존물`, `잔존물 분석`, `형질인류학`, `원격탐사`, `매장문화재`, `보존처리`

이 파일은 발굴·연구·보존 현장에서 실제로 판단의 근거를 설명할 때 쓰는 전문어를 묶는다. 일부 용어는 연구 보고서와 뉴스의 `news_formal`, 일부는 현장 협업과 박물관 설명의 `native_spoken` 맥락에서 익힌다.
