# 시각문화와 예술 비평의 언어

작품의 겉모습을 묘사하는 데서 멈추지 않고, 이미지가 어떤 맥락에서 만들어지고 관객에게 어떻게 받아들여지는지 읽는다. 전시·영화·공공미술·비평 담화에서 자주 만나는 형식, 재현, 전유와 수용의 어휘를 연결한다.

## 학습 파일

- [형식과 맥락, 관객의 시선](./01-form-and-context-and-reception.md) — `미장센`, `서사성`, `조형성`, `전유하다`, `탈맥락화`, `도상성`, `파편화`, `응축하다`, `복원성`, `설치미술`, `감응하다`, `형상화`, `변주성`, `환유`, `수용미학`

## 학습 범위

`news_formal`은 전시 비평, 문화 정책, 영화·미술 보도에서 작품의 구조와 사회적 의미를 정밀하게 분석할 때 쓰인다. `native_spoken`은 큐레이터와 관객이 작품의 인상이나 차용된 이미지를 이야기할 때 실제로 들을 수 있는 표현이다. 같은 이미지를 보더라도 전시 공간, 인용된 원본, 관객의 경험에 따라 의미와 평가가 달라지므로 사전식 번역만으로 판단하지 않는다.
