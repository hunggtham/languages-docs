# 슈퍼커패시터 소재와 의사 커패시턴스의 언어

이 토픽은 첨단 메타물질 슈퍼커패시터, 의사 커패시턴스 에너지 저장 메커니즘, 나노 복합체 전극 설계, 고속 이온 삽입·탈리 반응, 그리고 차세대 친환경 전력망 및 모빌리티 응용 분야를 다루는 고급 한국어 어휘 세트입니다. 전지(Battery)의 고에너지 밀도와 커패시터(Capacitor)의 초고출력 특성을 융합하는 최신 전기화학 및 재료공학 전문 용어를 학습합니다.

## 학습 파일
- [메타물질 슈퍼커패시터와 의사 커패시턴스 에너지 저장](./01-metamaterial-supercapacitors-and-pseudocapacitive-storage.md) — 슈퍼커패시터소재, 의사커패시턴스에너지저장, 전도성고분자나노복합체, 이온삽입탈리초고속반응, 초고출력밀도충방전, 전극비표면적극대화, 장수명사이클안정성, 전기화학적임피던스최소화, 겔고분자고체전해질, 급속충전모빌리티전원, 다공성전이금속탄화물소재, 하이브리드에너지저장장치, 에너지밀도한계극복기술, 차세대초고속에너지저장, 분산전원주파수조정용전원
