# 뉴로모픽 이벤트 기반 비전 센서 및 동적 시각 기술의 언어

뉴로모픽 이벤트 기반 비전 센서(Neuromorphic Event-Based Vision Sensors) 및 동적 시각 시스템 공학은 인간 망막의 생물학적 시각 정보 처리 메커니즘을 모사하여, 초당 고정된 프레임(FPS)을 일괄 전송하는 기존 롤링/글로벌 셔터 카메라의 근본적 한계를 탈피하고 화소별 조도 변화(로그 휘도 증감)가 일어난 순간에만 마이크로초(µs) 단위의 비동기적 스파이크 이벤트를 독립적으로 생성·출력하는 차세대 초저전력·초고속 시각 감지 반도체 기술 분야입니다. 모션 블러(motion blur)를 원천 차단하고 120dB 이상의 초광대역 동적 범위(HDR)를 달성하여, 직사광선과 칠흑 같은 암흑이 공존하는 극한 조명 환경에서도 초고속 자율주행 차량의 돌발 장애물 감지, 자율비행 드론의 초고속 자세 제어 및 엣지 AI 지능형 시각 인식을 완벽히 지원합니다. 본 단원에서는 동적 비전 센서 비동기 화소, 생체모사 인공망막, 희소 이벤트 스트림 엔코딩, 온칩 시계열 모션 벡터 추출, 저조도 시각 복원에 이르는 최첨단 사건 구동형 신경모사 시각 공학의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
