# 유연 열전 발전기와 체온 에너지 수확의 언어

유연 열전 발전기(fTEG)와 체온 에너지 수확은 인체와 주변 환경 사이의 미세한 온도 차이를 이용하여 전기를 생산하는 차세대 친환경 에너지 기술입니다. 이 분야는 유기무기 복합 열전 재료, 나노선 제베크 계수 극대화, 포논 산란을 통한 열전도율 저감, 그리고 ZT 성능 지수 최적화 등을 통해 웨어러블 전자기기의 전력 자립화를 실현하고자 합니다.
