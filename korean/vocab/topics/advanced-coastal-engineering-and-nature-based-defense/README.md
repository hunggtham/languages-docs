# 해안공학과 자연기반 방재의 언어

파랑과 퇴적물의 움직임을 계산하는 해안공학이 습지·사구·식생의 완충 기능과 어떻게 결합하는지 읽는다. 구조물을 세우는 선택과 자연의 회복 과정을 대립시키기보다, 위험·생태·지역 이용을 함께 설계하는 표현을 익힌다.

## 학습 파일

- [파랑을 낮추고 해안을 회복시키는 설계](./01-coastal-engineering-and-nature-based-defense.md) — `연성 호안`, `경성 호안`, `사빈 복원`, `양빈`, `모래 포집`, `사구 전진`, `표사 이동`, `퇴적 수지`, `조간대 완충`, `생태공학적 설계`, `자연기반 방재`, `다기능 방재`, `후퇴선`, `파랑 감쇠`, `월파 저감`

## 학습 범위

`news_formal`은 해안공학 설계, 환경영향평가와 방재 투자에서 쓰이는 전문어다. `native_spoken`은 주민 설명회에서 공사 방식과 경관·생태의 변화를 풀어 말할 때 유용하다. 하나의 해법을 만능으로 제시하지 않고, 파랑·퇴적·생태·접근성의 상호작용을 살피는 것이 핵심이다.
