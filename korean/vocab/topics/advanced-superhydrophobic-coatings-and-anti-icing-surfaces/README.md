# 초발수 코팅과 결빙 방지 계면 공학의 언어

본 레슨에서는 초발수 계면, 연잎 효과의 마이크로·나노 구조, 방빙 및 제빙 표면, 광열 자가 제빙, 그리고 항공기·풍력 발전 블레이드·해양 구조물 등 첨단 산업 분야에 적용되는 결빙 방지 코팅 기술의 핵심 어휘 15개를 다룹니다. 극한 환경에서의 표면 물성과 소재 공학적 전문 용어를 학습할 수 있습니다.
