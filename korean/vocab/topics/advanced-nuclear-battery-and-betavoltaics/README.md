# 동위원소 베타전지와 원자력 마이크로 전원의 언어

원자력 베타전지(Betavoltaics)와 동위원소 마이크로 전원은 방사성 동위원소의 붕괴 과정에서 방출되는 베타선(고에너지 전자)을 반도체 접합 등을 통해 전기에너지로 직접 변환하는 차세대 초장수명 전력원 기술입니다. 탄소-14(Carbon-14) 다이아몬드 베타볼타익이나 니켈-63(Nickel-63) 박막 소재는 외부 충전이나 유지보수 없이 수십 년에서 수백 년 동안 안정적인 미세 전력을 공급할 수 있어, 심우주 탐사선, 심해 해저 센서, 인체 삽입형 의료기기(심장박동기 등)와 같은 극한 환경 및 반영구적 독립 전원이 요구되는 최첨단 분야의 핵심 기술로 주목받고 있습니다. 본 주제에서는 와이드 밴드갭 반도체 접합, 방사선 원천 차폐 설계, 고에너지 밀도 동위원소 소재 등 이 기술을 구성하는 전문 어휘와 개념들을 심도 있게 학습합니다.
