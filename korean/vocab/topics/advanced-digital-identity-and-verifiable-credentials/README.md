# 디지털 신원과 검증 가능한 자격의 언어

온라인 서비스에서 신원을 드러내고 증명하는 방식을, 개인정보 최소 공개와 신뢰의 흐름이라는 관점에서 익힌다.

## 학습 파일

- [신원을 설계하고 자격을 검증하다](./01-digital-identity-and-verifiable-credentials.md) — `분산신원증명`, `자기주권신원`, `검증가능자격증명`, `탈중앙식별자`, `선택적공개`, `자격증명철회`, `신원연계`, `주체결속`, `쌍별식별자`, `신뢰사슬`, `자격증명지갑`, `기기증명`, `재전송공격`, `영속식별자`, `상관관계추적`

각 항목은 전자 신분증과 자격 증명 서비스를 설계하는 상황을 따라가며, 누구에게 무엇을 얼마나 보여 줄지와 검증 실패에 대응하는 절차를 연결한다.
