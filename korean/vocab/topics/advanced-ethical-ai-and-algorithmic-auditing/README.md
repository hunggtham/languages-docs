# 윤리적 인공지능과 알고리즘 감사의 언어

데이터의 대표성부터 배포 뒤 감시와 이의 제기까지, 인공지능 시스템의 책임을 추적하고 점검하는 어휘를 익힌다.

## 학습 파일

- [알고리즘을 점검하고 책임을 설계하다](./01-algorithmic-audit-and-accountability.md) — `데이터시트`, `데이터대표성`, `표본편향`, `인과공정성`, `집단별오류율`, `공정성상충`, `반사실검증`, `배포전검증`, `배포후감시`, `위험등록부`, `평가프로토콜`, `감사증적`, `설명요구권`, `인간우선원칙`, `퇴출기준`

각 파일은 실제 정책·제품 검토 상황을 따라가며 데이터, 평가, 권리 구제와 모델 수명주기의 연결을 보여 준다.
