# 행동경제학과 선택의 설계

사람은 늘 충분한 정보와 완벽한 계산으로 결정하지 않는다. 이 주제에서는 판단을 흐리는 편향과 선택 환경을 바꾸는 설계가 실제 정책·서비스·소비 장면에서 어떻게 작동하는지 읽는다. 심리학적 현상을 단순한 성격 결함으로 보지 않고, 정보 구조와 시간 압박, 사회적 신호가 선택에 미치는 영향까지 함께 살핀다.

## 학습 파일

- [편향을 읽고 선택 환경을 설계하다](./01-biases-and-choice-architecture.md) — `인지적 구두쇠`, `선택설계`, `기저율 무시`, `과신 편향`, `후회 회피`, `현상 유지 편향`, `자기고양 편향`, `선택 과부하`, `시간 할인`, `심리적 회계`, `사회적 선호`, `현재 편향`, `손실 회피`, `소유 효과`, `기준점 효과`

## 학습 범위

`news_formal`은 정책 평가, 소비자 보호, 금융·보건 커뮤니케이션에서 선택 구조와 판단 오류를 정밀하게 설명할 때 쓰인다. `native_spoken`은 상담, 회의와 일상적인 의사결정에서 “왜 그렇게 골랐는지”를 되짚을 때 자연스럽다. 편향이라는 말을 사람을 비난하는 낙인으로 쓰지 않고, 어떤 정보와 시간 조건이 판단을 바꾸었는지 분석하는 데 초점을 둔다.
