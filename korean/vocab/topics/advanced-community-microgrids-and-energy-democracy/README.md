# 공동체 마이크로그리드와 에너지 민주주의의 운영 언어

주민이 마이크로그리드의 소유와 운영에 참여하고, 에너지 전환의 비용과 편익을 함께 결정하는 장면을 읽는다. 기술 설비보다 의사결정 구조, 권리, 공개와 환원의 언어에 초점을 둔다.
