# 도시의 물을 다시 연결하는 순환과 중수도의 언어

가정과 건물에서 나온 물을 용도별로 나누고, 빗물·처리수·영양분을 도시 안에서 다시 연결하는 어휘를 익힌다. 기술의 이름만 외우지 않고 안전성, 자원 회수, 주민 신뢰가 함께 설계되는 맥락을 읽는 데 초점을 둔다.

이 파일은 주거·공공건물의 회색수 관리에서 도시 규모의 물 재이용과 하수 자원 회수까지, 순환 인프라를 설명하는 formal·현장 register를 연결한다.
