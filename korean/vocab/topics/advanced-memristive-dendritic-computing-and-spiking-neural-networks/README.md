# 멤리스터 수지상돌기 연산 및 스파이킹 신경망의 언어

멤리스터(memristor) 기반 수지상돌기(dendritic) 연산과 스파이킹 신경망(spiking neural networks, SNN) 기술은 폰 노이만 병목(von Neumann bottleneck)과 무어의 법칙 한계를 극복하고 인간 뇌의 고효율 지능 정보 처리를 반도체 하드웨어로 구현하는 첨단 뉴로모픽 공학의 핵심 분야입니다. 생물학적 신경세포의 복잡한 수지상 분기에서 일어나는 비선형 신호 통합, 시공간 일치 감지 및 국소 가소성 제어 기작을 나노 스케일 저항 스위칭 멤리스터와 비동기 사건 기반 회로로 모사함으로써, 극단적인 초저전력 환경에서도 복잡한 시계열 센서 데이터와 음성·영상 패턴을 실시간으로 분류할 수 있습니다. 본 단원에서는 멤리스터 수지상돌기 연산소자, 시냅스후전위 비선형 통합, 스파이킹 신경망 시공간 패턴 인식, 동적 임계치 스위칭, 온칩 비동기 사건 기반 신경망 및 생체적합성 단백질 멤리스터에 이르는 최신 뇌 모사 인공지능 하드웨어 분야의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
