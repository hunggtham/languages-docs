# 정밀의료와 바이오마커 검증

정밀의료는 환자를 하나의 평균값으로 다루지 않고 유전체, 종양의 변화, 치료 반응과 검사 성능을 함께 해석하는 접근이다. 이 주제에서는 약물 선택부터 바이오마커의 분석적·임상적 검증까지 이어지는 현대 의생명과학의 담화를 읽는다.

- [정밀의료와 바이오마커 검증](./01-precision-medicine-and-biomarker-validation.md) — `약물유전체학`, `다중오믹스`, `액체생검`, `순환종양DNA`, `최소잔존질환`, `종양변이부담`, `현미부수체불안정성`, `클론진화`, `환자층화`, `동반진단`, `분석적타당성`, `임상적유용성`, `외부검증`, `교정도`, `양성예측도`

## 학습 범위

`news_formal`은 임상시험, 규제 심사와 정밀의료 연구에서 근거의 수준과 검사 성능을 정확히 말할 때 쓰인다. `native_spoken`은 연구자와 임상의가 검사 결과와 치료 선택을 협의할 때 자연스럽다. 전문어를 단순히 번역하기보다 바이오마커가 환자 선별, 예측과 실제 진료에 어떻게 연결되는지 읽는 데 초점을 둔다.
