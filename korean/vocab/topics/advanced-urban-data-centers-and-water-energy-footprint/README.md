# 도시 데이터센터와 물·에너지 발자국의 언어

도시 데이터센터는 연산을 제공하는 동시에 막대한 전력과 냉각수를 사용한다. 이 lesson은 물 부족 지역에 시설을 배치하고, 냉각 방식과 전력 부하를 조절하며, 폐열을 다시 도시 서비스에 연결하는 과정에서 필요한 고급 어휘를 하나의 설계 회의 흐름으로 묶는다.

## 학습 범위

`news_formal`은 데이터센터 입지, 물 사용 공개, 전력망 부담과 도시 기후 정책을 보도하거나 평가할 때 쓰인다. `native_spoken`은 운영팀과 지자체가 냉각 장애, 서버 부하, 재이용수와 폐열 연결을 조정할 때 쓰는 실무어다. 핵심은 전력 사용량만 줄이는 것이 아니라 물·에너지·열의 흐름을 함께 관리하는 데 있다.
