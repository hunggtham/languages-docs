# 도시 미기후와 옥상 녹화의 설계 언어

건물과 포장이 만든 열을 측정하고, 옥상·식재·빗물·바람을 함께 설계하는 도시 기후 어휘를 익힌다. 기술 용어를 단순한 친환경 홍보 문구와 구별하면서 주민의 체감, 형평성, 유지관리까지 읽는다.

각 파일의 읽기 지문은 하나의 생활권 계획 상황에서 최대 15개 target을 자연스럽게 연결하며, 기술 효과와 주민이 실제로 이용할 수 있는 조건을 함께 보여 준다.
