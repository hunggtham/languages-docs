# 허위정보에 흔들리지 않는 위기 소통의 언어

재난이나 감염병 유행처럼 불안이 큰 상황에서는 사실만 많이 제공한다고 신뢰가 자동으로 생기지 않는다. 정보가 퍼지는 속도와 서사의 방향을 읽고, 불확실성을 정직하게 표시하면서도 사람들이 실제로 행동할 수 있게 안내해야 한다. 이 주제는 언론 브리핑, 공공기관 안내, 지역사회 대응과 온라인 검증에서 쓰이는 고급 표현을 다룬다.

## 학습 범위

`news_formal`은 재난 정보, 공공기관의 브리핑과 플랫폼 책임을 분석할 때 쓰이고, `native_spoken`은 주민과 기자가 불안, 소문과 정정의 효과를 이야기할 때 들을 수 있다. 선제적으로 설명하더라도 모든 예측을 단정해서는 안 되며, 모르는 부분을 표시하는 태도 자체가 신뢰의 기반이 된다는 점이 핵심이다.
