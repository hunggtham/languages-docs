# 제품을 오래 쓰게 하는 수리 경제와 수리권의 언어

제품의 순환성은 폐기 단계의 재활용률만으로 결정되지 않는다. 얼마나 쉽게 고칠 수 있는지, 필요한 부품과 정보에 접근할 수 있는지, 수리 서비스가 지역사회에 열려 있는지를 함께 살펴야 한다. 이 주제는 제조사·소비자·수리업체 사이의 책임을 설명하는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 에코디자인 규정, 제조사의 서비스 정책과 소비자 보호를 논할 때 쓰인다. `native_spoken`은 가전제품을 고치거나 수리점을 찾는 일상 대화에서 자연스럽다. `slang_online`은 수리 비용과 제조사 대응에 대한 소비자 반응을 읽을 때 제한적으로 참고한다. 수리를 개인의 부지런함으로만 보지 않고 설계·정보·부품·서비스 접근성의 문제로 연결하는 것이 핵심이다.
