# 양자 기술과 암호 체계의 전환

양자 기술을 막연한 미래 기술로 외우지 않고, 계산의 단위와 오류, 통신 보안의 전환이라는 연결된 흐름으로 읽는다. 연구 발표와 보안 회의에서 자주 만나는 전문어를 통해 기술의 가능성과 한계를 함께 설명하는 연습을 한다.

## 학습 범위

`news_formal`은 연구 투자, 국가 보안, 표준화와 암호 전환을 설명하는 공식 register다. `native_spoken`은 연구자·보안 담당자가 회의나 인터뷰에서 기술의 불확실성과 운영상의 우선순위를 풀어 말할 때 자연스럽다. 양자 계산의 물리적 개념과 조직의 암호 전환 계획을 한 흐름으로 묶어, 과장된 성능 주장과 실제 보안 준비를 구별한다.
