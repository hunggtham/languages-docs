# 디지털 콘텐츠 접근성과 멀티미디어 설계의 언어

디지털 콘텐츠의 접근성은 화면을 볼 수 있느냐의 문제가 아니라, 서로 다른 감각·입력 방식·기기 환경에서도 정보를 이해하고 행동으로 옮길 수 있느냐의 문제다. 이 lesson은 웹페이지, 영상, 오디오와 상호작용 콘텐츠를 누구나 이용할 수 있게 설계하고 검수할 때 쓰는 한국어를 다룬다.

## 학습 범위

`news_formal`은 디지털 서비스 기준, 콘텐츠 제작 지침과 접근성 감사 보고서에서 설계 조건과 책임을 정밀하게 설명할 때 쓰인다. `native_spoken`은 제작팀 회의와 검수 과정에서 사용자가 실제로 막히는 지점을 말할 때 자연스럽다. 영상 자막만 추가하는 데 그치지 않고, 이미지·소리·색·초점·상호작용에 대체 경로가 있는지를 함께 판단한다.
