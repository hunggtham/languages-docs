# 산림 탄소회계와 자연시장 언어

숲의 탄소를 숫자로 세는 일과 자연의 가치를 시장에 연결하는 일은 단순한 상쇄 상품 만들기가 아니다. 기준선을 정하고 실제 추가 효과를 검증하며, 산림 훼손의 책임과 지역사회의 권리를 함께 설명하는 정책·금융 어휘를 익힌다.

## 학습 범위

`news_formal`은 산림정책, 탄소시장 규칙, 기업 공시와 자연금융 보고서에서 기준선·검증·권리 문제를 정밀하게 말할 때 쓰인다. `native_spoken`은 현장 조사, 주민 협의와 프로젝트 심사에서 숫자의 의미와 책임을 풀어 설명할 때 자연스럽다. 탄소 크레딧의 양만 보지 않고 추가성, 영속성, 누출 위험, 생물다양성 및 지역사회 편익을 한 묶음으로 판단한다.
