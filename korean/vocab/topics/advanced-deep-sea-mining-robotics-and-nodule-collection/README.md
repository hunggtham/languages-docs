# 심해 채광 로봇과 망간단괴 채집의 언어

수심 5,000미터 초고압 환경 무인 궤도 주행 채광 로봇, 망간단괴 집해 수직 양광 파이프라인, 음향 측위 항법 및 부유토사 확산 방지 친환경 심해 자원 개발 어휘.
