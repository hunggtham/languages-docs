# 연안 어민 생계와 기후 적응의 언어

기후 변화가 어장과 항구만 바꾸는 것이 아니라 어민의 소득, 안전, 유통과 세대 재생산을 어떻게 흔드는지 읽는다. 생태 변화에 대응하면서도 생계의 선택권을 넓히는 정책과 현장 협의의 표현을 함께 익힌다.

## 학습 범위

`news_formal`은 수산 정책, 기후 적응 계획과 지역 경제 분석에서 쓰이는 표현을 다룬다. `native_spoken`은 어민·협동조합·지자체가 출어 일정, 소득 위험과 공동 대응을 조율할 때 들을 수 있는 말이다. 어장을 보전하는 것과 어민의 생계를 보장하는 것을 대립시키지 않고, 위험을 나누고 선택지를 늘리는 과정을 어휘로 읽는다.
