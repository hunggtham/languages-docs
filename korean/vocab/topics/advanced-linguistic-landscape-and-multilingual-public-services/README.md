# 다언어 공공서비스와 언어경관

공공장소의 언어 표지와 행정 서비스가 여러 언어 공동체를 어떻게 드러내고 배려하는지 살펴본다. 언어경관, 언어권리, 통역과 현지화가 단순한 번역을 넘어 접근성과 시민의 소속감에 어떻게 연결되는지 익힌다.
