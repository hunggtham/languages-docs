# 산불의 불길과 생태계 위험의 언어

산불은 바람에 따라 번지는 불길만의 문제가 아니다. 숲속 연료의 배열과 수분, 화재의 층위와 대류, 그리고 불이 지나간 뒤 토양·식생·유역이 바뀌는 과정을 함께 읽어야 위험의 크기와 복원 방향을 판단할 수 있다.

## 학습 범위

`news_formal`은 산불 관측, 위험 예보, 생태계 평가와 복원 정책을 정밀하게 말할 때 쓰인다. `native_spoken`은 현장 지휘관·주민·산림 관리자가 불길의 변화를 설명하고 대피·진화·복구 순서를 조율할 때 들을 수 있는 표현이다. 불이 난 순간의 규모만 보지 않고, 연소 방식과 산불 뒤의 토양·식생 변화를 하나의 위험 연쇄로 이해한다.
