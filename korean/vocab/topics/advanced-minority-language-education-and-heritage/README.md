# 소수언어를 배우고 공동체의 언어 유산을 이어 가는 언어

소수언어의 지속성은 사라질 위기에 놓인 단어를 모으는 일만으로 보장되지 않는다. 아이가 집과 학교에서 자연스럽게 언어를 쓰고, 장년 세대의 기억과 지역 공동체의 경험이 다음 세대로 이어지며, 교육 자료와 교사 양성이 함께 마련되어야 한다. 이 주제는 언어 둥지, 유산언어, 언어 회복과 같은 개념을 교육 현장과 공동체의 실천 속에서 읽는 고급 한국어를 다룬다.

## 학습 범위

`news_formal`은 소수언어 정책, 학교 교육과정과 기록 사업을 보도하거나 평가할 때 쓰인다. `native_spoken`은 가족이 어떤 언어로 아이와 이야기할지, 지역 수업에 참여할지 논의하는 대화에서 들을 수 있다. 언어를 박물관에 보관하는 것과 실제 생활에서 다시 쓰이게 하는 일은 다르므로, 학습자는 교육 접근성·세대 전승·공동체 주도성을 함께 살펴야 한다.
