# 위상 엑시톤-폴라리톤 및 빛-물질 강결합 소자의 언어

위상 엑시톤-폴라리톤(topological exciton-polariton) 및 빛-물질 강결합(strong light-matter coupling) 소자 기술은 반도체 미소공진기 내에서 빛(광자)과 물질의 전자-정공 쌍(엑시톤)이 가역적으로 에너지를 교환하며 결합하는 준입자의 양자역학적 특성과 위상수학(topology)의 불변성 원리를 융합하여, 외부 환경 노이즈나 구조적 결함에 의한 후방 산란 없이 신호를 손실 없이 전송하고 초저임계 레이징을 실현하는 첨단 나노광학 및 양자물리학 분야입니다. 원자 단위의 초미세 광학 격자 및 이차원 반도체 헤테로구조에서 발현되는 엑시톤-폴라리톤 보스-아인슈타인 응축은 거시적 양자 결맞음과 무마찰 초유체 흐름을 형성하며, 인공 스핀-궤도 게이지장과 시간 역전 대칭 파괴를 통해 단방향으로만 전파되는 키랄 에지 모드를 제공합니다. 본 단원에서는 토폴로지컬 엑시톤-폴라리톤 응축, 빛-물질 강결합 미소공진기, 위상학적 폴라리톤 레이저, 스핀-오빗 게이지장, 무손실 에지 상태, 단일 광자 비선형성, 상온 스위칭 및 미래 위상 광양자 소자 공학에 이르는 차세대 빛-물질 결합 광집적회로의 핵심 전문 어휘 15개를 체계적으로 학습합니다.
