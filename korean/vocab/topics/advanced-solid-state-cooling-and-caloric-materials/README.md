# 고체 냉각과 열량 효과 신소재의 언어

자기열량, 탄성열량, 전기열량 등 외력에 따른 고체 격자 엔트로피 상변화 원리를 이용해 냉매 누출 없이 높은 열효율을 구현하는 차세대 고체 냉각 어휘를 다룹니다. 온실효과를 유발하는 기존 증기 압축식 냉매 가스를 원천 배제하고, 고체 신소재 내부의 스핀·격자·전기 분극 엔트로피 전이를 제어하여 냉각 사이클을 구동하는 최첨단 친환경 열역학 및 열관리 시스템의 핵심 개념과 공학적 표현을 체계적으로 학습할 수 있도록 구성되었습니다.
