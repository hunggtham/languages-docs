# 마이크로 LED 대량 전사와 초고해상도 디스플레이의 언어

차세대 디스플레이 기술의 핵심인 마이크로 LED 대량 전사(Mass Transfer) 및 초고해상도 디스플레이 기술은 수백만 개에 달하는 초미세 발광 다이오드 칩을 기판 위에 정밀하고 신속하게 실장하는 첨단 공정 분야입니다. 유체 자가 조립, 엘라스토머 스탬프, 롤투롤 전사, 레이저 유도 전방 전사(LIFT) 등의 혁신적인 전사 기법을 통해 초고해상도 무기물 디스플레이, 확장현실(XR) 스마트 글래스, 투명 플렉서블 패널을 구현하며, 자발광 마이크로 화소의 적녹청(RGB) 집적과 계면 접합 신뢰성을 극대화하여 미래 초실감형 비주얼 디바이스의 지평을 열어가고 있습니다.
