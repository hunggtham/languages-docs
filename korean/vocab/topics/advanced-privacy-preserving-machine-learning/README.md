# 프라이버시 보존형 머신러닝의 공격과 방어

프라이버시 보존형 머신러닝은 원자료를 숨기는 것만으로 끝나지 않는다. 모델의 출력과 학습 업데이트에서 어떤 정보가 새어 나오는지, 악의적인 데이터가 학습을 어떻게 오염시키는지, 보호 장치가 정확도와 통신 비용을 어떻게 바꾸는지 함께 판단해야 한다. 이 topic은 공격자의 추론부터 연합학습의 집계·클리핑·프라이버시 회계까지 하나의 검토 흐름으로 연결한다.

## 학습 범위

`news_formal`은 AI 안전성·개인정보 감독·보안 연구 보고서에서 공격 가능성과 보장 수준을 따지는 전문 register다. `native_spoken`은 ML 플랫폼과 데이터 팀이 모델 출시 검토에서 위험, 정확도, 운영 비용을 조정할 때 쓰는 실무 register다. 각 기술이 자동으로 프라이버시를 보장한다고 가정하지 않고, 위협 모델과 실제 관찰 가능한 정보의 범위를 함께 읽는다.
