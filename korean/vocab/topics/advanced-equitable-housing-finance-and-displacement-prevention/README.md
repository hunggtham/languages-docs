# 주거 금융 형평성과 이주 방지

주택 금융의 문턱과 개발 압력이 누구에게 불리하게 작동하는지 살피고, 세입자와 기존 주민이 동네에 계속 머물 수 있도록 하는 정책 언어를 익힌다.
