# 바다의 공간을 조정하고 블루이코노미를 설계하는 언어

해양 공간은 어업, 항만, 해상풍력, 보전과 관광이 동시에 요구되는 공공 자원이다. 이 주제는 서로 다른 이용을 조정하고 생태계의 한계를 넘지 않으면서 지역 경제의 가치를 키우는 해양 정책·산업 담화의 어휘를 다룬다.

## 학습 범위

`news_formal`은 해양 정책, 환경영향 검토, 금융과 산업 전략을 보도하거나 분석할 때 쓰인다. `native_spoken`은 어민, 주민, 기업과 행정기관이 바다의 이용 순서와 지역 이익을 협의하는 대화에서 들을 수 있다. 개발 사업의 경제성만 따지지 않고 공간의 충돌, 생태계 서비스와 장기 회복력을 함께 읽는 것이 핵심이다.
