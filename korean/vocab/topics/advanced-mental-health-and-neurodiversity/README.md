# 정신건강과 신경다양성의 언어

감각과 인지의 차이를 병리화하지 않으면서도, 상담·교육·직장 담화에서 실제로 쓰이는 고급 표현을 읽는다. 임상적 진단을 대신하지 않고 당사자의 경험과 사회적 맥락을 설명하는 어휘에 초점을 둔다.

## 학습 범위

이 주제의 표제어는 건강·교육·노동 환경에서 사람의 경험을 설명하는 데 필요한 표현이다. `news_formal`은 정책·연구·공공 담화, `native_spoken`은 상담과 일상 대화, `slang_online`은 당사자 커뮤니티와 온라인에서 널리 쓰이는 현대적 용례를 가리킨다. 특정 표현을 사람의 정체성이나 진단으로 단정하지 말고, 문맥과 당사자의 선호를 함께 살핀다.
