# 해저 광물 채굴과 저서 생태계 보전의 언어

심해는 배터리와 첨단 기술 산업에 필수적인 핵심 광물이 매장된 자원의 보고이자, 지구상에서 가장 미지의 영역으로 남아 있는 취약한 생명의 안식처다. 전 세계적으로 에너지 전환과 공급망 확보를 위한 해저 광물 채굴 논의가 가속화되는 한편, 빛이 닿지 않는 심해 바닥의 생태계 파괴와 회복 불가능한 환경 피해를 경고하는 목소리도 커지고 있다. 본 주제에서는 국제 해저 거버넌스, 지질 및 자원 채굴 기술, 생태계 영향 평가와 해양 환경 보전 규범을 아우르는 전문적인 현대 한국어 어휘를 체계적으로 학습한다.
