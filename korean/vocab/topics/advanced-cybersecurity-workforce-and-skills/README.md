# 사이버 보안 인력을 키우고 역량을 설계하는 언어

사이버 보안은 도구를 구입하는 일만으로 강화되지 않는다. 조직은 어떤 역량이 부족한지 진단하고, 채용·교육·개발·운영의 경계를 다시 설계해 보안을 일상적인 업무 능력으로 만들어야 한다.

## 학습 범위

`news_formal`은 인력 정책과 조직 역량을 분석하는 보고서·언론의 말이다. `native_spoken`은 개발팀과 보안팀이 채용, 교육과 협업 방식을 조정할 때 쓰는 실무어이며, `slang_online`에 가까운 차용어는 실제 업계 대화에서 굳어진 형태를 중심으로 다룬다. 사람을 단순한 자원으로 세지 않고 역량을 조직의 과정에 연결하는 것이 핵심이다.
