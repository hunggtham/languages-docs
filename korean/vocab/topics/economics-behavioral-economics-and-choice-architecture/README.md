# 행동경제학 및 선택 설계학 공공 정책의 언어

행동경제학 및 선택 설계학 공공 정책(Behavioral Economics, Choice Architecture, and Public Policy)은 전통 신고전파 경제학의 비현실적인 '합리적 인간(Homo economicus)' 가정을 극복하고, 실제 인간의 불완전한 인지적 편향, 감정적 충동, 사회적 상호작용 및 휴리스틱을 실증적으로 규명하여 더 나은 개인의 의사결정과 효과적인 공공 정책을 설계하는 현대 경제학의 가장 혁신적인 융합 학문 분야입니다. 카너먼과 트버스키의 전망 이론과 손실 회피, 리처드 탈러의 심적 회계와 넛지(Nudge), 선스타인의 자유주의적 개입주의와 선택 아키텍처, 시간 할인과 현재 편향, 닻내림 효과와 소유 효과, 최후통첩 게임의 공정성 인식, 그리고 정보 비대칭의 역선택 방지와 기본값 옵트아웃 정책에 이르기까지 조세, 금융, 보건, 환경 정책 전반을 혁신하는 실천적 개념들을 포괄합니다. 본 단원에서는 넛지 이론 선택 설계, 제한된 합리성 휴리스틱, 현재 편향 시간 할인, 손실 회피 프레이밍, 닻내림 효과, 사회적 규범 동조 압력, 기본값 옵트아웃, 자기통제 실패, 심적 회계, 최후통첩 게임 공정성, 과잉 확신 편향, 소유 효과, 정보 비대칭 역선택, 행동경제학 공공 개입, 미래 행동경제학 의사결정론에 이르는 15개 핵심 전문 어휘를 깊이 있게 학습합니다.
