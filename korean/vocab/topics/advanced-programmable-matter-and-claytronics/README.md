# 프로그래머블 물질과 클레이트로닉스의 언어

이 단원은 최첨단 소재 공학 및 로보틱스 분야인 프로그래머블 물질(Programmable Matter), 클레이트로닉스(Claytronics), 초소형 카툼(Catom) 자가 조립, 삼차원 동적 형태 재구성, 그리고 합성 현실 인터페이스를 아우르는 고급 한국어 어휘를 다룹니다. 디지털 정보가 물리적 실물로 직접 구현되는 미래 기술 생태계를 정확하고 깊이 있게 이해할 수 있도록 설계되었습니다.
