# 카이랄 메타물질과 원편광 이색성의 언어

현대 나노광학 및 광전자공학에서 카이랄 메타물질과 원편광 이색성(Circular Dichroism, CD) 분야는 거울상 이성질체의 초정밀 분별, 광자 스핀 제어, 그리고 생체 거대분자의 고감도 감지 등을 가능하게 하는 최첨단 융합 학문 영역입니다. 본 학습 단원에서는 3차원 나노 나선형 구조체와 나노스케일 카이랄 공진기를 바탕으로 좌우 원편광의 비대칭 투과 특성을 극대화하는 전문 어휘들을 깊이 있게 다룹니다.

## 학습 파일
- [카이랄 메타물질과 원편광 이색성 전문 어휘](./01-chiral-metamaterials-and-circular-dichroism.md) — 카이랄메타물질광학소자, 거대원편광이색성스펙트럼, 삼차원나노나선형구조체, 광학활성생체거대분자식별, 원편광초고감도바이오센싱, 좌우원편광비대칭투과, 거울상이성질체초정밀분별, 광자스핀홀효과초표면, 신약후보물질광학순도측정, 나노스케일카이랄공진기, 원편광기반입체디스플레이, 차세대카이랄나노광학, 고집적편광제어광학소자, 바이오의약품품질평가키트, 미래초정밀키랄진단시스템
