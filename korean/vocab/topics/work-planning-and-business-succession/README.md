# 업무 계획과 사업 승계

계약·자금·업무 기준을 세우고, 가족 사업이나 조직의 책임을 다음 단계로 넘기는 데 필요한 어휘를 학습한다.

## 학습 파일

- [작은 사업의 계획과 다음 세대](./01-planning-and-succession.md) — `청약`, `예치`, `제안`, `과업`, `확보하다`, `분배`, `상시`, `추후`, `표준`, `예비`, `증대`, `가업`, `대물림하다`, `상용`, `자칭하다`
- [사업 연속성과 운영 리스크의 언어](./02-business-continuity-and-operating-risk.md) — `사업 연속성`, `리스크 관리`, `핵심 인력`, `의사결정 권한`, `비상 계획`, `현금 흐름`, `원가 구조`, `협상력`, `시장 진입`, `인수인계 공백`, `조직 탄력성`, `성과 연동 보상`

각 파일의 읽기 지문은 최대 15개 target headword를 포함하며, 행정·비즈니스 용어와 일상적인 사업 맥락을 함께 보여 준다.
