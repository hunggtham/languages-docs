# 연구 설계와 추론의 언어

자료를 모으는 일만으로는 좋은 연구가 되지 않는다. 무엇을 어떻게 정의하고, 누구를 표집하며, 측정의 흔들림과 해석의 한계를 어떻게 드러내는지가 결론의 신뢰도를 좌우한다. 이 lesson은 연구자와 정책 분석가가 설계·추정·검증의 선택을 설명할 때 쓰는 고급 어휘를 하나의 흐름으로 묶는다.

## 학습 파일

- [측정에서 일반화까지 연구 설계를 점검하는 말](./01-measurement-and-generalization.md) — `조작적 정의`, `표집틀`, `표본추출`, `측정오차`, `측정불변성`, `매개효과`, `조절효과`, `추정량`, `민감도분석`, `강건성`, `내생성`, `식별가능성`, `인과효과`, `반사실`, `일반화가능성`

## 학습 범위

`news_formal`은 연구 보고서, 정책 평가, 학술 논문과 과학 보도에서 설계와 추론의 타당성을 논할 때 쓰인다. `native_spoken`은 연구팀 회의나 분석 협의에서 결과의 해석 범위와 설계상의 약점을 짚을 때 쓰는 실무어다. 이 주제에서는 유행어를 억지로 넣지 않고, 실제 연구·정책 맥락에서 굳어진 전문어를 중심으로 다룬다.
