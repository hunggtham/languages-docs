# 빙하 수문학과 빙권 변화의 언어

빙하와 영구동토가 녹을 때 물의 저장·방출·재분배가 어떻게 달라지는지 읽는다. 과학 보도, 재난 관리, 지역사회 협의에서 얼음의 변화를 수문 위험과 연결해 말하는 어휘를 익힌다.

## 학습 범위

`news_formal`은 빙권 관측, 수자원 전망과 재난 정책을 정밀하게 말할 때 쓰인다. `native_spoken`은 현장 조사와 주민 설명에서 전문어를 풀어 말할 때 필요하다. 얼음의 감소를 단순한 경관 변화로 보지 않고 저장된 물, 토사, 지하수와 하류의 위험이 연결되는 과정으로 읽는다.
