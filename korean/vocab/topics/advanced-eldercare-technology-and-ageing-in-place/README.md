# 고령친화 기술과 지역사회 계속거주

집을 떠나 시설에 들어가는 것만이 노년의 안전한 선택은 아니다. 주거·돌봄·건강 기술을 당사자의 선택권과 사생활에 맞게 연결하여, 익숙한 지역에서 오래 살아가는 조건을 읽는 어휘를 익힌다.

가정 안의 센서와 앱만 소개하지 않고, 기술이 가족·요양 인력·지역 서비스의 역할을 어떻게 바꾸는지 한 시범사업의 설계와 점검 흐름으로 보여 준다.
