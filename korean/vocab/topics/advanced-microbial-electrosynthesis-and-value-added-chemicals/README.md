# 미생물 전기합성과 탄소순환 생물공학의 언어

미생물 전기합성(Microbial Electrosynthesis, MES)과 탄소순환 생물공학은 재생 가능 전력을 이용하여 이산화탄소와 같은 온실가스를 고부가가치 화학물질이나 청정 생물 연료로 전환하는 최첨단 융합 학문 분야입니다. 이 분야는 세균과 전극 사이의 세포외전자전달(EET) 인터페이스를 기반으로 하며, 차세대 지속 가능한 탄소 중립 사회를 실현하기 위한 핵심 기술로 주목받고 있습니다.
