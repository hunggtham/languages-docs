# 미생물 전기합성과 고부가가치 화학물질 생산의 언어

미생물 전기합성(MES) 공학은 재생 가능한 전기에너지와 미생물의 대사 능력을 결합하여 온실가스인 이산화탄소를 고부가가치 유기산, 바이오 연료 등 탄소중립 화학원료로 생체 변환하는 첨단 생물전기화학 분야입니다. 이 토픽에서는 전기를 이용해 미생물 촉매로 탄소를 자원화하고 지속 가능한 바이오리파이너리를 구축하는 데 사용되는 핵심 어휘들을 다룹니다.
