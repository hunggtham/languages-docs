# 산불 연기와 공중보건의 언어

산불의 위험은 불길이 지나간 뒤에도 연기와 미세 오염물질의 이동, 화학적 변화, 사람들의 노출을 통해 이어진다. 이 주제는 산불 연기가 어떻게 퍼지고 변하는지, 어떤 건강 취약성이 문제를 키우는지, 주민 안내가 어떤 행동으로 이어져야 하는지를 한국어로 읽는 연습이다.

## 학습 범위

`news_formal`은 산불 감시, 대기질 분석과 보건 당국의 위험 안내에서 오염물질의 경로와 근거를 정밀하게 말할 때 쓰인다. `native_spoken`은 학교·보건소·가정에서 연기 노출을 줄이는 행동을 설명할 때 자연스럽다. `slang_online` 대신 재난 상황의 실제 안내 언어에 초점을 두며, 전문 용어는 공포를 키우는 낙인보다 측정값·노출 시간·취약성을 함께 설명하는 데 사용한다.
