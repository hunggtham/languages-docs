# 희귀질환 치료제 개발의 경로와 근거

희귀질환 치료제는 환자 수가 적다는 이유만으로 임상 근거를 느슨하게 만드는 분야가 아니다. 질병이 자연스럽게 어떻게 진행되는지 기록하고, 어떤 환자에게 어떤 결과가 중요한지 정한 뒤, 작은 표본에서도 해석 가능한 시험과 규제 경로를 설계해야 한다. 이 주제에서는 연구자·환자·규제기관이 치료 개발의 불확실성을 어떻게 다루는지 읽는다.
