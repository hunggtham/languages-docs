# 학교 급식과 아침 돌봄망의 언어

이 lesson은 학교 식사를 한 끼의 제공으로만 보지 않고, 결식 예방·영양 정보·방학 돌봄과 지역 연계를 함께 움직이는 접근망으로 읽는다.
