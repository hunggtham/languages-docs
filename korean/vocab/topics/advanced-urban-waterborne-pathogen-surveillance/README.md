# 도시 수인성 병원체 감시의 언어

도시의 하수와 수질 자료를 이용해 병원체의 흔적을 읽고, 표본의 한계와 예측 결과를 공중보건 조치로 연결하는 과정을 익힌다. 연구실 용어뿐 아니라 역학자·지자체·현장 담당자가 자료의 불확실성을 조율할 때 쓰는 표현을 함께 다룬다.

## 학습 범위

`news_formal`은 환경역학 연구, 수질 관리와 감염병 정책을 정밀하게 말할 때 쓰인다. `native_spoken`은 연구자·지자체 담당자가 채취 일정, 결과의 한계와 대응 수위를 조율할 때 들을 수 있는 표현이다. 검출 자체를 확진으로 과장하지 않고 시료의 대표성, 시계열 흐름과 임상 자료를 함께 해석하는 어휘 묶음이다.
