# 원격탐사와 지구관측 자료를 읽는 언어

빛과 전파를 이용해 지표를 관측하는 센서의 선택부터 보정, 분류, 변화 해석까지 이어지는 어휘를 익힌다. 같은 장면도 파장·관측 시기·처리 방법에 따라 다른 의미를 낳는다는 점을 중심으로 읽는다.

## 학습 파일

- [센서 자료를 보정하고 지표 변화를 해석하다](./01-remote-sensing-and-earth-observation.md) — `다중분광`, `초분광`, `관측폭`, `재방문주기`, `방사보정`, `대기보정`, `구름마스킹`, `변화탐지`, `객체기반분류`, `감독분류`, `무감독분류`, `분광지수`, `데이터큐브`, `정합오차`, `스와스`

각 항목은 실제 지구관측 처리 회의와 재난·환경 모니터링 상황을 따라가며 센서 자료를 정책 판단으로 연결할 때 필요한 한계와 선택을 보여 준다.
