# C2 Vocabulary — Launch and spaceport operations robotics

This lesson follows a launch campaign from pad inspection and propellant loading to payload handling, range safety, and recovery. The network is **launch pad inspection robot → rocket engine test robot → fueling umbilical robot → cryogenic line inspection → payload fairing handling robot → satellite cleanroom robot → spacecraft thermal vacuum robot → launch tower elevator robot → range safety tracking drone → rocket stage transport robot → ground support equipment robot → payload encapsulation robot → orbital propellant servicing robot → space debris tracking system → mission control assistant robot → radiation test robot → spacecraft docking simulator robot → launch weather balloon robot → reentry heat shield inspection → spaceport fire response robot**.

## 1. launch pad inspection robot /lɔːntʃ pæd ɪnˈspekʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that checks a launch pad, its structures, and service connections before a launch.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot check launch pad, structure và service connection trước launch.
**Grammar & collocations:** `launch-pad-inspection-robot camera` — camera; `inspect a flame trench` — inspect flame trench.
**Examples:** `The launch pad inspection robot found debris near the flame trench.` → Robot inspection launch pad tìm debris gần flame trench.
**Liên kết tiếng Hàn:** `발사대 검사 로봇`.
