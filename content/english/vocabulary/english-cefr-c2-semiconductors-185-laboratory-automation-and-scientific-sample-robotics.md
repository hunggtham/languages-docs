# C2 Vocabulary — Laboratory automation and scientific-sample robotics

This lesson follows a research sample from accession and storage to preparation, analysis, chain of custody, and waste handling. The network is **lab sample transport robot → high-throughput sample robot → mass spectrometer loading robot → chromatography fraction robot → spectroscopy sample robot → cleanroom lab robot → laboratory freezer inventory robot → biobank retrieval robot → specimen accessioning robot → centrifuge loading robot → cell sorter maintenance robot → microscope slide scanning robot → histology staining robot → reagent preparation robot → laboratory waste robot → sample chain-of-custody robot → instrument calibration robot → lab contamination monitoring robot → research animal cage robot → scientific imaging robot**.

## 1. lab sample transport robot /læb ˈsæmpəl ˈtrænspɔːrt ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that moves laboratory samples between receiving, storage, preparation, and analysis areas.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot move lab sample giữa receiving, storage, preparation và analysis area.
**Grammar & collocations:** `lab-sample-transport-robot cart` — cart; `move a sealed tube` — move tube sealed.
**Examples:** `The lab sample transport robot moved the sealed tube to the analysis room.` → Robot transport lab sample chuyển tube sealed tới analysis room.
**Liên kết tiếng Hàn:** `실험실 샘플 운반 로봇`.
