# C2 Vocabulary — Telecom field and network-infrastructure robotics

This lesson follows a communications network from tower inspection and fiber work to emergency restoration, power, and connector care. The network is **cell tower inspection drone → antenna alignment robot → fiber cable repair robot → telecom tower climbing robot → microwave link inspection drone → base station cooling robot → fiber splice robot → utility pole inspection drone → network cabinet patrol robot → fiber route mapping robot → subsea telecom cable robot → emergency cell site robot → radio spectrum survey drone → antenna de-icing robot → tower lightning protection inspection → telecom battery replacement robot → small-cell installation robot → network power audit robot → fiber connector cleaning robot → remote telecom field robot**.

## 1. cell tower inspection drone /sel ˈtaʊər ɪnˈspekʃən droʊn/
**Part of speech:** noun
**Core meaning (English):** a drone that inspects antennas, cables, mounts, and structures on a cellular tower.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** drone inspect antenna, cable, mount và structure trên cell tower.
**Grammar & collocations:** `cell-tower-inspection-drone camera` — camera; `inspect a corroded bracket` — inspect bracket corroded.
**Examples:** `The cell tower inspection drone found a corroded bracket below the antenna array.` → Drone inspection cell tower tìm bracket corroded dưới antenna array.
**Liên kết tiếng Hàn:** `셀 타워 검사 드론`.
