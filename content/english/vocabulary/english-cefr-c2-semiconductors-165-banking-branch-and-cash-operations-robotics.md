# C2 Vocabulary — Banking-branch and cash-operations robotics

This lesson follows a bank branch from customer arrival and document intake to cash handling, security, and ATM maintenance. The network is **branch service robot → cash recycler robot → ATM replenishment robot → vault inventory robot → check deposit scanner → document authentication robot → cash transport robot → banknote sorting robot → coin processing robot → fraud review assistant robot → customer queue triage robot → safe deposit access robot → branch cleaning robot → security patrol robot → loan document intake robot → signature verification robot → teller assist robot → cash forecasting system → night deposit retrieval robot → ATM maintenance robot**.

## 1. branch service robot /bræntʃ ˈsɜːrvɪs ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that provides information, directions, or simple assistance in a bank branch.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot cung cấp information, direction hoặc simple assistance trong bank branch.
**Grammar & collocations:** `branch-service-robot kiosk` — kiosk; `direct a visitor to a desk` — direct visitor tới desk.
**Examples:** `The branch service robot directed the visitor to the business-banking desk.` → Branch service robot hướng visitor tới desk business banking.
**Liên kết tiếng Hàn:** `은행 지점 서비스 로봇`.

## Review in context

A **branch service robot**, **cash recycler robot**, and **ATM replenishment robot** support everyday transactions, while a **vault inventory robot** and **check deposit scanner** record assets and documents. A **document authentication robot**, **cash transport robot**, **banknote sorting robot**, and **coin processing robot** protect processing accuracy. A **fraud review assistant robot** and **customer queue triage robot** route people and cases; a **safe deposit access robot**, **branch cleaning robot**, and **security patrol robot** support secure operations. A **loan document intake robot**, **signature verification robot**, and **teller assist robot** help staff. A **cash forecasting system**, **night deposit retrieval robot**, and **ATM maintenance robot** connect planning with after-hours service.
