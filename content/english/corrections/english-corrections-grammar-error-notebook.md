# 1. Subject--Verb Agreement

❌ He have finished. ✅ He has finished.

❌ She have seen the film. ✅ She has seen the film.

❌ It have been outside. ✅ It has been outside.

------------------------------------------------------------------------

# 2. Present Perfect Structure

Formula:

have/has + V3

❌ have arrive ✅ have arrived

❌ has came ✅ has come

❌ have eat ✅ have eaten

❌ has happen ✅ has happened

------------------------------------------------------------------------

# 3. V2 vs V3

  V1      V2      V3
  ------- ------- ---------
  go      went    gone
  come    came    come
  eat     ate     eaten
  write   wrote   written
  see     saw     seen
  break   broke   broken
  fall    fell    fallen
  grow    grew    grown
  ride    rode    ridden

------------------------------------------------------------------------

# 4. Present Simple vs Present Continuous

State verbs usually DON'T use Continuous.

❌ I'm knowing him. ✅ I know him.

❌ Are you believing...? ✅ Do you believe...?

------------------------------------------------------------------------

# 5. Past Continuous

Formula:

was/were + V-ing

❌ I were watching... ✅ I was watching...

❌ She drank beer while... ✅ She was drinking beer while...

------------------------------------------------------------------------

# 6. Past Continuous + Past Simple

Background → Past Continuous

Interrupt → Past Simple

✅ I was studying when my friend called.

------------------------------------------------------------------------

# 7. Present Perfect vs Past Simple

Use Present Perfect - result now - unfinished time

Use Past Simple - yesterday - last... - in 2020 - when...

❌ When have you started? ✅ When did you start?

❌ When have you first met Simon? ✅ When did you first meet Simon?

------------------------------------------------------------------------

# 8. How long vs When

How long → Present Perfect

✅ How long have you lived here?

When → Past Simple

✅ When did you move here?

------------------------------------------------------------------------

# 9. for vs since

since = starting point

since Monday since 2023

for = duration

for two hours for three years

------------------------------------------------------------------------

# 10. just / already / yet / ever / never

Questions about life experience:

✅ Have you ever ridden a horse?

Negative:

✅ I haven't finished yet.

Positive:

✅ I've already done it.

Recent:

✅ I've just arrived.

------------------------------------------------------------------------

# 11. been vs gone

gone → still away

He's gone shopping.

been → returned

I've been to Japan.

------------------------------------------------------------------------

# 12. Present Perfect Continuous

Formula

have/has + been + V-ing

❌ have been were waiting ✅ have been waiting

------------------------------------------------------------------------

# 13. State Verbs

Don't use Continuous.

❌ I've been knowing him. ✅ I've known him.

❌ I've been having this bike. ✅ I've had this bike.

❌ I've been being ill. ✅ I've been ill.

------------------------------------------------------------------------

# 14. marry vs be married

Action

She got married last year.

State

She has been married for five years.

------------------------------------------------------------------------

# 15. It's ... since

Pattern

It's + period + since + Past Simple

❌ It's a month since I have seen Laura. ✅ It's a month since I saw
Laura.

❌ It's ages since I have eaten there. ✅ It's ages since I ate there.

------------------------------------------------------------------------

# 16. Articles

❌ run marathon ✅ run a marathon

❌ famous person ✅ a famous person

------------------------------------------------------------------------

# 17. Read the Situation Carefully

Common mistakes:

-   Changed the verb given by the exercise.
-   Used wrong subject (you/he/she).
-   Ignored keywords:
    -   so far
    -   since
    -   for
    -   last...
    -   yesterday
    -   when

Always identify:

1.  Subject
2.  Time expression
3.  State or action
4.  Result or process
