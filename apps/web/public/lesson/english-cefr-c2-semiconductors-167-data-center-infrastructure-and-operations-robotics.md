# C2 Vocabulary — Data-center infrastructure and operations robotics

This lesson follows a data center from physical inspection and cooling to rack service, power, access, and emergency response. The network is **data-center inspection robot → server aisle patrol robot → rack thermal mapping robot → cable tracing robot → hot-aisle containment inspection → battery backup inspection robot → fire suppression inspection robot → raised-floor survey robot → fiber patching robot → server replacement robot → rack inventory robot → cooling leak detection robot → power distribution inspection robot → generator maintenance robot → data-center cleaning robot → electrostatic monitoring robot → access mantrap robot → underfloor airflow mapping → crash cart delivery robot → remote hands robot**.

## 1. data-center inspection robot /ˈdeɪtə ˈsentər ɪnˈspekʃən ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that examines physical equipment and conditions inside a data center.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot examine physical equipment và condition trong data center.
**Grammar & collocations:** `data-center-inspection-robot route` — route; `inspect a restricted room` — inspect room restricted.
**Examples:** `The data-center inspection robot checked the cooling aisle before the load test.` → Data-center inspection robot check cooling aisle trước load test.
**Liên kết tiếng Hàn:** `데이터센터 검사 로봇`.
