# C2 Vocabulary — Court, legal records, and secure-facility robotics

This lesson follows legal material from filing and evidence intake to records, accessibility, secure delivery, and facility operations. The network is **court filing scanning robot → evidence handling robot → forensic imaging robot → document sealing robot → jury room service robot → courtroom accessibility robot → secure records retrieval robot → legal mail sorting robot → case file indexing robot → exhibit display robot → transcript verification robot → evidence chain-of-custody robot → archive retention robot → court facility patrol robot → prison mail inspection robot → correctional delivery robot → visitor screening robot → legal translation kiosk robot → court scheduling assistant robot → digital evidence intake robot**.

## 1. court filing scanning robot /kɔːrt ˈfaɪlɪŋ ˈskænɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that scans and registers documents submitted to a court.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot scan/register document nộp cho court.
**Grammar & collocations:** `court-filing-scanning-robot feeder` — feeder; `scan a signed motion` — scan motion đã sign.
**Examples:** `The court filing scanning robot registered the signed motion in the case system.` → Robot scanning court filing register motion đã sign vào case system.
**Liên kết tiếng Hàn:** `법원 서류 스캔 로봇`.
