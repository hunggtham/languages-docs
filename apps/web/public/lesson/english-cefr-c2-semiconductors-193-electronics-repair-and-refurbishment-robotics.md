# C2 Vocabulary — Electronics repair and refurbishment robotics

This lesson follows a device from diagnosis and component repair to secure wiping, grading, packaging, and recycling. The network is **electronics repair robot → circuit board inspection robot → solder rework robot → component placement repair robot → battery replacement repair robot → screen assembly robot → device teardown robot → repair parts inventory robot → diagnostic bench robot → electrostatic repair robot → connector insertion robot → thermal camera repair robot → water ingress test robot → firmware flashing robot → quality return inspection robot → warranty triage robot → recycling electronics robot → refurbishment grading robot → secure data wipe robot → device packaging robot**.

## 1. electronics repair robot /ɪˌlekˈtrɑːnɪks rɪˈper ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that diagnoses, repairs, or tests electronic devices.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot diagnose, repair hoặc test electronic device.
**Grammar & collocations:** `electronics-repair-robot bench` — bench; `repair a damaged device` — repair device hỏng.
**Examples:** `The electronics repair robot diagnosed and repaired the damaged device.` → Robot repair electronics diagnose và repair device hỏng.
**Liên kết tiếng Hàn:** `전자제품 수리 로봇`.
