# C2 Vocabulary — Precision crop and agricultural robotics

This lesson follows crop production from scouting and planting to disease control, harvesting, and field logistics. The network is **crop scouting robot → fruit ripeness robot → weed detection robot → precision spraying robot → autonomous tractor convoy → seed placement robot → orchard pruning robot → vineyard canopy robot → harvest yield mapping drone → soil nutrient sampling robot → irrigation leak robot → greenhouse pollination robot → plant phenotyping robot → crop disease imaging robot → autonomous cultivator → robotic grafting system → farm equipment docking robot → field boundary mapping drone → variable-rate application robot → agricultural residue robot**.

## 1. crop scouting robot /krɑːp ˈskaʊtɪŋ ˈroʊbɑːt/
**Part of speech:** noun
**Core meaning (English):** a robot that surveys crops for growth, stress, pests, or field conditions.
**Nghĩa cốt lõi & hình ảnh ghi nhớ:** robot survey crop về growth, stress, pest hoặc field condition.
**Grammar & collocations:** `crop-scouting-robot route` — route; `inspect a row of plants` — inspect row plant.
**Examples:** `The crop scouting robot found stressed plants near the field edge.` → Crop scouting robot tìm plant bị stress gần edge field.
**Liên kết tiếng Hàn:** `작물 정찰 로봇`.
