# IELTS Teacher Corrections

This file is the private source for correction-review tasks.

## How to use

1. Duplicate an entry after each IELTS class.
2. Give it a unique, permanent ID in the heading.
3. Change `status` from `draft` to `active` when it is worth reviewing.
4. In the app, log in as owner and click **Sync IELTS corrections**.
5. Do not rename an ID after syncing because progress is saved against that ID.

Allowed skills: `Grammar`, `Speaking`, `Pronunciation`, `Listening`, `Reading`, `Vocabulary`, `Writing`, `IELTS Class`, `Review`.

Allowed modes: `Anywhere`, `Desk`, `Commute`, `Can Speak`.

## 2026-09-08-final-t | Pronounce the final /t/ in “worked”

- status: draft
- skill: Pronunciation
- minutes: 5
- mode: Can Speak
- week: 1
- source: IELTS class correction
- next-review: 2026-09-09

### Correction

Do not drop the final /t/ in “worked”. Keep it short; do not add an extra vowel.

### Practice

Say “I worked late yesterday” slowly three times, then say it naturally twice without reading.

## 2026-09-08-present-perfect | Use present perfect for unfinished time

- status: draft
- skill: Grammar
- minutes: 5
- mode: Anywhere
- week: 1
- source: IELTS class correction
- next-review: 2026-09-11

### Correction

Use “I have lived in Korea for…” when the situation is still true now.

### Practice

Make three true present-perfect sentences about your life and say each sentence aloud.
